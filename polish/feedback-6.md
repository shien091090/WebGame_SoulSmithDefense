## Bug
- 第 1 關教學: 「買士兵階段如果買箭塔,會金幣不足造成關卡卡死」
  - 推論: 教學鎖表寫的是「買過 1 座之後鎖住弩塔, 到召喚步兵那一步才解開」, 解開後玩家照樣能把錢花在弩塔, 錢不夠買步兵就卡住。可比照第 2 關買魂柱的做法: 召喚步兵那一步只能買步兵, 或錢不夠時補到夠
- 第 2 關教學: 「一開始如果全部金幣買箭塔,沒錢買士兵,也會造成關卡卡死」
  - 推論: 開場「擺上一個箭塔和士兵」那一步要防止把錢全花在箭塔(例: 各限買一座 / 一隻, 或錢不夠時補到夠)

## 文案調整(左邊是現在的文字 → 使用者要的新文字)

### 魂件說明(選單、替換彈窗、圖鑑共用)
- 遠攻: 射箭打遠處的敵人 → 射箭攻擊範圍內敵人
- 冰霜: 讓敵人變慢, 攻擊會帶冰 → 攻擊附帶緩速效果
- 電擊: 攻擊會電到旁邊的敵人 → 攻擊附帶傷害擴散效果
- 治癒: 慢慢治好附近的友軍 → 緩慢治癒附近友軍
- 進攻主堡: 走回主堡, 退還買價 → 走回主堡,返還花費金幣
  - 使用者原本寫「走回主堡,返還一定比例花費」, 確認退款規則不變(走回主堡照舊全額退, 扣掉不在身上的出廠魂件)後改成這句
- 衝鋒: 沿路衝撞, 撞飛敵人 → 沿路衝撞敵人
- 購買: 裝在誰身上, 誰旁邊開店 → 可開啟商店功能
- 冰箭: 射出讓敵人大減速的箭 → 射箭攻擊附帶強大緩速效果
- 旋風斬: 砍擊身邊一圈敵人 → 大範圍砍擊
- 冰霜重擊: 重擊並凍慢一片敵人 → 範圍重擊並附帶緩速效果
- 雷霆斬: 帶電重砍, 打暈敵人 → 重擊附帶暈眩效果
- 雷電球: 射出慢飛的電球 → 發射出一顆電擊周遭敵人的雷電球
- 瞬閃: 閃電瞬移到敵人面前 → 敵人接近時會瞬移到敵人面前
- 治癒光線: 遠距治好最傷的友軍 → 發射治癒射線快速治癒友軍
- 神聖之路: 衝過的路能補血加速 → 移動時產生一條治癒和加速效果的軌跡
- 不動如山: 定在原地, 更耐打 → 大幅提高防禦力但無法移動
- 重設集結點(選單格): 拿旗插到新位置駐守 → 更改駐守位置
- 新文字有幾條超過原本「15 字內」的限制(最長「移動時產生一條治癒和加速效果的軌跡」17 字), 照使用者文字放, 版面跟著調整
