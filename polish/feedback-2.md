## 玩法變更(已告知使用者屬改玩法, 使用者選擇繼續打磨)
1. 回主堡退費: 「任何我方單位, 不只建築物, 只要裝上回主堡, 回去主堡都會全額返還」
2. 魂件來源: 屍體不能拔魂件, 只能拔活敵人; 拔除讀條中敵人死亡 → 讀條直接完成並獲得魂件(原話見「難度與關卡」)
3. 新魂件「電擊」(來自怪物): 「攻擊時會透過電擊連鎖部分傷害給附近敵人」
   - 電擊 + 自動索敵 = 瞬閃: 「是自動索敵的升級版, 可以直接閃電瞬移到附近敵人面前」
   - 電擊 + 近戰 = 雷霆斬: 「攻擊時除了原本的電擊連鎖以外再加上短暫暈眩效果, 攻擊力也會提升」
   - 電擊 + 遠攻 = 雷電球: 「發射出一個直直緩慢移動的雷電球, 雷電球會持續電擊周遭敵人」
   - 「以上這些效果都可以透過魂柱分享給範圍內單位」
4. 新魂件「治癒」(來自怪物): 「效果是持續治癒附近友軍, 多個治癒領域重疊時回血速度不會疊加」
   - 治癒 + 遠攻 = 治癒光線: 「從範圍治癒變成射出治癒射線給附近血最少的友軍, 範圍比單純治癒來的大, 且回血速度更快」
   - 治癒 + 衝鋒 = 神聖之路: 「移動時會留下軌跡持續一段時間, 友軍在軌跡上行走時會緩慢補血且行走速度變快, 多條軌跡疊加時效果不會疊加」(使用者原本說治癒 + 行軍, 後改為衝鋒, 見第 6 項)
5. 不動如山: 「效果是無論如何無法移動(重生移動回去定點除外), 同時防禦力提高」; 兩種配方都可以合成:
   - 回主堡 + 自動索敵
   - 回主堡 + 衝鋒
6. 拿掉行軍, 衝鋒改為基本魂件: 「我覺得行軍可以移除, 只要有衝鋒就好」
   - 衝鋒直接從怪物身上取得(原本帶行軍的敵人改帶衝鋒), 不再由行軍 + 近戰合成; 衝鋒原本的效果不變(沿路衝、衝撞撞退 + 暈眩、衝出畫面後從主堡繞回)
   - 使用者確認: 「衝鋒能組合的對象是治癒和回主堡這兩個」, 其他魂件都不能和衝鋒組合
