# 魂匠守衛者(打磨第 2 輪, 底版: 打磨第 1 輪 `polish/game` 就地修改)

## 本輪改動
相對打磨第 1 輪改了什麼, 美術 / RD / 音效各自看標記。規則編號有增刪與移動(例: 原規則 37 Z 一鍵處理 → 規則 39), 以本版為準, 不和上一版對號。

玩法:
1. **合成**(規則 14): 同一個單位身上的兩件基本魂件湊成組合, 當場合成一件「組合魂件」(遠攻 + 遠攻 → 穿透箭), 槽上只剩合成後那一件, 另一格空出來。組合魂件可以拆下來搬到別的單位。〔RD; 美術: 五種組合魂件圖示回到 drawSoulSlots / drawGroundPart / drawPlayer / drawSoulPopup〕
2. **共鳴疊加**(規則 15): 沒配成組的虛魂件也有單件效果; 多出來的冰霜會「附冰」在單位所有攻擊上(穿透箭 + 冰霜魂柱 = 帶冰的穿透箭, 修掉上輪「穿透箭吃不到冰霜」)。〔RD; 美術: drawPierceBeam / drawAreaHit / drawHitSpark 新增 frost〕
3. **玩家也吃共鳴**(規則 19): 玩家站在魂柱範圍內, 就得到那根魂柱的魂件效果(遠攻柱 → 玩家會射箭)。〔RD; 美術: drawPlayer 加回 resonating、attackAge〕
4. **商店不賣魂件**(規則 36): 只賣魂柱、弩塔、步兵、石魔像; 魂件全部從敵人身上拿。擴槽石整個拿掉。〔美術: drawShopPopup 改 4 格〕
5. **魂柱有上限、開局不放魂柱**(規則 36、關卡表): 每關上限 1~3 根, 只在商店的魂柱格顯示「已有 / 上限」。〔美術: drawShopPopup 新增 count、cap〕
6. **「購買」是一件魂件**(規則 37): 開局只裝在主堡上(主堡沒有其他魂件), 可以拔下來裝到別的我方單位, 誰身上有它, 誰旁邊就能開商店; 丟在地上不會消失, 外觀特殊。〔美術: 新增 drawShopZone, drawCastle 刪掉主堡區圈, drawGroundPart 新增 permanent〕
7. **買兵拿旗幟**(規則 38): 買步兵 / 石魔像後手上改拿旗幟(手上原本的魂件不會掉, 被旗幟蓋住), 插下旗幟, 兵從主堡走出到旗幟處。〔美術: 新增 drawRallyFlag, drawPlayer 新增 holdingFlag, drawPlacePreview 加 flag〕
8. **單位選單**(規則 40): 空手對我方建築 / 移動單位按 Z, 就算它身上沒有魂件也能開選單。建築多一格「拆除」(旁邊寫返還金額, 打 6 折), 移動單位多一格「重設集結點」(手上改拿旗幟)。〔美術: drawSoulPopup 改版〕
9. **魂件說明**(規則 40): 選單與替換彈窗下方多一塊說明, 寫游標那格魂件的名稱、效果; 組合魂件畫出它的兩件材料。〔美術: drawSoulPopup 新增 desc〕
10. **移動單位固守**(規則 25): 拿掉巡邏, 放下後站在集結點不動。步兵自帶「自動索敵」(原「索敵」改名), 裝著才會去打集結點附近的敵人。〔RD〕
11. **衝鋒 / 行軍到路線底**(規則 13、14): 衝出畫面, 1 秒後從主堡門走出繼續衝, 不算重生、不排隊; 有多條路線時走離集結點最近的那條。〔RD〕
12. **移動型魂件裝在建築上也有效**(規則 13、14): 弩塔、魂柱裝衝鋒 / 行軍 / 自動索敵會移動; 裝進攻主堡會慢慢走回主堡, 走到就消失並全額退款。〔RD; 美術: drawPillar 新增 moving、charging, drawCrossbow 新增 charging〕

## 概述
Y 型、長蛇、三叉……每一關路線不同, 鬼沿路線進攻主堡。玩家蓋弩塔與「魂柱」: 魂柱本身不攻擊, 但它身上的魂件會「共鳴」給周圍 150 內的每一個我方單位(塔、兵、主堡, 還有玩家自己)。魂柱裝冰霜, 周圍帶遠攻的塔全變冰箭; 換成遠攻, 全變穿透箭。魂件只能從鬼身上拿(屍體、活鬼), 同一個單位上湊成一組就合成更強的組合魂件。魂柱每關有上限, 要想清楚插在哪。
驗證假設: H03、H18、H32、H33、H39、H65、H66、H68、H71、H73、H74、H76、H78、H85~H96。

## 核心循環
看到預警是哪條路 → 從屍體、活鬼身上拿魂件 → 走到那一片的魂柱旁按 Z 裝上(或湊到同一個單位上合成)→ 範圍內的單位(和站在圈裡的自己)一起跳出組合名稱 → 鬼被打倒、噴金幣與屍體 → 撿錢買塔、魂柱(有上限)、兵 → 下一波換路, 跑過去換魂柱的魂件。
想再做一次的理由: 換一件魂件就讓一整片防線一起變招; 每關路線不同、魂柱數量有限, 該插哪裡要重新想; 想拿三星。

## 開始畫面
1. 打開網頁先進開始畫面: 上方大標題「魂匠守衛者」, 中間一排 5 張關卡卡片(關名 + 最佳星數; 未解鎖的畫鎖), 底部提示「[←][→] 選關  [Z] 開始  [X] 靜音」(方括號表示鍵帽圖示), 右上角喇叭圖示(靜音時打叉)。
2. 只有第 1 關一開始就解鎖; 通過第 N 關解鎖第 N+1 關。解鎖與最佳星數只存在這次開網頁的期間(重新整理就重置)。
3. ← → 在**已解鎖**的關卡間移動游標(不循環, 到頭停住); 開啟時游標在最大的已解鎖關。Z 進入該關, 直接開始遊戲(沒有說明頁)。X 切換靜音。
4. 進入關卡後, 要等 Z 放開才接受遊戲內的 Z。

規則:
- 階段由上往下排, 同時有多個階段的出現條件成立時只顯示編號最小的。
- 彈窗開著時只顯示「彈窗版」的階段: 商店開著 → 階段 2; 選單開著 → 階段 4(未完成時), 否則選單目標是屍體時的階段 7; 替換彈窗開著 → 階段 11。其他階段在彈窗開著時隱藏。
- 條件暫時不成立(例: 金幣被撿完、手上不是行軍)時泡泡隱藏, 條件再成立時再出現; 已完成的階段不再出現, 重玩、換關都不重置(只有重新整理網頁才重置)。
- 完成的那一下若同時關掉彈窗(階段 2、4、7、11), 完成特效照樣在完成當下泡泡所在的位置播完 0.6 秒(彈窗已不在)。
- 完成條件早已成立(例: 階段 4 出現時手上已經有魂件)時, 該階段出現的同一幀就完成並播特效。
- 完成特效長 0.6 秒; 播完下一個階段才出現。
- **第 1 關的波次倒數在階段 5 完成時才開始**(HUD 顯示「準備中」); 保險: 進關後遊戲時間 90 秒仍未完成階段 5 也開始倒數。階段 5 早已完成(重玩)時進關就開始倒數。其他關一進關就開始倒數。

### 魂件
11. 魂件分三類(conventions.itemKinds):
    - **基本魂件** 6 種: 遠攻、近戰、冰霜、自動索敵(原「索敵」改名)、進攻主堡、行軍
    - **組合魂件** 5 種: 穿透箭、冰箭、旋風斬、冰霜重擊、衝鋒(由規則 14 合成產生, 不能拆回材料)
    - **購買** 1 件: 全場唯一(規則 37)
    沒有擴槽石。
12. 魂件的「種類」(決定能不能共鳴、能不能讓單位動):
    - 攻擊類: 遠攻、近戰、冰霜、穿透箭、冰箭、旋風斬、冰霜重擊
    - 移動類: 自動索敵、進攻主堡、行軍、衝鋒(衝鋒同時會撞人, 規則 14 表)
    - 其他: 購買
13. 單件效果(對我方單位、主堡、玩家; n = 同種且「沒配成組」的件數, 實體 + 虛魂件合計):
    - 遠攻: 每 1.0 秒對射程 200 內最近的敵人射投射物(速度 420), 傷害 10×n
    - 近戰: 每 0.8 秒對碰觸距離(兩者半邊長和 +12)內最近的敵人造成 14×n 傷害
    - 冰霜: 單位有任何攻擊效果時 → 「附冰」: 它的每一次命中都讓敵人減速 50% 持續 2 秒(規則 15); 沒有攻擊效果時 → 自身中心 70 內的敵人移動速度 −30%(冰霜圈)
    - 自動索敵: 集結點 200 內有敵人時朝它移動, 速度 min(70×n, 140), 直到進入攻擊距離(有遠攻、穿透箭或冰箭: 180; 否則碰觸); 範圍內沒有就以速度 80 走回集結點。建築的集結點 = 蓋下的格子中心
    - 進攻主堡: 直線走向主堡; 移動單位速度 60, 走到主堡邊緣停下, 集結點改成停下的位置; **建築(弩塔、魂柱)速度 40, 中心進入主堡半徑 +10 內就消失並全額退款**(弩塔 15、魂柱 12), 身上其他魂件依序掉在 (1052+32×k, 580)(k 從 0 起算)成為地上的魂件
    - 行軍: 沿「目標路線」逆向走向出怪點(速度 50); 目標路線 = 這關所有路線中, 中線離這個單位集結點最近的那條(一樣近取關卡表列在前面的)。先直線走到目標路線上離自己最近的點, 再沿路逆走。到達出怪點(路線第 0 點)後沿同方向再走 半邊長+8 出畫面 → 消失 1.0 秒 → 從主堡門 (1124,434) 出現, 沿目標路線從主堡端逆走, 一直循環。這段消失**不算重生、不進重生排隊**, 消失期間不能互動、不是共鳴接收者、身上魂件保留
    - 敵人身上的魂件也照單件效果(不合成、不配組; 行軍對敵人沒有效果; 敵人的冰霜一律是冰霜圈)
    - 購買: 見規則 37
14. **合成**: 我方單位(弩塔、魂柱、步兵、石魔像)與主堡身上的實體槽, 只要有兩件基本魂件能湊成下表任一列, 當場合成: 依表的順序由上往下找, 找到的兩件中編號較小的那格變成組合魂件, 另一格變空; 重複直到湊不出組合。中立單位、屍體、敵人身上不合成。合成發生在裝上 / 互換的同一幀, 單位頭上跳出組合名稱(規則 16)。

    |---|---|---|---|
    | 0 | 穿透箭 | 遠攻 + 遠攻 | 每 1.0 秒朝射程 260 內最近的敵人射出一道直線, 線上(距線 14 內)每個敵人受 14 傷害 |
    | 1 | 冰箭 | 遠攻 + 冰霜 | 每 1.0 秒對射程 200 內最近的敵人射投射物, 10 傷害並減速 50% 持續 2 秒 |

15. **配組池與疊加**(每一幀算): 接收者的配組池 = 自己的實體魂件 + 共鳴來的虛魂件(規則 18)。
    1. 實體魂件已經依規則 14 合成完, 不會再有實體 + 實體的組合
    2. 虛的基本魂件依表的順序, 和「沒配到的實體基本魂件」或其他虛基本魂件配成組(先用虛的、再用實體的; 每件只用一次)→ 得到該組合的效果, 只在範圍內有效, 槽上不變
    3. 生效的效果 = 每件實體組合魂件 + 每件虛組合魂件 + 第 2 步配成的組 + 沒配到的基本魂件(實體或虛)的單件效果。**本輪起沒配到的虛魂件也有單件效果**
    4. 「附冰」: 沒配到的冰霜(實體或虛)在單位有任何攻擊效果時, 加在它所有攻擊上(規則 13 冰霜), 不再畫冰霜圈。附冰與冰箭 / 冰霜重擊的減速不疊加, 取最大
    - 例: 弩塔 [穿透箭] 在冰霜魂柱範圍內 → 冰霜配不到 → 附冰 → 穿透箭每一道都減速 50%。弩塔 [遠攻] 在冰霜魂柱範圍內 → 配成冰箭。空的弩塔在遠攻魂柱範圍內 → 射普通箭

17. 減速不疊加, 取最大的一個(搶奪減速 60% 也算在內)。每個攻擊效果各自計冷卻、各自找目標。行為優先序: 任一攻擊效果範圍內有目標 → 原地攻擊(衝鋒例外, 見表); 否則依序: 衝鋒 > 行軍 > 自動索敵 > 進攻主堡 > 站在集結點不動。

從開始畫面或結算畫面進入關卡後, 要等 Z 放開才接受遊戲內的 Z。
畫面上所有操作提示裡的按鍵, 一律畫成鍵帽(interface conventions.keycap), 不和文字黏在一起。

## 勝負與結束
- 勝利: 最後一波全部出完且場上沒有活著的敵人。
- 失敗: 主堡生命 ≤ 0。
- 結算畫面: 「勝利」/「主堡被攻陷」、關名、到達的波次、主堡剩餘生命、星星(勝利時 1~3 顆依序跳出, 失敗時 3 顆都暗)、已發現組合數(n / 5)。底部一排按鈕(← → 選, Z 執行, 預設第 0 個):
  - 勝利且不是第 5 關: [下一關, 重玩, 標題]
  - 第 5 關勝利: [重玩, 標題], 標題改「全部通關!」
  - 失敗: [重來, 標題]
  - 結算出現後 0.5 秒內的 Z 不算。重玩 / 重來 / 下一關都直接開始該關(不經過開始畫面)。
- 勝利時解鎖下一關, 並更新該關的最佳星數。

## 埋點
每一關結束(勝或敗、結算畫面出現的當下)自動下載一個 JSON, 檔名 `gamelog-SoulSmithDefense-<YYYYMMDD-HHMMSS>.json`(本機時間, 結算出現的時刻)。

時間欄位:
- `t`: 這關開始後經過的**真實秒數**(含慢動作期間的真實時間), 小數 1 位
- `st`: 這次開網頁後經過的真實秒數(教學跨關, 用這個比對)

檔案結構:
```
{
  "game": "SoulSmithDefense", "version": "polish-2",
  "summary": { ... }, "tutorial": { ... }, "events": [ ... ]
}
```

資源來去與累計欄位:
- 金幣來源: 撿金幣(goldEarned)、拆除返還與走回主堡退款(goldRefund, 不算 goldEarned); 去處: 商店(goldSpent)。goldEnd = 開局金幣 + goldEarned + goldRefund − goldSpent。

- 合成: 兩件基本魂件變一件組合魂件, 只記 fuse, 不另記 take / install / drop。
- 魂件去處: 裝上(install)、丟下(drop)、地上消失(ground_expire)、屍體消失(不記)。
- 購買魂件(item = "shop")照一般魂件記 take / install / drop / ground_swap, 但永遠不會有 ground_expire。
