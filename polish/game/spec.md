## 概述
Y 型、長蛇、三叉……每一關路線不同, 鬼沿路線進攻主堡。玩家蓋弩塔與「魂柱」: 魂柱本身不攻擊, 但它身上的魂件會「共鳴」給周圍 150 內的每一個我方單位(塔、兵、主堡, 還有玩家自己)。魂柱裝冰霜, 周圍帶遠攻的塔全變冰箭; 裝電擊, 周圍帶自動索敵的兵全變瞬閃。魂件只能從**活著的鬼**身上搶, 同一個單位上湊成一組就合成更強的組合魂件。魂柱每關有上限, 要想清楚插在哪。
驗證假設: H03、H18、H32、H33、H39、H66、H71、H73、H74、H76、H78、H85~H96、H98~H104。

## 核心循環
看到預警是哪條路 → 衝上前搶活鬼身上的魂件 → 走到那一片的魂柱旁按 Z 裝上(或湊到同一個單位上合成)→ 範圍內的單位(和站在圈裡的自己)一起跳出組合名稱 → 鬼被打倒、噴金幣 → 撿錢買塔(附帶遠攻)、魂柱(有上限)、兵 → 下一波換路, 跑過去換魂柱的魂件。
想再做一次的理由: 換一件魂件就讓一整片防線一起變招; 每關路線不同、魂柱數量有限, 該插哪裡要重新想; 10 種組合想全部組出來; 想拿三星。

## 開始畫面
1. 打開網頁先進開始畫面: 上方大標題「魂匠守衛者」, 中間一排 5 張關卡卡片(關名 + 最佳星數; 未解鎖的畫鎖), 底部提示「[←][→] 選關  [Z] 開始  [M] 靜音」(方括號表示鍵帽圖示), 右上角喇叭圖示(靜音時打叉)。
2. 只有第 1 關一開始就解鎖; 通過第 N 關解鎖第 N+1 關。解鎖與最佳星數只存在這次開網頁的期間(重新整理就重置)。
3. ← → 在**已解鎖**的關卡間移動游標(不循環, 到頭停住); 開啟時游標在最大的已解鎖關。Z 進入該關, 直接開始遊戲(沒有說明頁)。M 切換靜音。
4. 進入關卡後, 要等 Z 放開才接受遊戲內的 Z。

規則:
- 階段由上往下排, 同時有多個階段的出現條件成立時只顯示編號最小的。
- 彈窗開著時只顯示「彈窗版」的階段: 商店開著 → 階段 2; 單位選單開著 → 階段 4(未完成時); 替換彈窗開著 → 階段 10。其他階段在彈窗開著時隱藏。
- 條件暫時不成立(例: 金幣被撿完、手上不是衝鋒)時泡泡隱藏, 條件再成立時再出現; 已完成的階段不再出現, 重玩、換關都不重置(只有重新整理網頁才重置)。
- 完成的那一下若同時關掉彈窗(階段 2、4、10), 完成特效照樣在完成當下泡泡所在的位置播完 0.6 秒(彈窗已不在)。
- 完成條件早已成立(例: 階段 4 出現時手上已經有魂件)時, 該階段出現的同一幀就完成並播特效。
- 完成特效長 0.6 秒; 播完下一個階段才出現。
- **第 1 關的波次倒數在階段 5 完成時才開始**(HUD 顯示「準備中」); 保險: 進關後遊戲時間 90 秒仍未完成階段 5 也開始倒數。階段 5 早已完成(重玩)時進關就開始倒數。其他關一進關就開始倒數。

### 魂件
11. 魂件分三類(interface conventions.itemKinds):
    - **基本魂件** 8 種: 遠攻、近戰、冰霜、電擊、治癒、自動索敵、進攻主堡、衝鋒(本輪起衝鋒是基本魂件; 行軍刪除)
    - **組合魂件** 10 種: 穿透箭、冰箭、旋風斬、冰霜重擊、雷霆斬、雷電球、瞬閃、治癒光線、神聖之路、不動如山(由規則 14 合成產生, 不能拆回材料)
    - **購買** 1 件: 全場唯一(規則 40)
12. 魂件的「種類」:
    - 攻擊類: 遠攻、近戰、冰霜、電擊、穿透箭、冰箭、旋風斬、冰霜重擊、雷霆斬、雷電球
    - 支援類: 治癒、治癒光線
    - 移動類: 自動索敵、進攻主堡、衝鋒、瞬閃、神聖之路、不動如山
    - 其他: 購買
    - **會共鳴的** = 攻擊類 + 支援類(12 種); 移動類與購買不共鳴(規則 20)
    - 「攻擊效果」= 會打到敵人的效果: 遠攻、近戰、穿透箭、冰箭、旋風斬、冰霜重擊、雷霆斬、雷電球、電擊的單獨放電、衝鋒 / 神聖之路的衝撞、瞬閃的落地放電。冰霜、治癒、治癒光線本身不是攻擊效果
13. 單件效果(對我方單位、主堡、玩家; n = 同種且「沒配成組」的件數, 實體 + 虛魂件合計):
    - 遠攻: 每 1.0 秒對射程 200 內最近的敵人射投射物(速度 420), 傷害 10×n
    - 近戰: 每 0.8 秒對碰觸距離(兩者半邊長和 +12)內最近的敵人造成 14×n 傷害
    - 冰霜: 單位有任何攻擊效果時 → 「附冰」: 它的每一次命中都讓敵人減速 50% 持續 2 秒; 沒有攻擊效果時 → 自身中心 70 內的敵人移動速度 −30%(冰霜圈)
    - **電擊**(新): 單位有其他攻擊效果時 → 「附電」: 它的每一次命中, 另外對被打的敵人身邊 80 內最近的其他敵人(最多 2×n 隻, 上限 6)各造成該次傷害的 50%(連鎖; 連鎖出去的不再連鎖、不帶附冰); 沒有其他攻擊效果時 → 「放電」: 每 1.0 秒對自身中心 100 內最近的敵人造成 8×n 傷害, 並照附電連鎖(放電本身算攻擊效果, 所以同一單位的冰霜會附在放電上)
    - **治癒**(新): 自身中心 100 內的每一個友軍(我方步兵、石魔像, 含自己; 不含歸隊中與重生中的)每秒回 6 生命, 不超過上限。多個治癒領域重疊時**不疊加**(一個單位同一時間只吃一個治癒領域的 6/秒); n 件也不加快。建築、主堡、玩家沒有生命, 不受治癒, 但身上有治癒時照樣替周圍的兵補血
    - 自動索敵: 集結點 200 內有敵人時朝它移動, 速度 min(70×n, 140), 直到進入攻擊距離(有遠攻、穿透箭、冰箭或雷電球: 180; 否則碰觸); 範圍內沒有就以速度 80 走回集結點。建築的集結點 = 蓋下的格子中心
    - 進攻主堡: 直線走向主堡(移動單位速度 60, 建築速度 40)。**任何我方單位(弩塔、魂柱、步兵、石魔像)中心進入主堡半徑 +10 內就消失並退款**(規則 26 走回主堡: 全額, 扣掉不在身上的出廠魂件), 身上其他魂件依序掉在 (1052+32×k, 580)(k 從 0 起算)成為地上的魂件。移動單位走回去的路上照樣會打攻擊範圍內的敵人、會被敵人打(規則 30)
    - 衝鋒(本輪改基本魂件, 效果不變): 沿「目標路線」逆向走向出怪點(速度 90); 目標路線 = 這關所有路線中, 中線離這個單位集結點最近的那條(一樣近取關卡表列在前面的)。先直線走到目標路線上離自己最近的點, 再沿路逆走。到達出怪點(路線第 0 點)後沿同方向再走 半邊長+8 出畫面 → 消失 1.0 秒 → 從主堡門 (1124,434) 出現, 沿目標路線從主堡端逆走, 一直循環。這段消失**不算重生、不進重生排隊**, 消失期間不能互動、不是共鳴接收者、身上魂件保留。碰觸到敵人時不停下。**衝撞**: 每一隻進入碰觸距離的敵人(同一個衝鋒單位對同一隻敵人 1.0 秒內只撞一次)受 30×n 傷害、被撞退 60、暈眩 1.0 秒。撞退: 敵人在路線上 → 沿路線往出怪點方向退 60(退到出怪點為止), 在 0.2 秒內滑過去; 不在路線上(索敵追兵中)→ 沿「衝鋒單位 → 敵人」方向退 60。暈眩中的敵人不移動、不攻擊

    - 購買: 見規則 40

15. **配組池與疊加**(每一幀算): 接收者的配組池 = 自己的實體魂件 + 共鳴來的虛魂件(規則 20)。

    2. 虛的基本魂件依表的順序, 和「沒配到的實體基本魂件」或其他虛基本魂件配成組(先用虛的、再用實體的; 每件只用一次)→ 得到該組合的效果, 只在範圍內有效, 槽上不變。虛魂件只會是會共鳴的種類, 但配出來的組合可以是移動類(例: 虛電擊 + 實體自動索敵 → 瞬閃; 虛治癒 + 實體衝鋒 → 神聖之路); 離開魂柱範圍就失去
    3. 生效的效果 = 每件實體組合魂件 + 每件虛組合魂件 + 第 2 步配成的組 + 沒配到的基本魂件(實體或虛)的單件效果
    4. 「附冰」「附電」: 沒配到的冰霜 / 電擊在單位有其他攻擊效果時, 加在它所有攻擊上, 不再畫冰霜圈 / 不再單獨放電。附冰與冰箭 / 冰霜重擊的減速不疊加, 取最大
    - 例: 弩塔 [穿透箭] 在冰霜魂柱範圍內 → 冰霜配不到 → 附冰 → 穿透箭每一道都減速 50%。弩塔 [遠攻] 在電擊魂柱範圍內 → 配成雷電球。步兵 [近戰, 自動索敵] 在電擊魂柱範圍內 → 電擊先配近戰(雷霆斬, 順序 4 在瞬閃 6 前面)。空的弩塔在治癒魂柱範圍內 → 替周圍 100 內的兵補血

### 魂柱與共鳴
20. 魂柱: 建築, 本身不攻擊、不會被攻擊。身上**會共鳴的**魂件(規則 12: 攻擊類 + 支援類, 含組合魂件)會「共鳴」給中心距 ≤ 150 的每一個接收者, 成為接收者配組池裡的一件虛魂件。移動類與購買不共鳴, 只作用在魂柱自己身上(例: 魂柱裝衝鋒 → 魂柱自己衝出去, 範圍跟著走; 裝瞬閃 → 魂柱自己瞬移)。接收者: 弩塔、我方步兵、我方石魔像(歸隊中 / 重生中除外)、主堡、**玩家**。

40. **購買魂件**: 全場唯一, 開局裝在主堡上。它裝在哪個我方單位(含主堡)身上, 該單位中心 110 內就是「購買區」。購買不共鳴、不合成、不算出廠魂件, 可以像其他魂件一樣拿起、搬運、裝到任何我方單位或主堡上(中立單位、敵人不能裝, 不算安裝目標)。在地上、在手上、或它所在的單位正在重生 / 走出畫面中時, 場上沒有購買區(買不了東西)。帶著它的單位被拆除或走回主堡時, 它照一般魂件掉出。丟在地上不消失(規則 34)。
41. **旗幟**:
    - 來源: 商店買步兵 / 石魔像(這時那隻兵還沒出現); 或單位選單的「重設集結點」
    - 舉著旗幟時按 Z: 在合法位置(規則 27)插下, 不合法則無效。插下後旗幟留在地上, 對應的兵進入「歸隊中」走向旗幟(買的兵從主堡門 (1124,434) 走出; 重設的兵從所在位置出發), 到達後旗幟消失, 那裡就是它的新集結點。插下後玩家手上變回原本的東西
    - 拿著旗幟時畫放置預覽(合法 / 不合法)
    - 舉旗期間不能撿、拿、裝、丟東西(Z 只做插旗), 也不能再買兵或重設另一隻兵的集結點
    - 重設集結點的兵在玩家舉旗期間照常行動; 若它在舉旗期間倒下, 插下的旗幟在它重生走出後照樣生效; 若它在舉旗期間走回主堡退款了, 旗幟直接消失(插旗變成無效、不記 flag_plant)
42. 沒開彈窗、沒在搶奪時按 Z, 依手上的東西決定:
    1. **舉著旗幟** → 插旗(規則 41)
    2. **手上是建築材料** → 在合法位置蓋下(規則 27), 不合法則無效。拿著材料時畫面顯示放置預覽(合法 / 不合法), 預覽畫在格子中心; 拿著魂柱材料時預覽一併畫出它的範圍圈。弩塔蓋下時身上是 [遠攻, 空]
    3. **手上是魂件** → 「安裝目標」= 互動範圍內離玩家最近的一個: 我方單位(弩塔、魂柱、步兵、石魔像, 含歸隊中)、中立石魔像(購買除外)、主堡、地上的魂件。活敵人不算。
       - 安裝目標是單位、單位有空格 → 直接裝進編號最小的空格(從 0 起算), 手上變空, 接著檢查合成(規則 14)。不開彈窗
       - 安裝目標是單位、單位裝滿 → 打開「替換彈窗」(規則 44)
       - 安裝目標是地上的魂件 → 手上的東西和它互換(兩件都重新計時)
       - 沒有安裝目標 → 手上的東西丟在腳下, 成為地上的魂件(照規則 34 計時)
    4. **手空** → 「拿取目標」= 互動範圍內離玩家最近的一個: 地上的魂件、我方建築 / 移動單位(**身上沒有魂件也算**)、身上至少有一件魂件的主堡 / 中立單位 / 活敵人。倒下消散中的敵人不算。
       - 地上的魂件 → 撿起
       - 活敵人 → 開始搶奪(規則 47)
       - 其他 → 打開「單位選單」(規則 43)
       - 沒有拿取目標 → 無效
    - 「互動目標」(畫外框的那一個)= 依當下手上的東西算出的安裝目標或拿取目標; 拿著建築材料或舉著旗幟時沒有互動目標。
    - 玩家腳下常駐「Z 提示」, 寫這時按 Z 會做什麼: 拿起 / 選單 / 搶奪 / 裝上 / 替換 / 互換 / 丟下 / 蓋下 / 不能蓋 / 插旗 / 不能插 / 取消搶奪; 沒有動作時不顯示。「選單」= 手空且目標是我方單位、主堡或中立單位(會打開單位選單);「拿起」= 目標是地上的魂件。
43. **單位選單**: 一排格子 = 目標的實體魂件槽(長度 = 槽位上限)+ 0~1 格「選項格」:
    - 建築(魂柱、弩塔): 多一格「拆除」, 格子下方寫當下的退款金額「+N 金」(規則 26, 可能是 0)
    - 我方移動單位(步兵、石魔像, 含歸隊中): 多一格「重設集結點」, 格子下方寫「移防」
    - 主堡、中立: 沒有選項格
    - 開啟時游標在第一個有魂件的格子; 都沒有魂件時在選項格。← → 移動游標(頭尾循環)
    - 按 Z: 游標在有魂件的格子 → 拿到手上; 在「拆除」→ 拆掉該建築, 照規則 26 退款, 沒被收回的魂件依序掉在 (建築 x − 16×(m−1) + 32×k, 建築 y + 30)(m = 掉出件數, k 從 0 起算)成為地上的魂件; 在「重設集結點」→ 開始舉旗(規則 41)。成功後選單關閉; 游標在空格時無效, 選單抖一下、不關
    - 按 X 關閉
    - 說明區: 選單下半部顯示游標那格的說明(見「魂件說明」表): 名稱、一句效果; 組合魂件另畫出材料圖示「A + B」(不動如山畫「進攻主堡 + 自動索敵 / 衝鋒」); 拆除格寫「拆掉, 退還 N 金」; 重設集結點寫「拿旗插到新位置駐守」; 空格不顯示說明
    - 目標消失或目標中心離玩家超過「目標半邊長 +68」時選單自動關閉
44. 替換彈窗: 和單位選單同一種面板, 只有實體魂件槽(沒有選項格), 右側顯示手上的魂件。
    - 開啟時游標在「換掉後會合成的格」中編號最小的一格(換進手上魂件後, 依規則 14 會合成的那格); 沒有這種格時在第 0 格
    - ← → 移動游標(頭尾循環); Z: 手上的魂件與游標格互換(接著檢查合成), 彈窗關閉; X 關閉
    - 說明區顯示游標那格的說明(同規則 43)
    - 目標消失或離太遠時自動關閉(同規則 43)
45. **靜音: 任何時候按 M**(開始畫面、關卡中含彈窗開著、結算畫面), 背景音樂與音效一起切換。X 只用來關閉彈窗, 沒開彈窗時按 X 沒有作用。
46. 任何彈窗開著時, 遊戲時間變成 0.2 倍(慢動作), 玩家不能移動。
47. 搶奪(一鍵): 空手對活敵人按 Z → 從牠身上有魂件的格子中隨機選一格(之後不再換), 遊戲維持正常速度, 開始讀條 1.5 秒; 讀條期間該敵人減速 60%(速度 ×0.4)。結束方式:
    - 讀條滿 → 那一格的魂件從敵人身上移到玩家手上, 敵人立即失去它
    - **讀條中敵人生命歸 0 → 搶奪當場完成**, 那一格的魂件進到玩家手上(不論離玩家多遠、讀條跑到哪)
    - 敵人中心離玩家超過「敵人半邊長 +68」、敵人進入主堡、或再按 Z → 取消, 沒有任何損失(敵人恢復速度)
    - 搶奪中按 Z 只做取消。

## 勝負與結束
- 勝利: 最後一波全部出完且場上沒有活著的敵人。
- 失敗: 主堡生命 ≤ 0。
- 結算畫面: 「勝利」/「主堡被攻陷」、關名、到達的波次、主堡剩餘生命、星星(勝利時 1~3 顆依序跳出, 失敗時 3 顆都暗)、已發現組合數(n / 10)。底部一排按鈕(← → 選, Z 執行, 預設第 0 個):
  - 勝利且不是第 5 關: [下一關, 重玩, 標題]
  - 第 5 關勝利: [重玩, 標題], 標題改「全部通關!」
  - 失敗: [重來, 標題]
  - 結算出現後 0.5 秒內的 Z 不算。重玩 / 重來 / 下一關都直接開始該關(不經過開始畫面)。
- 勝利時解鎖下一關, 並更新該關的最佳星數。

## 埋點

時間欄位:

資源來去與累計欄位:
- 金幣來源: 撿金幣(goldEarned)、拆除與走回主堡退款(goldRefund, 不算 goldEarned; 中立招募沒有退款); 去處: 商店(goldSpent)。goldEnd = 開局金幣 + goldEarned + goldRefund − goldSpent。
- 魂件來源:
  - 單位選單拿與撿地上(算 take)
  - 搶奪(算 steal_done, 含 via = died; 不算 take)
  - **開局 / 購買時自帶的魂件**(新: 弩塔的遠攻; 兵的近戰、自動索敵上一輪就有): 弩塔記在 place 的 bundled, 兵的固定(由 purchase 的 item 推得), 不算 take / install
  - 拆除 / 退款 / 招募掉在地上的魂件(掉出時不記 take, 之後撿起才算 take from ground)
  - 地上互換(算 ground_swap, 不算 take / drop)
  - 屍體來源本輪刪除, take 不會再有 from = corpse
- 合成: 兩件基本魂件變一件組合魂件, 只記 fuse, 不另記 take / install / drop。
- 魂件去處: 裝上(install)、丟下(drop)、地上消失(ground_expire)、**退款時被收回的出廠魂件**(新, 只算 bundledBack, 不算 drop / ground_expire)、敵人倒下時身上的魂件(不記)。
- 購買魂件(item = "shop")照一般魂件記 take / install / drop / ground_swap, 但永遠不會有 ground_expire, 也不會被收回。
- 生命: 治癒是新的生命來源, 只記 healed / enemyHealed; 重生滿血不算 healed。

- 插下買來的兵的旗幟: flag_plant; 兵從主堡門走出時再播 unit_return。
- 同一種攻擊 / 命中 / 撿金幣音效同一幀只播一次; arrow_shot 每 0.1 秒最多播一次、shock_zap 每 0.15 秒最多播一次(玩家、單位、敵人共用這個限制)。
- 教學完成與觸發完成的動作音效(例: install_part)疊著播。
- 波次預警與上一波的戰鬥音效疊著播。
