## 概述
長蛇、夾擊、三叉……每一關路線不同, 鬼沿路線進攻主堡。玩家蓋弩塔與「魂柱」: 魂柱本身不攻擊, 但它身上的魂件會「共鳴」給周圍 150 內的每一個我方單位(塔、兵、主堡, 還有玩家自己)。魂柱裝冰霜, 周圍帶遠攻的塔全變冰箭; 裝電擊, 周圍帶自動索敵的兵全變瞬閃。魂件只能從**活著的鬼**身上搶, 同一個單位上湊成一組就合成更強的組合魂件。魂柱每關有上限、而且很貴, 要想清楚何時買、插在哪。
開局場上只有主堡(和中立石魔像), 一切從零自己佈陣。前兩關是新手教學, 用暫停式引導與新手任務一步一步帶玩家做過每個操作; 波次等玩家做完任務才推進。
驗證假設: H03、H18、H32、H33、H66、H71、H73、H74、H76、H78、H85~H94、H96、H98~H105、H107、H108、H110~H114(H39 Y 型雙路: 第 2 關改單線後沒有 Y 型關卡, 本輪不驗)。

## 核心循環
看到預警是哪條路 → 衝上前搶活鬼身上的魂件 → 走到那一片的魂柱旁按 Z 裝上(或湊到同一個單位上合成)→ 範圍內的單位(和站在圈裡的自己)一起跳出組合名稱 → 鬼被打倒、噴金幣 → 撿錢買塔(附帶遠攻)、魂柱(有上限、很貴)、兵 → 下一波換路, 跑過去換魂柱的魂件。
想再做一次的理由: 換一件魂件就讓一整片防線一起變招; 每關路線不同、魂柱數量有限, 該插哪裡要重新想; 10 種組合想全部組出來; 想拿三星。

6. **推進動畫**(這一關的勝利讓下一關第一次解鎖時, 回到這頁就播; 重玩舊關不播): 進這頁的那一幀就開始(中間不留空檔), 共 1.4 秒(真實時間)。0~0.8 秒玩家記號沿弧線(最高點比起點高 60)從過關的那張卡跳到下一張卡上方, 播 `level_advance`; 0.8~1.4 秒下一張卡的鎖碎開、卡片亮起, 播 `level_unlock`。播完游標直接出現在新解鎖的那張。

8. **操作鎖**(本輪新增, 修正: 上一版動畫播完前游標還停在原關卡, 這時按 Z 會進到原關卡): 從進這頁的那一幀起, 到大提示關閉與推進動畫全部播完為止, 只接受 M(大提示 ready 後另接受關閉它的 Z), 其他按鍵一律無效、不播音效; 這段期間不畫游標(drawTitle cursorIndex = −1), 播完才出現在新解鎖的那張。沒有大提示也沒有推進動畫時, 沒有這段鎖。
9. **第 1 關的教學鎖**(本輪新增, 使用者: 第一關過了之後, 在完成新手任務之前不可選回第一關): 第 1 關勝利過、而且這次開網頁還沒在第 2 關勝利過的期間, 第 1 關卡片上教學鎖(卡片微暗 + 角落小鎖頭, 星數照畫; 和「未解鎖」的大鎖一眼分得開)。游標在第 2 關按 ← 想移過去時: 游標不動, 播 `ui_invalid`, 卡片下方跳一行「教學期間不可這樣操作」(drawTutorialWarn, 位置 (640,600), 1.2 秒)。第 2 關勝利(「恭喜完成新手任務!」那一次)起解開。進這頁時游標本來就不會落在第 1 關(目前進度 / 剛玩的都是第 2 關)。

### 波次閘門與重出
- **第 k 波清空** = 第 1~k 波的敵人全部出完、沒有正在等著出場的教學重出敵人, 且場上活著的敵人全都是呆站的(身上沒有進攻主堡; 沒有活敵人也算)。呆站的敵人不擋教學閘門(使用者: 被拔掉進攻主堡的怪會一直站著, 留到最後一波再教怎麼處理), 但照樣擋勝利(勝利要場上沒有活敵人)。
- **第 1 關**: 進第 1 關時階段 16 還沒完成, 這一局的波次就由教學推進(沒有固定倒數; 階段 16 已完成則照「關卡」表 15 / 24 倒數): 第 1 波的預警在階段 8 完成時開始(進關時階段 8 已完成 → 進關 3 秒時); 第 2 波的預警在階段 14 完成且第 1 波已全部出完時開始; 第 3 波的預警在階段 16 完成時開始。第 2 波清空到階段 15 出現之間的 2.0 秒(本輪新增), 波次面板照「等新手任務」顯示 status "tutorial"。

15. **配組池與疊加**(每一幀算): 接收者的配組池 = 自己的實體魂件 + 共鳴來的虛魂件(規則 20)。
    1. 實體魂件已經依規則 14 合成完, 不會再有實體 + 實體的組合
    2. 虛的基本魂件依表的順序, 和「沒配到的實體基本魂件」或其他虛基本魂件配成組(先用虛的、再用實體的; 每件只用一次)→ 得到該組合的效果, 只在範圍內有效, 槽上不變。虛魂件只會是會共鳴的種類, 但配出來的組合可以是移動類(例: 虛電擊 + 實體自動索敵 → 瞬閃; 虛治癒 + 實體衝鋒 → 神聖之路); 離開魂柱範圍就失去
    3. 生效的效果 = 每件實體組合魂件 + 每件虛組合魂件 + 第 2 步配成的組 + 沒配到的基本魂件(實體或虛)的單件效果
    4. 「附冰」「附電」: 沒配到的冰霜 / 電擊在單位有其他攻擊效果時, 加在它所有攻擊上, 不再畫冰霜圈 / 不再單獨放電。附冰與冰箭 / 冰霜重擊的減速不疊加, 取最大
    - 例: 弩塔 [穿透箭] 在冰霜魂柱範圍內 → 冰霜配不到 → 附冰 → 穿透箭每一道都減速 50%。弩塔 [遠攻] 在電擊魂柱範圍內 → 配成雷電球。步兵 [近戰, 自動索敵] 在電擊魂柱範圍內 → 電擊先配近戰(雷霆斬, 順序 4 在瞬閃 6 前面)。空的弩塔在治癒魂柱範圍內 → 替周圍 100 內的兵補血
16. 單位多出一個組合(合成或第 15 條第 2 步配成, 含玩家)時, 頭上跳出組合名稱 1.5 秒; 同一個單位的同一種組合 4 秒內不重複跳。這種組合是**這次開網頁以來**第一次出現時改跳「新組合! <名稱>」(重玩、換關不清空)。例外: 這次是某條配方第一次真的合成(會跳第一次合成演出, 規則 52)時, 頭上照一般跳組合名稱(不加「新組合!」), 由演出負責慶祝。
17. 減速不疊加, 取最大的一個(搶奪減速 60% 也算在內)。每個攻擊效果各自計冷卻、各自找目標。

    - 來源: 商店買步兵 / 石魔像(這時那隻兵還沒出現); 或單位選單的「重設集結點」
    - 舉著旗幟時按 Z: 在合法位置(規則 27)插下, 不合法則無效。插下後旗幟留在地上, 對應的兵進入「歸隊中」走向旗幟(買的兵從主堡門 (1124,434) 走出; 重設的兵從所在位置出發), 到達後旗幟消失, 那裡就是它的新集結點。插下後玩家手上變回原本的東西
    - 拿著旗幟時畫放置預覽(合法 / 不合法)
    - 舉旗期間不能撿、拿、裝、丟東西(Z 只做插旗), 也不能再買兵或重設另一隻兵的集結點
    - 重設集結點的兵在玩家舉旗期間照常行動; 若它在舉旗期間倒下, 插下的旗幟在它重生走出後照樣生效; 若它在舉旗期間走回主堡退款了, 旗幟直接消失(插旗變成無效、不記 flag_plant)
42. 沒開彈窗、沒在搶奪時按 Z, 依手上的東西決定:
    1. **舉著旗幟** → 插旗(規則 41)
    2. **手上是建築材料** → 在合法位置蓋下(規則 27), 不合法則無效。拿著材料時畫面顯示放置預覽(合法 / 不合法), 預覽畫在格子中心; 拿著魂柱材料時預覽一併畫出它的範圍圈。弩塔蓋下時身上是 [遠攻, 空]
    3. **手上是魂件** → 「安裝目標」= 互動範圍內離玩家最近的一個: 我方單位(弩塔、魂柱、步兵、石魔像, 含歸隊中)、中立石魔像(購買除外)、主堡、地上的魂件。活敵人不算。
       - 安裝目標是單位、單位有空格 → 直接裝進編號最小的空格(從 0 起算), 手上變空, 接著檢查合成(規則 14)。不開彈窗
       - 安裝目標是單位、單位裝滿 → 打開「替換彈窗」(規則 44)
       - 安裝目標是地上的魂件 → 手上的東西和它互換(兩件都重新計時)
       - 沒有安裝目標 → 手上的東西丟在腳下, 成為地上的魂件(照規則 34 計時)
    4. **手空** → 「拿取目標」= 互動範圍內離玩家最近的一個: 地上的魂件、我方建築 / 移動單位(**身上沒有魂件也算**)、身上至少有一件魂件的主堡 / 中立單位 / 活敵人。倒下消散中的敵人不算。
       - 地上的魂件 → 撿起
       - 活敵人 → 開始搶奪(規則 47)
       - 其他 → 打開「單位選單」(規則 43)
       - 沒有拿取目標 → 無效
    - 「互動目標」(畫外框的那一個)= 依當下手上的東西算出的安裝目標或拿取目標; 拿著建築材料或舉著旗幟時沒有互動目標。
    - **教學鎖**(見「新手教學 / 教學鎖」): 這一下的動作被教學擋住時無效, 播 `ui_invalid` 並跳教學提示; 安裝目標存在但被擋時不會改成丟下。
    - 玩家腳下常駐「Z 提示」, 寫這時按 Z 會做什麼: 拿起 / 選單 / 搶奪 / 裝上 / 替換 / 互換 / 丟下 / 蓋下 / 不能蓋 / 插旗 / 不能插 / 取消搶奪, 以及被教學擋住時的「不能裝」(裝上 / 替換被擋)、「不能搶」(搶奪被擋); **蓋、插的「蓋下 / 不能蓋」「插旗 / 不能插」只照規則 27 的一般規則, 教學位置鎖不影響**(本輪改, H110: 教學不允許、但一般規則允許的位置照樣寫「蓋下」「插旗」, 按下 Z 才擋下並跳「教學期間不能放這裡」); 沒有動作時不顯示。「選單」= 手空且目標是我方單位、主堡或中立單位(會打開單位選單);「拿起」= 目標是地上的魂件。
43. **單位選單**: 一排格子 = 目標的實體魂件槽(長度 = 槽位上限)+ 0~1 格「選項格」:
    - 建築(魂柱、弩塔): 多一格「拆除」, 格子下方寫當下的退款金額「+N 金」(規則 26, 可能是 0)
    - 我方移動單位(步兵、石魔像, 含歸隊中): 多一格「重設集結點」, 格子下方寫「移防」
    - 主堡、中立: 沒有選項格
    - 開啟時游標在第一個有魂件的格子; 都沒有魂件時在選項格。← → 移動游標(頭尾循環)
    - 教學鎖住的格子(魂件格、拆除格)畫鎖頭, 游標停得到, 說明區照常顯示; 底部動作提示改「教學中不能動」(灰色), 按 Z 無效、選單抖一下、播 `ui_invalid`
    - 按 Z: 游標在有魂件的格子 → 拿到手上; 在「拆除」→ 拆掉該建築, 照規則 26 退款, 沒被收回的魂件依序掉在 (建築 x − 16×(m−1) + 32×k, 建築 y + 30)(m = 掉出件數, k 從 0 起算)成為地上的魂件; 在「重設集結點」→ 開始舉旗(規則 41)。成功後選單關閉; 游標在空格時無效, 選單抖一下、不關
    - 按 X 關閉
    - 說明區: 選單下半部顯示游標那格的說明(見「魂件說明」表): 名稱、一句效果; 組合魂件另畫出材料圖示「A + B」(不動如山畫「進攻主堡 + 自動索敵 / 衝鋒」); 拆除格寫「拆掉, 退還 N 金」; 重設集結點寫「拿旗插到新位置駐守」; 空格不顯示說明
    - 目標消失或目標中心離玩家超過「目標半邊長 +68」時選單自動關閉
44. 替換彈窗: 和單位選單同一種面板, 只有實體魂件槽(沒有選項格), 右側顯示手上的魂件。
    - 開啟時游標在「換掉後會合成的格」中編號最小的一格(換進手上魂件後, 依規則 14 會合成的那格); 沒有這種格時在第 0 格
    - ← → 移動游標(頭尾循環); Z: 手上的魂件與游標格互換(接著檢查合成), 彈窗關閉; X 關閉
    - 說明區顯示游標那格的說明(同規則 43)
    - 目標消失或離太遠時自動關閉(同規則 43)
45. **靜音: 任何時候按 M**(開始畫面、關卡中含彈窗開著、結算畫面), 背景音樂與音效一起切換。X 只用來關閉彈窗, 沒開彈窗時按 X 沒有作用。
46. 任何彈窗開著時, 遊戲時間變成 0.2 倍(慢動作), 玩家不能移動。
47. 搶奪(一鍵): 空手對活敵人按 Z → 從牠身上有魂件的格子中隨機選一格(之後不再換), 遊戲維持正常速度, 開始讀條 1.5 秒; 讀條期間該敵人減速 60%(速度 ×0.4)。結束方式:
    - 讀條滿 → 那一格的魂件從敵人身上移到玩家手上, 敵人立即失去它
    - **讀條中敵人生命歸 0 → 搶奪當場完成**, 那一格的魂件進到玩家手上(不論離玩家多遠、讀條跑到哪)
    - 敵人中心離玩家超過「敵人半邊長 +68」、敵人進入主堡、或再按 Z → 取消, 沒有任何損失(敵人恢復速度)
    - 搶奪中按 Z 只做取消。

### 暫停、圖鑑、演出(本輪新增)
50. **Esc 暫停**: 關卡中(沒有引導卡、合成演出、圖鑑、結算時)按 Esc → 整個遊戲暫停: 遊戲時間、波次時鐘、所有計時停住, 畫面壓暗、中央顯示暫停面板(drawPause), 播 `pause_on`, 背景音樂壓低一半。再按 Esc → 恢復, 播 `pause_off`。暫停中只接受 Esc 與 M。彈窗開著時也能暫停, 恢復後回到彈窗(仍是慢動作)。開始畫面、結算畫面按 Esc 沒有作用。
51. **C 組合圖鑑**(本作破例的按鍵, 不算進 Z / X / 空白鍵的動作鍵上限): 關卡中(沒有引導卡、合成演出、Esc 暫停、結算時)按 C → 遊戲暫停(同規則 50)並打開圖鑑(drawCodex), 播 `codex_open`。再按 C、或按 X、或按 Esc → 關閉並恢復, 播 `codex_close`(按 Esc 關圖鑑不會進暫停)。彈窗開著時也能開, 關掉後回到彈窗。
    - 內容: 全部 11 條配方(10 種組合, 不動如山有兩條), 每條一列「[材料 A] + [材料 B] = [組合]」, 用魂件圖示表示; 材料只寫名稱, 組合寫名稱 + 一句效果(文字照「魂件說明」表)。依規則 14 合成表的順序排, 不動如山兩條排最後(進攻主堡 + 自動索敵、進攻主堡 + 衝鋒)
    - **還沒解鎖的配方整列畫成問號**(本輪改, 使用者: 還沒解鎖之前先顯示問號, 解鎖之後才顯示): 材料 A、材料 B、組合三個圖示都畫成「?」格, 名稱寫「???」, 不寫效果; 列數與排序不變(玩家看得出總共有幾條)。解鎖 = 第 0~8 列: 這種組合這次開網頁出現過(規則 16 的「已發現」, 含魂柱共鳴配出的); 第 9、10 列(不動如山的兩條配方): 那一條配方這次開網頁真的合成過(規則 52)——不動如山只能靠合成產生, 兩條各自解鎖。拿掉「已組過」記號(使用者: 不用再顯示)。右上角「已發現 n / 10」(n = 規則 16 的已發現組合數)
    - 圖鑑沒有游標, 開著時只接受 C、X、Esc、M
52. **第一次合成演出**: 某條配方(11 條之一)**這次開網頁第一次真的合成**(規則 14, 實體槽裡兩件變一件; 魂柱共鳴的虛配組不算)時, 合成的那一幀整個遊戲暫停(同規則 50), 播演出(drawComboReveal):
    - 0~0.3 秒畫面壓暗; 0.3~0.9 秒材料 A 從左、材料 B 從右滑到中央, 中間一個「+」; 0.9~1.2 秒兩件撞在一起閃光, 變成組合魂件的大圖示並彈一下; 1.2~1.5 秒下方滑出說明面板: 「新組合!」、組合名稱、一句效果、旁邊小圖示寫出由哪兩件組成「[A] 名稱 + [B] 名稱」

    - 演出期間只接受 Z 與 M; 新手任務泡泡不畫、完成特效停住, 演出關掉後才播
    - 合成發生在彈窗裡(替換彈窗按 Z)時, 彈窗照常關閉, 再開始演出
53. **波次面板與波次推進動畫**: 波次資訊不放在上方 HUD, 改放在左上角的波次面板(drawWavePanel, 固定在 HUD 下方 x 8~228、y 54~112), 常駐:

54. **主堡血量牌**: 主堡生命畫在主堡身上(drawCastle), 常駐不隱藏: 主堡本體下半部一塊血量牌(中心 (1180,472), 100×20), 畫生命條 + 數字「hp / 20」。被突破時牌子跟著主堡閃一下; 生命 ≤ 5 時牌子變紅並緩慢閃爍。上方 HUD 不再顯示主堡生命。

| Z(引導卡) | 卡片出現滿 1.5 秒後: 下一張 / 繼續 |

| X(彈窗中) | 關閉彈窗 |

## 勝負與結束
- 勝利: 最後一波全部出完、場上沒有活著的敵人, 且沒有正在等著重出的教學敵人。
- 失敗: 主堡生命 ≤ 0。第 1、2 關教學中也會輸(重來時已完成的教學階段不再出現)。
- 結算畫面: 「勝利」/「主堡被攻陷」、關名、到達的波次、主堡剩餘生命、星星(勝利時 1~3 顆依序跳出, 失敗時 3 顆都暗)、已發現組合數(n / 10)。底部一排按鈕(← → 選, Z 執行, 預設第 0 個):
  - 勝利: [繼續, 重玩]; 第 5 關勝利標題改「全部通關!」。例外(本輪新增): 第 1 關勝利、而這次開網頁還沒在第 2 關勝利過 → 只有 [繼續](關卡預覽頁的第 1 關這時上教學鎖, 「重玩」會繞過它; 見「開始畫面」第 9 條)
  - 失敗: [重來, 關卡預覽]
  - 「繼續」「關卡預覽」→ 回到關卡預覽頁(開始畫面); 這次勝利讓下一關第一次解鎖時, 在那頁播推進動畫(「開始畫面」第 6、7 條)。「重玩」「重來」直接開始同一關
  - 結算出現後 0.5 秒內的 Z 不算。
- 勝利時解鎖下一關, 並更新該關的最佳星數。

## 埋點
每一關結束(勝或敗、結算畫面出現的當下)自動下載一個 JSON, 檔名 `gamelog-SoulSmithDefense-<YYYYMMDD-HHMMSS>.json`(本機時間, 結算出現的時刻)。

時間欄位:

資源來去與累計欄位:
- 金幣來源: 撿金幣(goldEarned, 含教學重出的敵人掉的)、拆除與走回主堡退款(goldRefund, 不算 goldEarned; 中立招募沒有退款); 教學補金幣(tutorialGold, 本輪新增的來源; 不算 goldEarned、不算 goldRefund, 也不產生 coin 撿取); 去處: 商店(goldSpent)。goldEnd = 開局金幣 + goldEarned + goldRefund + tutorialGold − goldSpent。開局金幣 30 / 70 / 70 / 85 / 80, 不記進任何累計欄位。
- 魂柱提價只改 purchase 的 price(40)與拆除 / 走回主堡的 refund(24 / 40), 欄位不變。
- 本輪沒有新增資源的來源或去處: 輕快小鬼攻擊變小、步兵生命停在 1 只影響生命, 不產生 unit_down / unit_respawn(被擋下的那幾次記 tutorialFloor, 不算 unitDowns); 搬運箭頭、等待提示、關卡預覽頁的鎖都不動金幣與魂件。
- 教學重出的敵人和一般敵人一樣算進 kills、playerKills、leaks、leaksByWave、steals(另外記 tutorialSpawns 與 tutorial_spawn)。
- 教學期間地上魂件不會消失, 那段期間不會有 ground_expire。
- 本輪開局全空, 不再有開局就在場上的弩塔 / 步兵, 所以「開局自帶的魂件」只剩購買時自帶的(弩塔記在 place 的 bundled, 步兵由 purchase 推得)。
- 魂件來源:
  - 單位選單拿與撿地上(算 take)
  - 搶奪(算 steal_done, 含 via = died; 不算 take)
  - **開局 / 購買時自帶的魂件**(新: 弩塔的遠攻; 兵的近戰、自動索敵上一輪就有): 弩塔記在 place 的 bundled, 兵的固定(由 purchase 的 item 推得), 不算 take / install
  - 拆除 / 退款 / 招募掉在地上的魂件(掉出時不記 take, 之後撿起才算 take from ground)
  - 地上互換(算 ground_swap, 不算 take / drop)
  - 屍體來源本輪刪除, take 不會再有 from = corpse
- 合成: 兩件基本魂件變一件組合魂件, 只記 fuse, 不另記 take / install / drop。
- 魂件去處: 裝上(install)、丟下(drop)、地上消失(ground_expire)、**退款時被收回的出廠魂件**(新, 只算 bundledBack, 不算 drop / ground_expire)、敵人倒下時身上的魂件(不記)。
- 購買魂件(item = "shop")照一般魂件記 take / install / drop / ground_swap, 但永遠不會有 ground_expire, 也不會被收回。
- 生命: 治癒是新的生命來源, 只記 healed / enemyHealed; 重生滿血不算 healed。

治癒領域、聖光軌跡、醫鬼補血是持續效果, 不配音效(避免一直響)。

背景音樂:
- `title`: 開始畫面(關卡預覽頁), 循環
- `battle`: 關卡中, 循環; 彈窗開著(慢動作)時音量降到一半並壓低音色, 關閉後恢復; **Esc 暫停、圖鑑、引導卡、合成演出期間也降到一半**(本輪新增), 結束後恢復
- 結算畫面停止背景音樂(只播 level_win / level_lose 與 star)

靜音: **任何時候按 M**(開始畫面、關卡中含彈窗 / 暫停 / 圖鑑 / 引導卡 / 合成演出開著、結算畫面), 背景音樂與音效一起切換; HUD 與開始畫面右上角的喇叭圖示顯示狀態。靜音狀態跨關保留。
暫停: **關卡中按 Esc**(規則 50), 暫停期間背景音樂降到一半、正在播的音效照常播完、不再觸發新的遊戲音效。

同時觸發的處理:
- 最後一隻敵人倒下 → 勝利: enemy_die 照播, level_win 疊著播。
- 敵人突破主堡 → 主堡生命歸 0: 只播 level_lose, 不播 castle_hit。
- 讀條中的敵人倒下 → 搶奪完成: enemy_die 與 steal_done 疊著播。
- 雷霆斬命中: 只播 thunder_slash(它的連鎖不另播 shock_zap); 其他攻擊帶附電: 該攻擊自己的音效與 shock_zap 疊著播。
- 瞬閃到敵人面前: blink 與落地放電的 shock_zap 疊著播。
- 裝上 / 互換造成合成: install_part(或 swap_part)與 fuse 疊著播; 合成出的組合是這次開網頁第一次出現時, fuse 換成 combo_new(只播一個), 不另播 combo。
- 組合名稱同一幀跳出多個(換一件魂柱魂件讓整片單位一起變招): 該幀只播一次; 有任何一個是首次就只播 combo_new, 否則只播 combo; 同一幀已有 fuse 時不播 combo(combo_new 仍照上一條)。
- 拆除: demolish 單獨播, 不另播 coin_pickup; 拆除掉出的魂件不播 drop_part。
- 走回主堡退款(建築或兵): home_refund 單獨播, 掉出的魂件不播 drop_part。
- 插下買來的兵的旗幟: flag_plant; 兵從主堡門走出時再播 unit_return。
- 同一種攻擊 / 命中 / 撿金幣音效同一幀只播一次; arrow_shot 每 0.1 秒最多播一次、shock_zap 每 0.15 秒最多播一次(玩家、單位、敵人共用這個限制)。
- 教學完成與觸發完成的動作音效(例: install_part)疊著播。
- 第一次合成(規則 52): 合成那一幀播 install_part(或 swap_part)與 combo_reveal, **不播 fuse、combo_new、combo**; 演出關掉播 ui_confirm; 如果這一下也完成了新手任務(例: 階段 12), tutorial_done 在演出關掉後、泡泡完成特效開始時才播。
- 引導卡: 暫停那一刻只播 guide_pause(同一幀其他音效照常疊著), 0.3 秒後第 1 張卡出現播 guide_card; 換卡只播新卡的 guide_card(按 Z 本身不另播); 最後一張按 Z 播 ui_confirm。新手任務完成特效播完緊接著出引導卡時, tutorial_done 與 guide_pause 先後播, 不疊。
- 新手任務完成後緊接著出下一個任務: tutorial_done 播在完成時, quest_new 播在 0.6 秒後新泡泡出現時。
- 波次推進: wave_start 只在出怪那一刻播一次, 和橫幅同步; 第 1 關教學推進的波次也一樣。
- 新手教學完成大提示與推進動畫: 先播 tutorial_clear, 按 Z 播 ui_confirm, 之後推進動畫播 level_advance、level_unlock。
- 波次預警與上一波的戰鬥音效疊著播。
- 教學補金幣(階段 24、30 出現的那一刻): coin_pickup 與新任務的 quest_new 疊著播(本輪新增)。
- 第 2 關階段 17 / 25 完成: tutorial_done 播在完成時, 0.6 秒後特效播完才開始預警, wave_warning 接在後面, 不疊。
- 搬運箭頭(本輪新增)出現、換下一件都不播音效(換件一定伴隨 take_part / install_part / swap_part, 再加聲音會太吵); 清單某項打勾也不另播。
- 第 1 關第 2 波清空(最後一隻倒下的 enemy_die)與階段 15 引導卡的 guide_pause 相隔 2.0 秒(本輪新增的間隔), 不疊。
- 階段 22 的等待提示: 第一次出現播 quest_new; 招募成功時播 recruit, 泡泡換成「去主堡看看」不另播 quest_new(同一個階段)。
- 關卡預覽頁操作鎖期間(本輪新增)按 Z、←、→ 不播任何音效(包括 ui_invalid; 只有第 1 關教學鎖擋下時播 ui_invalid)。
- 敵人近戰打我方兵: 沿用既有的處理(不另配音效), 本輪只加斬擊畫面。

## 範圍邊界
- 不做: 大地圖、特殊事件點、存檔(解鎖與星數只存在這次開網頁期間)
- 不做擴槽(擴槽石拿掉; 擴充來源等使用者之後指定)
- 不做玩家身上的魂件槽; 玩家的攻擊只來自魂柱共鳴(H66)
- 不做組合魂件拆回材料
- 不做敵人攻擊建築、主堡、玩家
- 不做背包; 不做可互動的屍體
- 第 3 關起沒有新手教學; 冰霜、電擊(魂柱以外的用法)、治癒、衝鋒與其他組合不另做教學階段(選單說明區、第一次合成演出、C 鍵圖鑑(解鎖後)會講)
- 暫停面板沒有選項(只能繼續); 不做從暫停回標題
- 教學鎖只在第 1、2 關教學中; 教學完成後重玩第 1、2 關沒有任何鎖、引導、重出與補金幣
- 不做「教學限制的預先提示」: 位置鎖不在預覽上畫可放 / 不可放, 只在放下時擋(H110)
