## 概述
Y 型、長蛇、三叉……每一關路線不同, 鬼沿路線進攻主堡。玩家蓋弩塔與「魂柱」: 魂柱本身不攻擊, 但它身上的魂件會「共鳴」給周圍 150 內的每一個我方單位(塔、兵、主堡), 當作他們多帶一件魂件拿來湊組合。魂柱裝冰霜, 周圍帶遠攻的塔全變冰箭; 換成遠攻, 全變穿透箭。玩家從塔、屍體、活鬼身上拿魂件, 走到單位旁按 Z 就裝上。敵人只打我方的兵, 兵倒下會回主堡重新出發。
驗證假設: H03、H32、H33、H39、H65、H68、H69、H71、H73、H74、H76、H78。

## 核心循環
看到預警是哪條路 → 想好要讓哪一片單位變成什麼招 → 從塔、屍體、活鬼身上拿魂件, 走到那一片的魂柱旁按 Z 裝上(或多蓋一根魂柱)→ 範圍內的單位一起跳出組合名稱 → 鬼被打倒、噴金幣 → 撿錢買塔、魂柱、兵 → 下一波換路, 跑過去換魂柱的魂件。
想再做一次的理由: 換一件魂件就讓一整片防線一起變招; 每關路線不同, 魂柱該擺哪裡要重新想; 想拿三星。

## 開始畫面
1. 打開網頁先進開始畫面: 上方大標題「魂匠守衛者」, 中間一排 5 張關卡卡片(關名 + 最佳星數; 未解鎖的畫鎖), 底部提示「← → 選關  Z 開始  X 靜音」, 右上角喇叭圖示(靜音時打叉)。
2. 只有第 1 關一開始就解鎖; 通過第 N 關解鎖第 N+1 關。解鎖與最佳星數只存在這次開網頁的期間(重新整理就重置)。
3. ← → 在**已解鎖**的關卡間移動游標(不循環, 到頭停住); 開啟時游標在最大的已解鎖關。Z 進入該關, 直接開始遊戲(沒有說明頁)。X 切換靜音。
4. 進入關卡後, 要等 Z 放開才接受遊戲內的 Z。

規則:
- 階段由上往下排, 同時有多個階段的出現條件成立時只顯示編號最小的; 階段 9 例外: 替換彈窗開著時優先顯示它。
- 條件暫時不成立(例: 金幣被撿完、手上不是行軍)時泡泡隱藏, 條件再成立時再出現; 已完成的階段不再出現, 重玩、換關都不重置(只有重新整理網頁才重置)。
- 任何彈窗開著時, 只顯示階段 9, 其他階段隱藏。完成的那一下若是彈窗內的動作(階段 2 用彈窗拿、階段 5、階段 9), 彈窗是當場關閉的, 完成特效在彈窗關閉後的同一幀開始播, 播在該階段原本的泡泡位置。
- 完成特效長 0.6 秒; 播完下一個階段才出現。
- **第 1 關的波次倒數在階段 3 完成時才開始**(HUD 顯示「準備中」); 階段 3 早已完成(重玩)時進關就開始倒數。其他關一進關就開始倒數。

### 魂件
12. 基本魂件六種: 遠攻、近戰、冰霜、索敵、進攻主堡、行軍; 另有擴槽石。**沒有組合魂件這種物品**(底版的魂爐拿掉)。
13. 單件效果(n = 這個單位身上沒配成組的同種實體魂件數):
    - 遠攻: 每 1.0 秒對射程 200 內最近的敵對單位射投射物(速度 420), 傷害 10×n
    - 近戰: 每 0.8 秒對碰觸距離(兩者半邊長和 +12)內最近的敵對單位造成 14×n 傷害
    - 冰霜: 自身中心 70 內的敵對單位移動速度 −30%
    - 索敵: 離據點 200 內有敵對單位時朝它移動, 速度 min(70×n, 140), 直到進入攻擊距離(有遠攻、穿透箭或冰箭: 180; 否則碰觸); 範圍內沒有就以速度 80 走回據點
    - 進攻主堡: 直線走到主堡邊緣停下, 據點改成停下的位置
    - 行軍: **只對移動單位有效**: 離開據點, 沿所在路線逆向走向出怪點(速度 50), 到了就停在出怪點; 走到分岔點時, 走向路上活著的敵人比較多的那條(一樣多走關卡表裡列在前面的那條)
14. 組合(配組): 每個單位的「配組池」= 自己身上的實體魂件 + 共鳴來的虛魂件(規則 18)。依下表順序由上往下, 池裡兩種都有就配成一組, 能配幾組配幾組, 每件只用一次; 配組時先用虛魂件、再用實體魂件。配成組的魂件只發揮組合效果; 沒配到的實體魂件發揮單件效果, 沒配到的虛魂件沒有效果。
    | 順序 | 名稱 | 魂件 | 效果 |
    |---|---|---|---|
    | 0 | 穿透箭 | 遠攻 + 遠攻 | 每 1.0 秒朝射程 260 內最近的敵對單位射出一道直線, 線上(距線 14 內)每個敵對單位受 14 傷害 |
    | 1 | 冰箭 | 遠攻 + 冰霜 | 每 1.0 秒對射程 200 內最近的敵對單位射投射物, 10 傷害並減速 50% 持續 2 秒 |
    | 2 | 旋風斬 | 近戰 + 近戰 | 每 0.8 秒對自身中心 60 內所有敵對單位造成 16 傷害 |
    | 3 | 冰霜重擊 | 近戰 + 冰霜 | 每 0.8 秒對碰觸距離內最近的敵對單位造成 16 傷害, 並使它與它身邊 60 內的敵對單位減速 50% 持續 2 秒 |
    | 4 | 衝鋒 | 行軍 + 近戰 | **只有移動單位會配這一組**(弩塔、主堡跳過這一列): 沿路線逆向走向出怪點(速度 90, 分岔點的選法同行軍), 碰觸到敵人時不停下。**衝撞**: 每一隻進入碰觸距離的敵人(同一個衝鋒單位對同一隻敵人 1.0 秒內只撞一次)受 30 傷害、被撞退 60、暈眩 1.0 秒。撞退: 敵人在路線上 → 沿路線往出怪點方向退 60(退到出怪點為止), 在 0.2 秒內滑過去; 不在路線上(索敵追兵中)→ 沿「衝鋒單位 → 敵人」方向退 60。暈眩中的敵人不移動、不攻擊、不能被撞退以外的方式移動 |
15. (刪除: 組合魂件)
16. 單位每多出一個組合(含共鳴造成的), 頭上跳出組合名稱 1.5 秒; 同一個單位的同一種組合 4 秒內不重複跳。這種組合是**這次開網頁以來**第一次出現時改跳「新組合! <名稱>」, 並記進 HUD 的「已發現組合」(重玩、換關不清空)。

### 玩家
35. 玩家移動速度 260, 不會被攻擊、不擋路, **身上沒有魂件槽, 不攻擊**。
    - 手上最多「拿著」1 樣東西: 一件魂件、擴槽石、或一份單位材料
    - 互動範圍: 中心距 ≤ 目標半邊長 +48
36. 商店: 在主堡區內、沒開任何彈窗時按空白鍵, 打開「商店彈窗」(慢動作同規則 40)。一排 8 項(從 0 起算): 弩塔 15、魂柱 12、步兵 12、遠攻 8、近戰 8、冰霜 12、擴槽石 20、石魔像 18(招募過石魔像才解鎖)。索敵、進攻主堡、行軍只能從敵人與單位身上取得。
    - 開啟時游標在第 0 項; ← → 移動(頭尾循環)
    - 按 Z 購買: 金幣足夠、已解鎖、手上是空的 → 扣錢, 東西進到手上, 彈窗關閉; 否則無效(彈窗抖一下, 底部提示「金幣不足」「尚未解鎖」或「手上要空著」)
    - 按 X 關閉
37. 沒開彈窗、沒在搶奪時按 Z, 依手上的東西決定:
    1. **手上是單位材料** → 在合法位置放置(規則 23), 不合法則無效。拿著材料時畫面顯示放置預覽(合法 / 不合法); 靜態單位的預覽畫在格子中心; 拿著魂柱材料時預覽一併畫出它的範圍圈
    2. **手上是魂件或擴槽石** → 「安裝目標」= 互動範圍內離玩家最近的一個: 我方單位(弩塔、魂柱、步兵、石魔像, 含歸隊中)、中立石魔像、主堡、地上的魂件。擴槽石只把「可擴槽且未達上限」的單位算進來。屍體、活敵人不算。
       - 安裝目標是單位、手上是魂件、單位有空格 → 直接裝進編號最小的空格(從 0 起算), 手上變空。不開彈窗
       - 安裝目標是單位、手上是魂件、單位裝滿 → 打開「替換彈窗」(規則 38)
       - 安裝目標是單位、手上是擴槽石 → 槽位上限 +1, 擴槽石用掉。不開彈窗
       - 安裝目標是地上的魂件 → 手上的東西和它互換
       - 沒有安裝目標 → 手上的東西丟在腳下, 成為地上的魂件(不會消失)
    3. **手空** → 「拿取目標」= 互動範圍內離玩家最近的一個: 地上的魂件、身上至少有一件魂件的我方單位 / 中立單位 / 主堡 / 屍體 / 活敵人。
       - 地上的魂件 → 撿起
       - 活敵人 → 開始搶奪(規則 41)
       - 其他 → 打開「拿取彈窗」(規則 38)
       - 沒有拿取目標 → 無效
    - 「互動目標」(畫外框的那一個)= 依當下手上的東西算出的安裝目標或拿取目標; 拿著單位材料時沒有互動目標。
    - 玩家腳下常駐「Z 提示」, 寫這時按 Z 會做什麼: 拿起 / 搶奪 / 裝上 / 替換 / 擴槽 / 互換 / 丟下 / 蓋下 / 不能蓋 / 取消搶奪; 沒有動作時不顯示。
38. 拿取彈窗 / 替換彈窗(同一種面板): 顯示目標的實體魂件槽(長度 = 槽位上限)和玩家手上的東西(虛魂件不顯示, 不能拆)。
    - 拿取彈窗: 開啟時游標在第一個有魂件的格子; 替換彈窗: 開啟時游標在第 0 格
    - ← → 移動游標(頭尾循環)
    - 按 Z: 拿取彈窗中游標格有魂件 → 拿到手上; 替換彈窗中 → 手上的魂件與游標格互換。成功後彈窗關閉; 游標在空格(拿取彈窗)時無效, 彈窗抖一下、不關
    - 按 X 關閉
    - 目標消失或目標中心離玩家超過「目標半邊長 +68」時彈窗自動關閉
39. 沒開彈窗時按 X: 切換靜音(背景音樂與音效一起)。
40. 任何彈窗開著時, 遊戲時間變成 0.2 倍(慢動作), 玩家不能移動。
41. 搶奪(一鍵): 空手對活敵人按 Z → 從牠身上有魂件的格子中隨機選一格(之後不再換), 遊戲維持正常速度, 開始讀條 1.5 秒; 讀條期間該敵人減速 60%(速度 ×0.4)。讀條滿 → 那一格的魂件從敵人身上移到玩家手上, 敵人立即失去它。搶奪中玩家可以移動; 敵人中心離玩家超過「敵人半邊長 +68」、敵人死亡、或再按 Z 時取消, 沒有任何損失(敵人恢復速度)。搶奪中按 Z 只做取消。

- 勝利: 最後一波全部出完且場上沒有活著的敵人。
- 失敗: 主堡生命 ≤ 0。
- 結算畫面: 「勝利」/「主堡被攻陷」、關名、到達的波次、主堡剩餘生命、星星(勝利時 1~3 顆依序跳出, 失敗時 3 顆都暗)、已發現組合數(n / 5)。底部一排按鈕(← → 選, Z 執行, 預設第 0 個):
  - 勝利且不是第 5 關: [下一關, 重玩, 標題]
  - 第 5 關勝利: [重玩, 標題], 標題改「全部通關!」
  - 失敗: [重來, 標題]
  - 結算出現後 0.5 秒內的 Z 不算。重玩 / 重來 / 下一關都直接開始該關(不經過開始畫面)。
- 勝利時解鎖下一關, 並更新該關的最佳星數。

## 埋點
每一關結束(勝或敗、結算畫面出現的當下)自動下載一個 JSON, 檔名 `gamelog-SoulSmithDefense-<YYYYMMDD-HHMMSS>.json`(本機時間, 結算出現的時刻)。

時間欄位:
- `t`: 這關開始後經過的**真實秒數**(含慢動作期間的真實時間), 小數 1 位
- `st`: 這次開網頁後經過的真實秒數(教學跨關, 用這個比對)

檔案結構:
```
{
  "game": "SoulSmithDefense", "version": "polish-1",
  "summary": { ... }, "tutorial": { ... }, "events": [ ... ]
}
```

`summary`(結算出現時記錄):
| 欄位 | 說明 |
|---|---|
| level / levelName | 關卡編號(1~5)/ 關名 |
| attempt | 這次開網頁以來第幾次玩這關(從 1 起算, 含這次) |
| failsBefore | 這次開網頁以來這關在這次之前失敗過幾次 → 算失敗次數 |
| result | "win" / "lose" |
| durationSec | 這關從開始到結算的真實秒數 → 算每關通過時間 |
| gameSec | 同一段的遊戲時間秒數(慢動作期間按 0.2 倍計) |
| slowMoSec | 彈窗開著(慢動作)的真實秒數總和 |
| waveReached / totalWaves | 結束時已開始的波數 / 總波數 → 卡關位置 |
| castleHp / stars | 結束時主堡生命 / 星數(失敗 0) |
| leaks | 突破主堡的敵人數(= events 裡 leak 的筆數) |
| leaksByWave | 陣列, 第 k 項(從 0 起算 = 第 k+1 波)該波漏掉幾隻 → 卡在哪一波 |
| leaksBySpawn | 物件, 出怪點名稱 → 漏掉幾隻 → 卡在哪條路 |
| kills | 打倒的敵人數 |
| goldEarned | 撿到的金幣枚數 × 2(只算撿到的; 開局金幣不算) |
| goldSpent | 商店花掉的金幣總和 |
| goldEnd | 結束時身上金幣 |
| purchases | 物件, 品項 → 買了幾次 |
| steals | 物件 { started, done, canceled } |
| installs | 物件 { direct, replace, slotStone } — 直接裝、替換彈窗互換、擴槽各幾次 |
| drops | 丟下次數(拿著東西沒有安裝目標時按 Z) |
| unitDowns | 我方移動單位倒下(回主堡)次數 |
| recruits | 招募成功(中立單位進入主堡)次數 |
| combosFoundThisLevel | 這關裡第一次出現(新組合!)的組合名稱陣列 |
| combosFoundTotal | 這次開網頁以來已發現的組合數(0~5) |

`tutorial`(結算出現時記錄): 物件, 階段編號(字串 "1"~"12")→ { shownSt, doneSt }; shownSt = 這個階段第一次顯示的 st, doneSt = 完成的 st; 還沒出現 / 還沒完成的為 null。每個檔案都放完整的 12 個階段(跨關累積), 所以任何一個檔案都能算出每個教學階段出現與完成的時間。

`events`(依發生順序, 每筆都有 `type`、`t`、`st`):
| type | 何時記錄 | 其他欄位 |
|---|---|---|
| level_start | 進入關卡的當下 | level, attempt |
| clock_start | 波次倒數開始(第 1 關可能晚於 level_start) | |
| wave_start | 第 k 波開始出怪的當下 | wave |
| leak | 敵人進入主堡的當下 | wave(該敵人所屬波), enemy, spawn, castleHpAfter |
| purchase | 商店購買成功 | item, price, goldAfter |
| place | 放下單位材料 | kind, x, y |
| take | 從拿取彈窗拿到手上、或撿起地上的魂件 | item, from(crossbow / pillar / soldier / golem / neutral / castle / corpse / ground) |
| install | 裝上 / 替換 / 擴槽成功 | item, to(同 from 的單位種類), mode(direct / replace / slotStone), swappedOut(替換時換下來的魂件, 否則 null) |
| ground_swap | 手上東西和地上魂件互換 | item(放下的), got(拿到的) |
| drop | 丟下 | item |
| steal_start / steal_done / steal_cancel | 搶奪開始 / 成功 / 取消 | enemy, item; cancel 另有 reason(far / dead / key) |
| combo_new | 某組合這次開網頁以來第一次出現 | name, unit |
| recruit | 中立石魔像進入主堡 | |
| unit_down | 我方移動單位生命歸 0 | unit, x, y |
| tutorial_show / tutorial_done | 教學階段第一次顯示 / 完成 | stage |
| mute | 切換靜音 | muted |
| level_end | 結算出現 | result, wave, castleHp, stars |

資源來去與累計欄位:
- 金幣只有一個來源(撿金幣)與一個去處(商店), goldEarned / goldSpent 各算一邊。
- 魂件的來源: 商店購買(算 purchase 與 goldSpent, 不算 take)、拿取彈窗與撿地上(算 take)、搶奪(算 steal_done, 不算 take)、招募後在主堡旁掉出的魂件(掉出時不記, 之後撿起才算 take from ground)、地上互換(算 ground_swap, 不算 take / drop)。
- 擴槽石: 購買算 purchase, 用掉算 install(mode slotStone); 丟下 / 撿起照魂件算。
