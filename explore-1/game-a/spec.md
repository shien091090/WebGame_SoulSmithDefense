# 魂匠急行(跑位壓力)

## 概述
敵人從西、北、東三條路輪流進攻中央主堡, 玩家是不會戰鬥的魂匠, 只能親自跑到單位旁邊、站定按住才能拆裝魂件, 手上一次只拿得了一件; 在三條防線間奔走, 臨場決定先救哪裡。
驗證假設: H01、H02、H03、H04、H05、H06、H07、H08、H09、H10。

## 核心循環
看到某條路的預警 → 跑去別處拆下魂件(或撿屍體上的魂件)→ 搬到快被突破的防線裝上 → 敵人死掉噴金幣、留下帶魂件的屍體 → 趁消失前撿錢、搶魂件 → 回主堡買新單位 → 下一波換一條路, 再跑一次。
想再做一次的理由: 每一波的路線組合不同, 「這次先救哪裡、從哪拆」都要重新判斷; 跑對了防線一口氣守住的爽快。

## 規則
### 地圖
1. 畫面 1280×720, 上方 0~50 為 HUD。主堡中心 (640,430), 半徑 56。
2. 三條直線路線, 寬 56: 西路 y=430 從 x=0 到主堡; 東路 y=430 從 x=1280 到主堡; 北路 x=640 從 y=50 到主堡。
3. 六個建造地基(64×64), 編號從 0 起算: 0 (220,340)、1 (420,520)、2 (1060,340)、3 (860,520)、4 (540,170)、5 (740,290)。0、1 屬西路, 2、3 屬東路, 4、5 屬北路。
4. 主堡周圍半徑 110 內是「主堡區」(購買用)。

### 開局
5. 金幣 30, 主堡生命 20。
6. 地基 0、2、4 上各有一座箭塔, 魂件 [遠攻], 槽位上限 2。
7. 主堡魂件 [遠攻, 遠攻], 槽位上限 3。
8. 兩隻中立石魔像在 (160,640)、(1120,640), 無魂件, 槽位上限 3。
9. 玩家出生在 (640,560)。

### 單位
10. 單位數值:
    - 箭塔: 生命 120, 槽位 2, 預設 [](購買時)
    - 步兵: 生命 60, 槽位 2, 預設 [近戰, 索敵]
    - 石魔像: 生命 250, 槽位 3, 預設 []
    - 主堡: 槽位 3, 不會被敵人攻擊、永遠不會移動
    - 小鬼: 生命 30, 速度 45, 槽位 2, [近戰, 進攻主堡], 掉 2 枚金幣, 抵達主堡扣 2
    - 弓鬼: 生命 24, 速度 45, 槽位 2, [遠攻, 進攻主堡], 掉 3 枚金幣, 抵達主堡扣 2
    - 狂鬼: 生命 70, 速度 40, 槽位 3, [近戰, 索敵, 進攻主堡], 掉 4 枚金幣, 抵達主堡扣 4
11. 單位的行為完全由身上的魂件決定, 沒有魂件就什麼都不做。同種魂件裝多個時數值相加(n 個遠攻 = 傷害 ×n)。
12. 魂件效果(n = 同種魂件數量):
    - 遠攻: 每 1.0 秒對 200 內最近的敵對單位射出投射物(速度 400), 傷害 8×n
    - 近戰: 每 0.8 秒對碰觸距離(兩者半徑和 +12)內最近的敵對單位造成 12×n 傷害
    - 索敵: 240 內有敵對單位時朝它移動, 速度 min(70×n, 140), 直到進入攻擊距離(有遠攻: 180; 否則碰觸)
    - 進攻主堡: 朝主堡前進。敵人沿自己的路線走; 其他單位直線走向主堡
13. 行為優先序: 攻擊範圍內有目標就原地攻擊不移動 > 索敵 > 進攻主堡 > 不動。
14. 箭塔裝上索敵或進攻主堡就會移動(速度同上規則, 進攻主堡時速度 45); 移動後不再佔用地基, 地基變回空的。
15. 敵人的「敵對單位」= 我方的箭塔、步兵、石魔像; 不攻擊玩家、主堡、中立單位。我方單位(含主堡)的敵對單位 = 敵人。中立單位不受攻擊、也不攻擊。
16. 中立單位只對「進攻主堡」有反應: 裝上後直線走向主堡(速度 45), 其他魂件裝在中立單位身上沒有效果。
17. 敵人中心進入主堡半徑 +10 內: 主堡扣對應生命, 敵人消失, 不留屍體、不掉金幣。
18. 中立單位走進主堡(同上距離): 該單位消失, 它身上的魂件掉在 (640,520) 成為地上物品, 主堡商店解鎖該單位(石魔像)。
19. 我方單位裝了進攻主堡: 走到主堡邊緣停下, 沒有其他效果。
20. 任何單位(含我方)生命歸 0: 變成屍體, 保留身上全部魂件, 10 秒後連同魂件一起消失。敵人死亡時另外在 40 半徑內隨機噴出金幣, 每枚 2 金。
21. 金幣 7 秒後消失, 最後 2 秒閃爍。玩家中心距金幣 34 內自動撿起。

### 玩家
22. 移動速度 260, 不會受傷, 不擋路, 敵人無視玩家。
23. 「手」上最多拿 1 件東西: 魂件、擴槽石、箭塔材料、步兵、石魔像其中之一。
24. 互動目標 = 距離最近、且中心距 ≤ 目標半邊長 +44 的可互動物(我方單位、中立單位、主堡、屍體、地上物品、空地基)。活著的敵人不能互動。
25. 目標有魂件時, 會有一格被選中; 換目標時預設選最右邊有魂件的那格。按 K 依序換到下一個有魂件的格子。
26. 按住 J 依手上狀態執行(按住期間有移動或放開 J, 進度歸零):
    - 手空、目標是單位或屍體: 1.2 秒後拆下選中那格的魂件到手上, 原單位立即失去它
    - 手空、目標是地上物品: 0.3 秒後撿起
    - 手拿魂件、目標是我方單位 / 中立單位 / 主堡且有空格: 0.8 秒後裝進第一個空格
    - 手拿擴槽石、目標是我方單位 / 中立單位 / 主堡且槽位上限 < 4: 0.8 秒後上限 +1, 擴槽石用掉
    - 手拿箭塔材料、目標是空地基: 0.8 秒後蓋出一座空箭塔(槽位 2)
27. 手拿步兵或石魔像時, 按下 J(不用按住)立即放在玩家腳下, 從此依魂件行動。
28. 按 L: 把手上的東西丟在腳下, 成為地上物品(地上物品不會消失)。
29. 在主堡區內且手空時, 按 1~4 購買, 金幣不足或未解鎖則無效:
    - 1 箭塔材料 15 金(靜態單位, 只能蓋在空地基上)
    - 2 步兵 12 金(移動單位, 放在腳下)
    - 3 擴槽石 20 金
    - 4 石魔像 18 金(移動單位, 招募過石魔像才解鎖)
30. 購買的東西直接進手上。

### 波次
31. 說明頁關閉後開始計時。第 k 波在 10 + (k−1)×22 秒開始; 開始前 5 秒, 該波會用到的每條路線出現預警。
32. 每條路線每 1.2 秒出一隻, 依下表順序:
    - 第 1 波: 西 小鬼×4
    - 第 2 波: 東 小鬼×4、弓鬼×2
    - 第 3 波: 北 小鬼×5; 西 弓鬼×2
    - 第 4 波: 西 狂鬼×3; 東 小鬼×4
    - 第 5 波: 北 弓鬼×4、狂鬼×3; 東 小鬼×3
    - 第 6 波: 西、北、東 各 小鬼×4、狂鬼×2
33. 出怪點: 西 (10,430)、東 (1270,430)、北 (640,60)。

## 操作
只用鍵盤。
| 按鍵 | 動作 |
|---|---|
| W A S D | 移動 |
| 按住 J | 拆下魂件 / 撿起地上物品 / 裝上魂件 / 用擴槽石 / 在地基蓋箭塔 |
| J | 手拿步兵或石魔像時, 放在腳下 |
| K | 換選目標身上的下一格魂件 |
| L | 丟下手上的東西 |
| 1~4 | 在主堡區購買 |
| J | 說明頁翻頁, 最後一頁再按開始遊戲 |
| Enter | 結算畫面重新開始 |
說明頁關閉時要等 J 放開後才接受按住 J 的動作, 避免一進場就誤觸。

## 勝負與結束
- 勝利: 第 6 波全部出完且場上沒有活著的敵人。
- 失敗: 主堡生命 ≤ 0。
- 結算畫面顯示勝利或失敗, 按 Enter 從開局重新開始(不再顯示說明頁)。

## 範圍邊界
- 不做: 大地圖、星星、多關卡、跨關解鎖、特殊事件點、音效、難度曲線
- 不做魂件組合效果(同種只疊數值)
- 不做賣出、不做玩家血量、不做敵人拆裝
- 活著的敵人不能拆
