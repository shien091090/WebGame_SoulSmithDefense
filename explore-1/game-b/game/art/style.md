## 3. 形狀語言

扁平幾何 + 深色描邊; **我方 = 圓角、藍色本體、腳下藍底座; 敵方 = 尖角(角、鋸齒)+ 紅色本體 + 深紅描邊、無底座; 中立 = 灰綠 + 虛線圈; 玩家 = 米白斗篷金邊, 全場唯一**。魂件一律裝在「深色圓角方格」裡, 不論在頭上槽列、地上、背包、目標格、商店, 都是同一格同一圖示。

## 4. 理念落實

- **P0 辨識度先於好看**: 陣營用「顏色 + 輪廓 + 有沒有底座」三條分; 屍體去飽和 + 壓扁 + X 眼, 一眼分得出活的跟死的。
- **P1 視覺權重跟著決策迫切度**: 背景草地與路線壓低飽和; 最亮的是魂件格(玩家要拆裝的東西)與面板目標的白框; 發現橫幅放在 y 154~226 的路線第一段上方, 不蓋 HUD 的常駐讀數。
- **P2 規則上存在的東西要看得見**: 主堡區(半徑 130)畫成金色虛線圈, 玩家在區內變亮; 中立樹精的虛線圈標出「不屬於任何一方」; 減速、受擊、攻擊、移動都有各自外觀; 金幣不足 / 未解鎖在商店格上分開畫。
- **P3 一個意義一種長相**: 魂件圖示一套用到底(槽列、背包、目標格、地上魂件、商店); 組合色 + 組合圖示在槽列配對框、底部面板、圖鑑、橫幅一致; 白實線框只代表「面板目標」; 金色只代表金幣 / 錢 / 主堡區。
- **P4 關鍵區分走兩條通道**: 敵我 = 色相 + 輪廓(尖角 vs 圓角 + 底座); 四種敵人 = 剪影(圓頭角 / 前傾水滴 + 速度線 / 灰甲頭盔肩甲 / 翅膀)+ 尺寸; 五種範圍效果 = 顏色 + 形狀(見物件表)。
- **P7 每個元素都要掙得版面**: 血條只在受傷時畫; 槽列不加文字; 底部面板 none 模式只留兩行淡字。
- **P9 以最混亂那刻驗收**: 槽列有深色背襯、配對連線有黑色襯底, 壓在路線、範圍效果上仍讀得到; 文字一律帶黑描邊或壓在面板上。
- **P13 事件要排隊**: 同時只有一條發現橫幅(RD 依規格 2.5 秒播); 橫幅只有一行字。
- **P15 回饋強度與份量成正比**: 命中火花 24px(最小)< 旋風斬 / 爆裂彈範圍 < 死亡爆炸 / 自爆 / 冰爆 < 發現組合橫幅(全畫面唯一帶字事件)。
- **P17 進度圖形與數字分工**: 屍體剩餘時間只用透明度表達(沒有數字, 圖形畫總進度); 下一波倒數只用數字, ≤ 5 秒變橘。
- **P18 重要資訊不能只閃一下**: 發現的組合留在 HUD 圖鑑(常駐), 結算再列一次。
- **P19 資訊貼著物件**: 魂件槽列貼在每個單位頭上; 血條貼頭上; 減速覆蓋長在本體上。
- **P21 示意圖要選會分岔的例子**: 第 3 頁同時畫「拆」與「裝」兩個方向, 並放屍體與自己兩個角落例子, 避免玩家以為只能點塔; 第 6 頁畫鎖 → 可買, 對照未招募前。

## 8. 說明頁(drawGuidePage)

**分工**: 美術只畫示意圖, 只畫在 `(x, y, w, h)` 框內(會先 clip), 框內底色是草地色圓角矩形。**頁標題、說明文字、頁碼、翻頁提示由 RD 畫**。圖內只有物件旁的短標籤(「出怪口」「你」「屍體」「拆」「裝」「圖鑑」…)。
> 與介面 textOwnership(「所有文字由美術畫」)的偏離: 介面的繪製清單沒有說明頁函式、state 也沒有傳說明文字, 照字面就沒人畫得出說明文字; 因此說明頁沿用任務單分工。請 RD 畫頁面文字並把示意圖框留給 drawGuidePage。

## 9. 判讀約定

- `drawAreaEffect` 的 radius = 外緣, 所有元素畫在 radius 以內(圓面、外環內緣貼 radius)。
- 減速覆蓋、受擊閃都在判定框內; 攻擊上彈 3px(介面允許 4)。
- `drawSoulSlots` 的 pairs 只畫 a、b 都在 slots 範圍內的項; slots 超過 3 格只畫前 3。
- `drawBottomPanel` 的 targetSlots 超過 3 只畫前 3, shopItems 超過 7 只畫前 7(介面固定上限)。
- `drawHud` 的 nextWave 介面上限 4 項, 超過只畫前 4。
- 商店單位品項的小圖依 name 判斷(含「箭塔」→ 箭塔、「樹精」→ 樹精、其他 → 步兵)。
