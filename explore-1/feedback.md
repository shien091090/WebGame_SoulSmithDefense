## game-a(魂匠急行)
- 「拆組件下來裝到別的單位上, 很簡單的動作, 不用經過一層背包進出, 裝上去直接生效, 並且馬上可以看到搭起來的效果, 我覺得很棒」 → 對應機制: 拆裝直接在單位間進行、裝上即生效且效果立即可見(推論)
- 「讓玩家在場上很忙是我要的體驗沒錯, 但目前a款難度太高」「方向上是OK的」 → 對應機制: 多條路線間奔走調度(H04、H06 的正向體驗); 難度使用者表示「可以等到打磨階段再細調」
- 「搭好的防禦塔一下就被拆掉了讓人體驗不好」(見跨款「不好的體驗」)

## game-b(魂匠煉成)
- 「裝上去會跳出該單位的攻擊變成XX技能, 例如兩個進攻變成旋風斬, 我覺得超酷, 很喜歡」 → 對應機制: 魂件組合產生有名字的新技能, 並在裝上時跳出提示(H11)
- 「b款用滑鼠玩的體驗不是很喜歡」 → 對應機制: 滑鼠操作(推論: 使用者偏好鍵盤操控角色)

## game-c(魂匠掠奪)
- 「搶敵人魂件的設計我覺得很好, 這樣讓原本難以獲得或成本高(要花錢)的魂件有更多來源」 → 對應機制: 從活著的敵人身上拆魂件(H17、H18)
- 「搶敵人魂件的代價如果是讀條速度比較慢我覺得是合理的, 體驗也不錯」 → 對應機制: 從敵人身上拆要讀條較久
- 「c款多了背包的設計, 按鍵變多了操作也變得非常複雜, 玩起來非常卡」 → 對應機制: 背包作為魂件中轉
- 「c款怪物沒有固定路線而是改成從四面八方進攻, 這個體驗不喜歡, 這樣未來擴充關卡的話就比較難做出每一關地圖的差異性, 也比較難以玩出不同策略」 → 對應機制: 敵人四面八方進攻、無固定路線(H21)

## 跨款比較
- A 的直接拆裝手感與 B 的組合變技能是使用者明確喜歡的兩點; C 的搶敵人魂件也被肯定
- 拆裝操作的期望(原話):
  - 「我希望對我方或中立單位不要有讀條設計, 在已經很忙碌的情況下, 且非常頻繁需要拆裝組件的情況下, 讀條會讓人有點焦急」
  - 「選擇要拆哪個組件的部分用按鍵去切換也有點卡, 希望是按鍵打開一個小彈窗, 在彈窗狀態時再去用方向鍵選擇, 這樣體感上或許會比較不那麼卡」

## 不好的體驗
- 「3款都一樣的部分是, 好不容易組裝好的單位(不管是步兵還是防禦塔), 很容易被敵人圍攻就打死, 讓人有種白忙一場的感覺, 體驗不佳」 → 可能來源: 單位耐久低、敵人會集火我方單位, 使魂件投資容易歸零(推論)
- 「c款多了背包的設計, 按鍵變多了操作也變得非常複雜」 → 可能來源: 背包中轉增加操作步驟
- 「從四面八方進攻, 這個體驗不喜歡」 → 可能來源: 無固定路線
- 「b款用滑鼠玩的體驗不是很喜歡」 → 可能來源: 滑鼠操作
- 拆裝我方 / 中立單位的讀條「會讓人有點焦急」 → 可能來源: 拆裝需站定讀條(H06)

## 補充(使用者看過整理後補答)
- 「慢動作面板我覺得體驗不錯, 當選擇魂件時如果整體變慢動作, 可以讓玩家多一點思考時間, 但慢動作的畫面表現要再更明顯一點, 這樣體驗應該會比較好」 → 對應機制: B 開魂件面板時慢動作(H15; 使用者感受為正面, 與 H15 預期的「削弱緊湊感」相反)
- 「波次預警我覺得不是體驗問題而是這類型遊戲必做, 不做體驗會非常差, 玩家需要對接下來的進攻提早做準備」 → 對應機制: 波次預警(H08); 使用者視為此類型的必備功能
- 「金幣限時消失體驗不好, 在已經很忙碌的情況下, 不應該逼迫玩家一樣要趕到某個地方去」 → 對應機制: 金幣限時消失(H09)
- 「屍體限時消失則需要拿捏, 因為都不消失會讓場面變的很亂辨識度很差, 一下就消失則會有一樣強迫玩家要趕過去的問題」 → 對應機制: 屍體(連同魂件)限時消失(H09); 存在時間要取中間值
- 組合圖鑑(H13): 使用者試玩時沒注意到這個功能, 無感受
