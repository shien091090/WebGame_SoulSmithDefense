# 魂匠掠奪(搶敵人的魂件)

## 概述
敵人從四面八方走向中央主堡, 主堡不賣任何魂件, 魂件只能從敵人身上來——玩家可以貼身從**活著的敵人**身上硬拆魂件(邊拆邊挨打), 拆掉攻擊它就無害、拆掉「進攻主堡」它就停下; 搶來的魂件裝到自己的塔上, 越打越把敵人的力量變成自己的。
驗證假設: H01、H02、H03、H04、H05、H10、H17、H18、H19、H20、H21、H22。

## 核心循環
敵人逼近 → 衝上去貼身按住拆魂件(挨打、血量下降)→ 敵人變弱或停下, 魂件進背包 → 裝到塔上讓塔變強 → 塔打死敵人噴金幣、留屍體 → 撿錢、再拆屍體 → 回主堡回血、買塔殼 → 下一波敵人帶更多、更稀有的魂件, 再去搶。
想再做一次的理由: 菁英敵人身上的魂件特別好, 想冒險去搶; 塔被自己堆得越來越強。

## 規則
### 地圖
1. 畫面 1280×720, 上方 0~50 為 HUD。開闊平地, 沒有路線。
2. 主堡中心 (640,385), 半徑 56; 主堡中心 150 內為「主堡區」(回血)。
3. 主堡下方三個商店台(56×56), 編號從 0 起算: 0 (530,490) 塔殼、1 (640,520) 野狼、2 (750,490) 石像。

### 開局
4. 金幣 20, 主堡生命 20。
5. 主堡魂件 [遠攻], 槽位上限 3。
6. 箭塔兩座: (480,250)、(860,560), 魂件 [遠攻], 槽位上限 3。
7. 中立野狼兩隻: (180,140)、(1100,620), 魂件 [近戰], 槽位上限 2。中立石像一座: (1100,140), 無魂件, 槽位上限 3。
8. 玩家在 (640,470), 生命 100, 背包 3 格, 空。

### 魂件
9. 魂件六種(n = 同種數量, 同種只疊數值):
    - 遠攻: 每 1.0 秒對 200 內最近的敵對單位射投射物(速度 400), 傷害 8×n
    - 近戰: 每 0.8 秒對碰觸距離(半徑和 +12)內最近的敵對單位造成 12×n
    - 索敵: 240 內有敵對單位時朝它移動, 速度 min(70×n, 140), 直到進入攻擊距離(有遠攻: 180; 否則碰觸)
    - 進攻主堡: 直線走向主堡
    - 鐵壁: 受到的傷害 ×0.5ⁿ, 最低 ×0.25
    - 疾行: 移動速度 ×(1+0.6×n), 攻擊間隔 ×0.7ⁿ
10. 行為優先序: 攻擊範圍內有目標就原地攻擊 > 索敵 > 進攻主堡 > 不動。沒有攻擊魂件的單位不會攻擊; 沒有移動魂件的單位不會動。箭塔裝上索敵或進攻主堡就會走。

### 單位
11. 單位數值:
    - 箭塔: 生命 120, 槽位 3, 塔殼蓋出時 []
    - 野狼: 生命 80, 槽位 2, 購買時 [近戰]
    - 石像: 生命 300, 槽位 3, 購買時 []
    - 主堡: 槽位 3, 不受攻擊、不移動
    - 小鬼: 生命 30, 速度 45, [近戰, 進攻主堡], 掉 2 枚金幣, 抵達主堡扣 2
    - 弓鬼: 生命 24, 速度 40, [遠攻, 進攻主堡], 掉 2 枚金幣, 抵達主堡扣 2
    - 盾鬼: 生命 50, 速度 38, [近戰, 鐵壁, 進攻主堡], 掉 3 枚金幣, 抵達主堡扣 2
    - 疾鬼: 生命 35, 速度 45(疾行後 72), [近戰, 疾行, 進攻主堡], 掉 3 枚金幣, 抵達主堡扣 2
    - 魂王鬼(菁英): 生命 160, 速度 35, [遠攻, 鐵壁, 索敵, 進攻主堡], 槽位 4, 掉 8 枚金幣, 抵達主堡扣 6
12. 敵人的敵對單位 = 我方箭塔、野狼、石像**與玩家**; 不攻擊主堡、中立單位。我方單位的敵對單位 = 敵人。
13. 中立單位不受攻擊也不攻擊, 只對進攻主堡有反應: 裝上後直線走向主堡(速度 45)。走進主堡(中心進入半徑 +10): 消失, 身上魂件掉在 (640,460) 成為地上魂件, 對應商店台解鎖(野狼 → 台 1、石像 → 台 2)。
14. 敵人中心進入主堡半徑 +10: 主堡扣血, 敵人消失, 不留屍體、不掉金幣。我方單位裝進攻主堡: 走到主堡邊緣停下。
15. 單位死亡變成屍體, 保留魂件, 12 秒後消失。敵人死亡另在 40 內噴金幣, 每枚 2 金; 金幣 15 秒後消失, 最後 3 秒閃爍; 玩家中心距 34 內自動撿起。
16. 地上魂件不會消失; 玩家走到中心距 34 內且背包有空格時自動撿進背包。

### 玩家
17. 移動速度 230, 生命 100, 會被敵人攻擊; 在主堡區內每秒回 10 生命。
18. 生命歸 0: 倒下, 4 秒後在 (640,470) 滿血復活; 背包內容保留; 倒下期間不能操作。
19. 玩家本身不會攻擊。
20. 互動目標 = 距離最近、且中心距 ≤ 目標半邊長 +44 的單位或屍體(敵人、我方、中立、主堡、屍體皆可)。
21. 目標有魂件時有一格被選中; 換目標時預設選第一個有魂件的格子。按 K 換到下一個有魂件的格子。
22. 按住 J: 把目標選中那格的魂件拆進背包第一個空格, 原單位立即失去它。
    - 目標是活著的敵人: 需按住 0.8 秒, 期間玩家**可以移動**, 目標離開互動距離則進度歸零
    - 其他目標: 需按住 0.3 秒
    - 背包滿時無法開始; 放開 J 進度歸零
23. 站在商店台上(玩家中心距台中心 ≤ 30)時, 按 J 改為購買該台品項(金幣不足或未解鎖無效):
    - 台 0 塔殼 10 金: 放進背包(背包滿則無效)
    - 台 1 野狼 12 金、台 2 石像 14 金: 在台的正下方 50 處出現, 立即依魂件行動
24. 按 Q: 背包選中格依序換到下一格(0→1→2→0)。
25. 按 L: 使用背包選中格的東西:
    - 魂件: 立即裝進目標的第一個空格(任何活著的單位皆可, 含敵人; 屍體不行); 沒有目標或目標滿則無效
    - 塔殼: 在玩家腳下立即蓋出空箭塔; 距其他箭塔、主堡中心、商店台中心都要 > 60, 否則無效
26. 沒有任何攻擊魂件、也沒有進攻主堡與索敵的敵人視為「已無害」, 不擋勝利條件。

### 波次
27. 說明頁關閉後開始計時。第 k 波在 10 + (k−1)×24 秒開始; 開始前 3 秒在該波用到的每個邊緣出現預警。
28. 每個邊緣每 1.0 秒出一隻, 出生點在該邊緣上隨機: 北 y=60(x 100~1180)、南 y=710(x 100~1180)、西 x=10(y 80~700)、東 x=1270(y 80~700)。
    - 第 1 波: 北 小鬼×5
    - 第 2 波: 東 小鬼×2、弓鬼×2; 西 小鬼×2、弓鬼×1
    - 第 3 波: 北 盾鬼×2; 南 盾鬼×2; 東 疾鬼×2; 西 疾鬼×1
    - 第 4 波: 南 小鬼×6; 北 魂王鬼×1
    - 第 5 波: 北 盾鬼×2、弓鬼×2; 南 盾鬼×2、弓鬼×2; 東 疾鬼×2; 西 疾鬼×1
    - 第 6 波: 東 魂王鬼×1、疾鬼×2; 西 魂王鬼×1、疾鬼×2; 北 盾鬼×2; 南 盾鬼×2

## 操作
只用鍵盤。
| 按鍵 | 動作 |
|---|---|
| W A S D | 移動 |
| 按住 J | 拆下目標選中那格的魂件(活的敵人也行) |
| J | 站在商店台上時購買 |
| K | 換選目標身上的下一格魂件 |
| Q | 換選背包的下一格 |
| L | 把背包選中的魂件裝到目標上 / 把塔殼蓋在腳下 |
| J | 說明頁翻頁, 最後一頁再按開始遊戲 |
| Enter | 結算畫面重新開始 |
說明頁關閉時要等 J 放開後才接受按住 J 的動作。

## 勝負與結束
- 勝利: 第 6 波全部出完, 且場上沒有「未無害」的活著敵人(已無害的敵人在勝利時一併消失)。
- 失敗: 主堡生命 ≤ 0。
- 結算畫面顯示勝負, 按 Enter 從開局重新開始(不再顯示說明頁)。

## 範圍邊界
- 不做: 大地圖、星星、多關卡、跨關解鎖、特殊事件點、音效、難度曲線
- 不做魂件組合效果、不做擴槽、不做賣出
- 主堡不賣魂件
- 玩家不會攻擊
