## 形狀語言

扁平幾何、深色描邊、無漸層(光暈例外); **尖角只屬於敵人**(犄角), 我方與中立一律圓頭(狼耳是圓的); 每個單位腳下有陣營底座: 實心藍 = 我方、暗紅 = 敵人、土色虛線 = 中立。

## 理念落實

- P0 辨識度先於好看: 三陣營用「底座顏色 + 輪廓語言(敵人有尖角)」兩條通道分開; 地面刻意低對比, 只當底。
- P1 視覺權重跟著決策迫切度: 最亮的是檸檬黃「你指著的」(目標外框、選中格)與玩家白色本體; 背景與主堡區圈最弱, 主堡區只在玩家站進去時變明顯。
- P2 規則上存在的東西必須可見: 已無害敵人有獨立外觀(褪色 + 虛線 + 角下垂 + 閉眼); 中立單位不畫血條但有虛線底座; 商店台三態(可買 / 錢不夠 / 鎖住)各自不同; 空槽畫虛線格, 槽位上限全部畫出。
- P3 一個意義一種長相: 魂件圖示全畫面同一套; 檸檬黃只代表「你目前指著 / 選著」; 藍只代表我方; 尖角只代表敵人; 說明頁直接呼叫遊戲內畫法。
- P4 關鍵區分走兩條通道: 敵 / 我 / 中立 = 顏色 + 輪廓(尖角、虛線); 我方 / 敵方投射物 = 顏色 + 形狀(有方向的細箭 vs 圓火球); 魂件 = 形狀 + 顏色; 已無害 = 褪色 + 虛線輪廓 + 姿態。
- P7 每個元素都要掙得版面: 血條只在受傷時出現(玩家除外); 地上魂件、商店台不加多餘標籤; 說明頁每頁只畫該頁要教的東西。
- P9 以最混亂的一刻驗收: 槽列一律墊深色底板, 壓在任何單位或地面上都讀得到; 選中格同時用框、底色、外光三層。
- P13 事件要排隊: 本作事件回饋只有擊中火花(0.25 秒、24px)與主堡閃色, 都長在物件身上, 不另開事件字幕。
- P15 回饋強度與份量成正比: 單位受擊只閃白(小); 主堡被突破整座閃紅(大, 扣主堡生命); 拆活敵人的連線越接近完成越粗越亮。
- P17 進度圖形與數字分工: 按住進度只用環(沒有數字, 環畫總進度); 邊緣預警帶寫剩餘秒數, 帶本身只負責閃與指向; HUD 下一波倒數只用數字, ≤ 3 秒轉紅。
- P18 重要資訊不能只閃一瞬: 拆下的魂件直接進背包常駐格; 結算畫面留存波次。
- P19 資訊貼著物件: 血條、槽列貼在單位頭上; 商店台品名價格貼在台下; 拆魂連線直接連到被拆那一格。
- P21 示意圖選分岔例子: 第 3 頁左右對照拆前 / 拆後, 右格小鬼還留著「進攻主堡」並照樣在走, 讓玩家看出「拆掉的是那一格, 不是整隻敵人」。

## 繪製層級(照 interface.json drawOrder)

drawBackground → drawShopPad → drawCoin → drawGroundPart → drawCorpse → 單位(drawCastle / drawTower / drawWolf / drawStatue / drawEnemy, 依 y 由小到大) → drawSoulSlots → drawRipBeam → drawPlayer → drawProjectile → drawHitSpark → drawEdgeWarning → drawBag → drawHud → drawResult。說明頁期間只畫 RD 的頁面 + drawGuidePage。

## 判讀約定

- 計時欄位 `xxxAge / xxxDuration`: `0 ≤ Age < Duration` 才播, 其他值(含閒置的 Age = Duration、負值、NaN)一律當作沒在播。
- `drawEdgeWarning` 只讀 `remaining`(顯示 ceil 後的秒數, 剩 < 1 秒閃得更快); `total` 刻意不用(帶子不畫總進度, 倒數交給數字)。
- 表外值的預設外觀(看到這些外觀請回頭查傳入值): 未知敵人 `type` → 小鬼; 未知屍體 `kind` → 小鬼屍; 未知 `team` → 中立; 未知 `edge` → 北; 未知商店 `state` → 鎖住; 未知 `index` → 塔殼台圖示; 未知魂件字串 → 空格; 未知 `projectile.team` → 敵方火球; `page` 超出 0~5 → 第 0 頁。
- 單位(箭塔 / 野狼 / 石像 / 敵人)的攻擊動作是往上彈 3px, 尖角可能因此超出判定框上緣 ≤ 3px(介面允許 ≤ 4px)。
- 互動目標外框: 框外、寬 3, 內緣離判定框 1px。

## 畫面文字歸屬

除說明頁外, 畫面上所有文字由美術畫(照 interface.json textOwnership): 商店台品名價格 / 「未解鎖」、HUD 全部、「倒下了 N」、邊緣預警秒數、結算畫面(標題、「第 w / 6 波」、「按 Enter 重新開始」)。**RD 不要再畫這些字。**

說明頁例外: `drawGuidePage` 只畫示意圖, 只畫在 `(x, y, w, h)` 框內(會自己 clip); **頁標題、說明文字、頁碼、翻頁提示由 RD 畫**。示意圖內只有物件旁的短標籤與鍵帽。
