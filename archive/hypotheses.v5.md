# 玩法驗證文件

## 核心玩法(使用者指定, 每款都必須有)
- 2D 俯視角守塔: 怪物分多個波次持續進攻主堡, 最後一波結束且敵人全滅即勝利
- 玩家操控一個角色在地圖上走動
- 從主堡購買物件, 分「靜態單位」與「移動單位」兩類, 兩類的放置方式不同
- 可以取下任何單位身上的魂件(敵方屍體、我方單位、中立單位、防禦塔、主堡), 在不同單位間安裝、組合, 改變單位的行為(例: 塔裝上索敵與近戰會走路追敵)
- 每個單位有魂件槽位上限; 部分單位的上限可升級擴充
- 把敵人身上的「進攻主堡」裝到中立單位上, 中立單位會走向主堡, 進入主堡後可從主堡購買該單位
- 敵人被擊殺會噴金幣, 玩家要靠近才撿得到, 金幣用來在主堡購買
- 節奏緊湊不冷場, 考驗臨場反應
- (探索試玩不做: 大地圖、星星評價、關卡解鎖、跨關解鎖、特殊事件點)

## 已確認的體驗
### 想要
- 讓玩家在場上很忙, 在多處之間奔走調度(「讓玩家在場上很忙是我要的體驗沒錯」)
- 魂件直接在單位之間拆裝, 不經背包, 裝上即生效並馬上看到效果(「不用經過一層背包進出, 裝上去直接生效…我覺得很棒」)
- 魂件組合變出有名字的新技能, 裝上時跳出提示(「兩個進攻變成旋風斬, 我覺得超酷, 很喜歡」)
- 魂件統一從敵人(活敵人、屍體)身上取得, 商店不賣魂件(「大部分魂件都可以從敵人身上取得, 幾乎沒有成本」); 從敵人身上拆讀條較久是合理代價
- 波次預警, 讓玩家對接下來的進攻提早準備(使用者視為此類型必備)
- 選魂件時遊戲變慢動作, 給玩家思考時間; 慢動作的畫面表現要更明顯
- 選要拆哪個魂件時: 按鍵打開小彈窗, 在彈窗中用方向鍵選
- 屍體存在時間取中間值: 都不消失場面會亂、辨識度差, 太快消失又逼玩家趕過去
- 敵人走固定路線, 讓每關地圖有差異、能玩出不同策略
- 鍵盤配置: 方向鍵移動, 其他動作限縮在 Z、X、空白鍵, 最多 3 個按鍵(「以只使用最多3個按鍵為限制去設計」)
- 角色自己裝上魂件就有不同攻擊模式(「角色本身因為安裝魂件有不同攻擊模式的遊玩方式很有趣」); 條件: 操作不能在拿著狀態多開一層視窗, 打磨先拿掉角色裝備格, 找到不卡的操作再加回(「只是現在的操作太卡, 所以先拿掉」)
- 佈陣感: 自己規劃單位擺在哪, 佈局有彈性、發揮空間大(「我想要的是一種佈陣的感覺」)
- 玩家角色不會被攻擊(「我喜歡角色不會被攻擊的設定」)
- 魂柱共鳴讓擺放位置更有策略性(「這3款之中我最喜歡魂柱共鳴的設計, 讓擺放位置多了更多策略性」)
- 推線的移動模式由魂件賦予(行軍魂件「我覺得不錯」), 衝刺要有衝撞感: 把怪撞開 + 暈眩
- 自己組裝出強力組合的成就感(反面: 「平白得到強力道具的感覺反而沒有自己組裝的成就感」)
- 拿著魂件時一鍵處理: 鄰近單位就直接裝上(有空格不選格, 裝滿才讓玩家選替換哪格), 否則丟下
- 拔活敵人魂件要即時: 一鍵拔隨機魂件, 仍讀條, 讀條中敵人緩速
- 移動單位放下後固守原地, 留在魂柱範圍內、受玩家控制(「放下去之後就不要亂動了, 就是固守在原地就好」)
- 按鍵提示畫成按鍵外觀, 一眼認出是哪個鍵(「Z互動的Z是指按鍵Z」玩家無法一眼認出)
- 選魂件時有簡單說明告知效果(「魂件一多, 只靠圖示會不知道每個魂件的效果是什麼」)
- 中立單位有標籤, 一眼認出是中立
- 單位倒下等待重生時, 主堡上看得到重生倒數與排隊人數
- 波次開始的音效像戰鼓或號角
### 不要
- 拆裝我方或中立單位要讀條(忙碌又頻繁拆裝時「會讓人有點焦急」)
- 背包中轉魂件, 按鍵變多、操作複雜卡頓
- 用按鍵逐格切換要拆的魂件(「有點卡」)
- 滑鼠操作(本作; 「這個遊戲機制我覺得比較適合鍵盤玩」)
- 好不容易組好的單位(步兵或塔)很容易被圍攻打死, 白忙一場
- 金幣限時消失, 逼玩家在忙碌中趕去撿
- 敵人從四面八方進攻、沒有固定路線
- 魂件先進角色身上再拿出去裝到別的單位(「多一層手續會讓整個玩家體驗很卡」)
- 單位跟著角色移動(「我不喜歡守衛跟著角色移動」)
- 靜態單位只能蓋在指定地點(「布局彈性變的很差, 可玩性被限縮」)
- 角色會被攻擊、倒下有懲罰(暫停活動或回主堡重生都一樣), 「難以控制局面的無力感」
- 拿著狀態下還要多開一層視窗(裝備格 + 丟下)(「就還是覺得很卡」)
- 拔活敵人要靠近 + 選擇 + 讀條(「敵人早就走掉了, 很不即時」)
- 系統平白送組合魂件(「地上多了一堆東西我也沒時間去撿」「沒有自己組裝的成就感」)
- 塞魂件讓敵人倒戈的魂亂(「太無腦了, 一直隨便拿東西裝在敵人身上就贏了」)
- 陣紋與魂柱兩套佈陣機制並存(「兩者我覺得擇一就好」)
- 移動單位自己巡邏, 跑出魂柱範圍外「很不受控」
- 單件道具太強(OP): 魂柱不限數量、擴槽石
- 畫面太花: 魂柱放太多、地上堆滿魂件
- 地上的魂件囤成「隨時可取用的軍火庫, 讓遊戲變得太簡單」
- 商店賣魂件(「有點多餘…花錢買魂件很浪費錢」)
- HUD 顯示對玩家沒幫助的資訊(組合區塊「只是一連串意義不明的符號」)
- 衝鋒衝到路線底就卡住(「感覺很像bug」)

## 機制清單
### 保留
- H01 魂件可在任何單位間拆裝調度
- H04 敵人分波次進攻, 玩家親自走動調度(場上要忙)
- H08 波次開始前預警
- H11 兩件魂件組合成有名字的新技能, 裝上時跳提示
- H23 魂件直接在單位間拆裝、裝上即生效且效果立即可見
- H29 開魂件選單時慢動作(畫面表現要明顯)
- H30 可從活著的敵人身上拆魂件(條件: 敵人魂件取得成本極低, 由商店之外的額外來源改為唯一來源)
- H31 從活敵人身上拆要讀條, 且比其他目標久
- H14 玩家角色自己有魂件槽, 裝上就有對應攻擊方式(條件: 不能在拿著狀態多開一層視窗; 打磨暫不做)
- H42 靜態單位可蓋在路旁任意空格
- H51 玩家角色不會被攻擊
- H54 推線的移動模式由魂件賦予, 不是單位天生
- H65 魂柱: 身上魂件共鳴給範圍內我方單位配組(條件: 魂柱數量有上限, 見 H80)
- H68 行軍魂件: 移動單位裝上沿路線逆推, 搭近戰成衝鋒
### 避開
- H07 拆裝我方 / 中立單位要站定讀條
- H21 敵人從四面八方進攻、無固定路線
- H24 背包作為魂件中轉
- H25 用按鍵逐格切換選中的魂件
- H26 滑鼠操作(本作)
- H27 組好的單位容易被敵人圍攻打死、魂件投資歸零
- H28 金幣限時消失
- H22、H36 玩家角色會被攻擊、倒下有懲罰
- H48 魂件先進角色身上再拿出裝到別的單位(兩段式搬運)
- H49 移動單位當跟班跟著角色走
- H50 靜態單位只能蓋在固定塔位
- H70 拿著魂件時要再開一層視窗(選裝備格 / 丟下格)
- H72 拔活敵人要靠近 + 開彈窗選格 + 讀條, 敵人不緩速
- H75 系統平白送組合魂件(每波送到地上)
- H77 把魂件塞進活敵人讓它倒戈(魂亂)
- H79 移動單位放下後自行巡邏
- H80 魂柱可無限購買
- H81 商店賣擴槽石
- H82 商店賣魂件
- H83 地上的魂件永不消失
- H84 衝鋒衝到路線底停在出怪點
