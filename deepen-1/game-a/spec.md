# 魂匠陣紋(陣紋連線: 同種魂件靠近就連成一道防線)

## 概述
路旁任何空格都能蓋塔, 而兩個靜態單位(箭塔、魂碑、主堡)只要距離夠近、身上帶著同一種魂件, 就會自動連成一條發光的「陣紋」——敵人碰到陣紋就會被射、被斬或被凍住。玩家自己身上的魂件也算陣紋的一端, 走到哪就把陣紋拖到哪。擺位本身就是火力: 換一件魂件、多蓋一塊便宜的魂碑, 整片防線的形狀就跟著變。同一個單位上湊成組合的兩件魂件會當場合成一件組合魂件, 發現過的組合魂件之後可以直接在主堡買到。
驗證假設: H03、H32、H33、H40、H41、H52、H53、H54、H55、H56、H57、H58、H59、H69。

## 核心循環
看到預警 → 想好陣紋要拉在哪段路上 → 從塔、屍體、活敵人身上拿魂件, 裝到路旁的塔或魂碑上(或裝在自己身上)→ 同種魂件的兩端連成陣紋, 跳出陣紋名稱 → 敵人走過陣紋被削血、留下帶魂件的屍體、噴金幣 → 撿錢買魂碑、塔、魂件, 把陣紋網拉得更密 → 下一波換一段路重拉。
想再做一次的理由: 同一組魂件換個擺法就是完全不同的防線; 自己衝進敵群旁邊拖著陣紋掃過去很爽。

## 規則
### 地圖
1. 畫面 1280×720, 上方 0~50 為 HUD, 遊戲區 y 50~720。
2. 敵人路線寬 56, 中線依序連接: (0,146) → (960,146) → (960,434) → (336,434) → (336,626) → 主堡 (1180,626)。
3. 主堡中心 (1180,626), 半徑 56。主堡中心 110 內是「主堡區」(購買用)。
4. 出怪點 (10,146)。
5. 蓋塔格: 遊戲區切成 48×48 的格子, 第 i 欄第 j 列(都從 0 起算)的格子中心 = (24+48i, 74+48j), i = 0~26, j = 0~13。路線中線都落在格線上, 所以緊貼路邊的可蓋格子中心離中線 72。

### 開局
6. 金幣 40, 主堡生命 20。
7. 箭塔兩座: (408,218)、(600,218), 魂件 [遠攻], 槽位上限 2。兩座相距 192, 開局就連著一條箭紋。
8. 魂碑一塊: (888,74), 魂件 [冰霜]。
9. 主堡魂件 [遠攻, 近戰], 槽位上限 3。
10. 中立野狼兩隻, 家在 (168,314)、(696,530), 無魂件, 槽位上限 2。
11. 玩家在 (1060,530), 身上 [近戰, 空, 空], 手上空。

### 魂件
12. 基本魂件五種: 遠攻、近戰、冰霜、索敵、進攻主堡。另有組合魂件五種(規則 14)與擴槽石(不是魂件, 只用來擴槽)。
13. 單件效果(n = 這個單位身上同種基本魂件的件數):
    - 遠攻: 每 1.0 秒對射程 200 內最近的敵人射投射物(速度 420), 傷害 10×n
    - 近戰: 每 0.8 秒對碰觸距離(兩者半邊長和 +12)內最近的敵人造成 14×n 傷害
    - 冰霜: 自身中心 70 內的敵人移動速度 −30%
    - 索敵: 離「據點」200 內有敵人時朝它移動, 速度 min(70×n, 140), 直到進入攻擊距離(身上有遠攻、穿透箭或冰箭: 180; 否則碰觸); 範圍內沒有敵人就以速度 80 走回據點
    - 進攻主堡: 直線走到主堡邊緣停下, 據點改成停下的位置
14. 合成: 我方單位(箭塔、魂碑、步兵、野狼)、主堡、玩家身上, 只要有兩件基本魂件符合下表, 就**立即合成**為一件組合魂件: 放進兩件中較前面的那一格, 另一格變空; 依表的順序由上往下檢查, 一直合到沒有可合的為止。組合魂件不能再拆回兩件, 可以像一般魂件一樣拆下、搬運、裝到別處。中立單位、屍體、敵人、地上的魂件不會合成。
    | 順序 | 組合魂件 | 由哪兩件合成 | 效果 |
    |---|---|---|---|
    | 0 | 穿透箭 | 遠攻 + 遠攻 | 每 1.0 秒朝射程 260 內最近的敵人射出一道直線, 線上(距線 14 內)每個敵人受 14 傷害 |
    | 1 | 冰箭 | 遠攻 + 冰霜 | 每 1.0 秒對射程 200 內最近的敵人射投射物, 10 傷害並減速 50% 持續 2 秒 |
    | 2 | 旋風斬 | 近戰 + 近戰 | 每 0.8 秒對自身中心 60 內所有敵人造成 16 傷害 |
    | 3 | 冰霜重擊 | 近戰 + 冰霜 | 每 0.8 秒對碰觸距離內最近的敵人造成 16 傷害, 並使它與它身邊 60 內的敵人減速 50% 持續 2 秒 |
    | 4 | 逆襲 | 索敵 + 進攻主堡 | 帶著它的單位離開據點, 沿敵人路線**逆向**走向出怪點(速度 60); 任一攻擊效果範圍內有敵人時停下攻擊, 打完繼續走; 走到出怪點就停在那裡。玩家身上的逆襲沒有效果 |
15. 合成發生時, 該單位頭上跳出「合成! <名稱>」1.5 秒; 這種組合是本局第一次合成時改跳「新組合! <名稱>」, 並在主堡商店上架這種組合魂件(規則 37)。
16. 一個單位身上有多件同種組合魂件時, 各自獨立發動(各自計冷卻)。
17. 減速不疊加, 同時中多個取最大的一個。每個攻擊效果各自計冷卻、各自找目標。行為優先序: 任一攻擊效果範圍內有目標 → 原地攻擊; 否則依序: 逆襲 > 索敵 > 進攻主堡 > 該單位的預設移動(規則 27)> 不動。箭塔裝上會移動的魂件也會走, 它的蓋塔格保留給它。

### 陣紋
18. 陣紋端點: 箭塔、魂碑、主堡、玩家。兩個端點中心距 ≤ 200, 且兩邊身上都帶著同一種「紋種」, 就自動連成一條陣紋(兩端中心之間的線段)。每一對端點最多一條陣紋, 兩邊共有多種紋種時依 冰霜 > 近戰 > 遠攻 的順序取第一種。玩家只算身上的魂件, 手上拿著的不算。
19. 紋種: 遠攻、穿透箭、冰箭算「遠攻」; 近戰、旋風斬、冰霜重擊算「近戰」; 冰霜、冰箭、冰霜重擊算「冰霜」。索敵、進攻主堡、逆襲不算紋種。
20. 陣紋效果, 作用於「碰到陣紋」的敵人(敵人中心到線段的距離 ≤ 80):
    | 紋種 | 名稱 | 效果 |
    |---|---|---|
    | 冰霜 | 霜紋 | 碰到的敵人減速 50%, 離開後再維持 0.3 秒 |
    | 近戰 | 刃紋 | 每 0.8 秒, 碰到的每個敵人受 12 傷害 |
    | 遠攻 | 箭紋 | 每 0.5 秒, 碰到的每個敵人受 6 傷害 |
    每條陣紋各自計時, 多條陣紋重疊時效果都算(減速仍取最大)。陣紋只打敵人, 不擋路、不擋玩家。
21. 陣紋出現的當下, 線段中點跳出陣紋名稱 1.2 秒; 這種陣紋是本局第一次出現時改跳「新陣紋! <名稱>」。有一端是玩家的陣紋只在本局第一次出現時跳(因為玩家走動時會頻繁連上、斷開)。
22. 兩端距離超過 200、或任一端不再帶共有紋種、或一端消失時, 陣紋立即消失; 之後再滿足條件就重新連上。端點移動時陣紋跟著移動。

### 單位
23. 我方單位沒有生命、不會被攻擊。
    | 單位 | 槽位上限 | 半邊長 | 購買時的魂件 | 可擴槽 | 放置方式 |
    |---|---|---|---|---|---|
    | 箭塔(靜態) | 2 | 24 | [] | 是, 最多 4 | 蓋在玩家所站的蓋塔格 |
    | 魂碑(靜態) | 1 | 16 | [] | 否 | 蓋在玩家所站的蓋塔格 |
    | 步兵(移動) | 2 | 16 | [近戰] | 否 | 放在玩家腳下 |
    | 野狼(移動) | 2 | 18 | [近戰] | 否 | 放在玩家腳下 |
    | 主堡 | 3 | 56 | | 是, 最多 4 | |
24. 魂碑本身不攻擊、不移動: 身上的魂件只用來當陣紋的紋種, 不發動任何單件或組合效果(冰霜也不產生減速範圍), 但仍會合成。
25. 單位放下的位置是它的「據點」。
26. 靜態單位的合法位置: 玩家所站的蓋塔格(欄 = ⌊x/48⌋, 列 = ⌊(y−50)/48⌋)在範圍內、格子中心離任何路線中線 ≥ 52、離主堡中心 ≥ 90、格子上沒有其他靜態單位。移動單位的合法位置: 玩家中心離主堡中心 ≥ 90。
27. 移動單位的預設移動「巡邏」: 放下時取路線中線上離據點最近的點當巡邏中心, 先直線走到巡邏中心, 之後沿路線在巡邏中心前後各 120(沿路線量)之間來回走; 步兵速度 50、野狼速度 90。

29. 敵人數值(槽位上限 = 魂件數):
    | 敵人 | 生命 | 速度 | 半邊長 | 魂件 | 掉金幣枚數 | 抵達主堡扣血 |
    |---|---|---|---|---|---|---|
    | 小鬼 | 40 | 45 | 16 | [近戰, 進攻主堡] | 1 | 2 |
    | 弓鬼 | 30 | 50 | 16 | [遠攻, 進攻主堡] | 2 | 2 |
    | 冰鬼 | 50 | 42 | 16 | [冰霜, 進攻主堡] | 2 | 2 |
    | 疾鬼 | 35 | 80 | 16 | [索敵, 進攻主堡] | 2 | 2 |
    | 霜甲鬼 | 120 | 34 | 22 | [近戰, 冰霜, 進攻主堡] | 4 | 3 |
30. 敵人失去進攻主堡就停在原地。
31. 敵人中心進入主堡半徑 +10 內: 主堡扣血, 敵人消失, 不留屍體、不掉金幣。
32. 敵人生命歸 0: 變成屍體, 保留全部魂件, 15 秒後連同魂件消失(最後 3 秒閃爍); 在 40 半徑內噴出金幣, 每枚 2 金。
33. 金幣不會消失。玩家中心距金幣 90 內時, 金幣以每秒 420 飛向玩家, 碰到玩家(距 20 內)就撿起。

### 中立單位與招募
34. 中立野狼在家附近閒逛: 每 2 秒在家中心 110 內隨機挑一點, 以速度 50 走過去(會走上路線, 不受攻擊、不擋路)。身上的魂件除了進攻主堡都沒有效果, 也不會合成。
35. 中立單位裝上進攻主堡: 停止閒逛, 直線走向主堡(速度 60)。中心進入主堡半徑 +10 內: 它消失, 身上的魂件依序掉在 (1100+32×k, 540)(k 從 0 起算)成為地上的魂件, 主堡商店解鎖野狼。

### 玩家
36. 玩家移動速度 260, 不會被攻擊、不擋路。
    - 身上 3 格魂件槽(不可擴充): 身上的魂件照規則 13、14 生效(會射擊、會斬、會合成), 索敵、進攻主堡、逆襲沒有效果; 身上的魂件也是陣紋端點
    - 手上最多「拿著」1 樣東西: 一件魂件、擴槽石、或一份單位材料。拿著的魂件不生效、不算陣紋, 不會自動進到身上
    - 互動目標 = 中心距 ≤ 目標半邊長 +48 的可互動物中最近的一個: 我方單位、中立單位、主堡、屍體、地上的魂件、活著的敵人
37. 商店: 在主堡區內、沒開任何彈窗時按空白鍵, 打開「商店彈窗」(慢動作同規則 41)。兩排:
    - 第 0 排 8 項(從 0 起算): 箭塔 15、魂碑 6、步兵 12、遠攻 8、近戰 8、冰霜 12、擴槽石 20、野狼 14(招募過野狼才解鎖)
    - 第 1 排 5 項, 依規則 14 的順序: 穿透箭、冰箭、旋風斬、冰霜重擊、逆襲, 各 24; 本局合成過才上架, 沒上架的顯示 ???
    - 開啟時游標在第 0 排第 0 項; ← → 在同一排移動(頭尾循環), ↑ ↓ 換排(索引超過該排長度時取最後一項)
    - 按 Z 購買: 金幣足夠、已解鎖 / 已上架、手上是空的 → 扣錢, 東西進到手上, 彈窗關閉; 否則無效(彈窗抖一下, 底部提示「金幣不足」「尚未解鎖」或「手上要空著」)
    - 按 X 關閉
38. 沒開彈窗時按 Z, 依序判斷第一個成立的:
    1. 手上是單位材料 → 在合法位置放置(規則 26), 不合法則無效。拿著材料時畫面顯示放置預覽(合法 / 不合法); 靜態單位的預覽畫在格子中心
    2. 互動目標是地上的魂件 → 手空: 撿起; 手上有魂件或擴槽石: 互換。不開彈窗
    3. 有其他互動目標 → 打開「魂件彈窗」(規則 39)
    4. 都沒有 → 無效
39. 魂件彈窗: 顯示目標的魂件槽(長度 = 槽位上限)和玩家手上的東西。
    - 開啟時游標: 手空 → 第一個有魂件的格子; 手上有魂件 → 第一個空格; 沒有這種格子 → 第 0 格
    - ← → 移動游標(頭尾循環)
    - 按 Z 依游標格執行, 成功後彈窗關閉:
      | 手上 | 游標格 | 目標 | 結果 |
      |---|---|---|---|
      | 空 | 有魂件 | 我方 / 中立 / 主堡 / 屍體 | 立即拿到手上 |
      | 空 | 有魂件 | 活敵人 | 開始搶奪(規則 42), 彈窗關閉 |
      | 魂件 | 空格 | 我方 / 中立 / 主堡 | 立即裝上(可能立即合成) |
      | 魂件 | 有魂件 | 我方 / 中立 / 主堡 | 立即互換: 手上的進格子, 格子的到手上(可能立即合成) |
      | 擴槽石 | 任一格 | 可擴槽且上限 < 4 的目標 | 槽位上限 +1, 擴槽石用掉 |
      | 其他情況 | | | 無效, 彈窗抖一下、不關 |
    - 按 X 關閉
    - 目標消失或目標中心離玩家超過「目標半邊長 +68」時彈窗自動關閉
40. 沒開彈窗時按 X: 打開「自身彈窗」, 顯示玩家身上 3 格 + 第 3 格之後的「丟下」格, 以及手上的東西:
    - 開啟時游標: 手空 → 第一個有魂件的身上格; 手上有魂件 → 第一個空的身上格; 沒有這種格子 → 第 0 格
    - ← → 在 4 格間移動(頭尾循環)
    - 按 Z: 身上格照規則 39 我方單位那幾列(拿下 / 裝上 / 互換, 擴槽石無效); 「丟下」格: 手上是魂件或擴槽石 → 丟在腳下成為地上的魂件(不會消失), 手空或手上是單位材料 → 無效。成功後彈窗關閉
    - 按 X 關閉
41. 任何彈窗(魂件 / 自身 / 商店)開著時, 遊戲時間變成 0.2 倍(慢動作), 玩家不能移動。
42. 搶奪: 遊戲恢復正常速度, 1.5 秒後那一格的魂件從敵人身上移到玩家手上, 敵人立即失去它。搶奪中玩家可以移動; 敵人中心離玩家超過「敵人半邊長 +68」、敵人死亡或再按 Z 時取消, 沒有任何損失。搶奪中按 Z 只做取消。

### 波次
43. 說明頁關閉後開始計時。第 k 波在 12 + (k−1)×26 秒開始; 開始前 6 秒出怪點出現預警。
44. 每 1.2 秒出一隻, 依下表順序:
    - 第 1 波: 小鬼×6
    - 第 2 波: 小鬼×4、弓鬼×3
    - 第 3 波: 疾鬼×5、小鬼×3
    - 第 4 波: 冰鬼×4、霜甲鬼×2
    - 第 5 波: 疾鬼×4、霜甲鬼×2、弓鬼×3
    - 第 6 波: 小鬼×5、疾鬼×4、霜甲鬼×3、冰鬼×3

## 操作
只用鍵盤: 方向鍵 + Z、X、空白鍵。
| 按鍵 | 動作 |
|---|---|
| ← → ↑ ↓ | 移動(彈窗開著時改為移動游標) |
| Z | 對互動目標打開魂件彈窗 / 撿起或互換地上的魂件 / 拿著單位材料時放置 |
| Z(彈窗中) | 對游標格執行: 拿、裝、互換、擴槽、搶奪、丟下、購買 |
| Z(搶奪中) | 取消搶奪 |
| X | 打開自身彈窗(把身上的魂件拿下來、或把手上的裝到身上、或丟下) |
| X(彈窗中) | 關閉彈窗 |
| 空白鍵 | 在主堡區打開商店 |
| Z | 說明頁翻頁, 最後一頁再按開始遊戲 |
| Z | 結算畫面重新開始 |
說明頁關閉後要等 Z 放開才接受遊戲內的 Z。

## 勝負與結束
- 勝利: 第 6 波全部出完且場上沒有活著的敵人。
- 失敗: 主堡生命 ≤ 0。
