五種基本魂件色相兩兩 ≥ 59°, 且每種另有專屬圖形(箭 / 劍 / 雪花 / 眼 / 城垛), 色相 + 形狀兩條通道。

張力(請製作人驗收):
- 霜紋(#4da3ff 地面淡帶 + 雙線冰晶)與減速中(#bff0ff 染在鬼身上)同屬冰藍色系: 介面要霜紋讓人聯想冰霜, 又不能撞減速色。分法 = 明度差大(中藍 vs 近白冰色)+ 類別不同(地面長條 vs 敵人本體色調)。最難分的一幀: 減速中的鬼站在霜紋帶裡。
- 受擊閃白與互動目標外框都用白: 受擊是整隻身體 0.2 秒變白, 外框是框外一圈白線, 形狀不同; 受擊與減速同時發生時, 受擊優先, 減速改成身體下緣一條冰色細線。
- 金幣(#ffbf2e 圓幣)與遠攻(#f2c230 方塊 + 箭)色相相近: 金幣是地上的小圓幣、魂件一律是方塊圖示, 類別層分開。

## 形狀語言

扁平幾何 + 深色描邊; 魂件一律「圓角方塊 + 白色圖形」, 組合魂件 = 兩色斜切 + 金鑲邊 + 四角小菱; 我方是暖石 / 木質 + 青色記號, 敵人是深紫黑的鬼形(圓頂、波浪下緣)+ 紅眼; 玩家是全場唯一帶白描邊的青色角色。

## 理念落實

- P0 辨識度先於好看: 我方 / 敵方 / 中立 / 玩家各一套類別長相(青記號 / 紅眼鬼形 / 灰無記號 / 白描邊青袍), 先分類別再談屬性色。
- P1 視覺權重跟著決策迫切度走: 陣紋判定帶只有約 10% 不透明的淡色 + 虛線外緣, 壓在單位之下; 彈窗游標是彈窗裡唯一的白粗框 + 外光。
- P2 規則上存在的東西畫面上就存在: 陣紋判定帶外緣 = reach, 冰霜範圍外緣 = radius, 屍體剩餘時間畫成框內底部細條(最後 3 秒變紅並閃爍), 被拔掉進攻主堡的鬼頭上有問號。
- P3 一個意義一種長相: 魂件圖示全畫面同一個畫法(槽列、地上、手上、彈窗、商店); 金色鑲邊只代表「組合魂件」, 名稱提示的組合類也用金邊; 陣紋類提示用膠囊底板 + 紋種色。
- P4 關鍵區分至少兩條通道: 魂件 = 色相 + 圖形; 三種陣紋 = 顏色 + 線型(霜紋雙線冰晶 / 刃紋鋸齒 / 箭紋直線羽標); 拿著 vs 裝著 = 位置(身體右側 vs 頭頂)+ 外觀(白底外光 + 一雙手 vs 深色槽列); 商店「還沒發現」= 紫色虛線框 + ???, 「買不起」= 整格變暗 + 紅價格。
- P7 每個元素都要掙得版面: 敵人血條只在受傷時畫; 主堡區的空白鍵鍵帽只在玩家站在區內時出現。
- P9 以最混亂的一刻驗收: 文字一律深色描邊; 互動目標外框白線內側再加一條深色細線, 壓在任何單位上都看得到。
- P13 事件要排隊: 名稱提示在「出現彈一下 → 上飄 → 淡出」內完成, 組合類在單位頭上、陣紋類在線段中點, 兩類的位置錯開(同時觸發時由 RD 傳的位置自然分開)。
- P15 回饋強度和份量成正比: 一般合成 / 陣紋 = 深底小牌; 本局第一次(新組合 / 新陣紋)= 實心亮底大牌 + 雙框; 陣紋的每跳傷害只讓線段變亮變粗, 不另放火花。
- P17 進度圖形與數字分工: 出怪預警中央是剩餘秒數, 外圈白環只畫「這一秒還剩多少」; 搶奪環畫 0~1 進度(沒有數字)。
- P18 重要資訊不能只存在一瞬間: 合成 / 陣紋名稱只閃 1.2~1.5 秒, 但組合魂件留在槽列圖示上(金邊)、商店第 1 排上架、結算畫面列出發現數。
- P19 資訊貼著物件: 槽列在單位頭上(RD 傳位置), 手上物品貼在玩家右手, 搶奪進度環繞著玩家本身。
- P21 示意圖選分岔例子: 說明第 6 頁並排「同種連線」與「不同種打叉不連」; 第 7 頁並排「路旁格可蓋」與「路上格不可」。

### 畫面文字歸屬

除說明頁外, 畫面上所有文字都由美術畫(照介面 textOwnership): 名稱提示、彈窗標題與「手上 / 丟下 / 動作提示 / Z 確定 X 關閉」、商店標題 / 品名 / 價格 / ??? / 「組合魂件」/ 底部訊息與操作提示、HUD 數值與右側操作提示、「慢動作」、結算全部文字、敵人呆站的問號、主堡區的空白鍵鍵帽。RD 不要另畫。

**說明頁例外**: 介面的文字歸屬是通則句、說明頁函式 state 只有圖框, 依任務單分工 — 美術只畫示意圖與物件旁短標籤(「出怪點」「主堡」「陣紋」「拿著」「屍體」「活鬼」「拿回」「丟下」「出手」「箭紋」「不同種」「你」「可蓋」「不可」「中立」「解鎖」「慢動作」)與鍵帽; 頁標題、說明文字、頁碼、翻頁提示歸 RD。

### 判讀約定

- 陣紋 reach 指判定帶**外緣**(線段到外緣的距離), 帶 = 距線段 [0, reach]。
- 主堡區、冰霜範圍、範圍斬擊、搶奪環的半徑都指**外緣**, 描邊往內畫。
- 魂件彈窗的 w、h 以傳入值為準; 傳入值小於「格數×48+120 / 116」時改用這個最小值(不讓格子溢出面板)。標題中心改在 (0, −43)、字級 14: 最窄 w=168 時照 (0, −40) 會和「手上」小字上下疊 3px。
- 名稱提示: 位移從 +4 飄到 −7, 彈跳最大 1.2 倍; 為了兩者疊加仍在 size 內, 底板高 = 20(一般)/ 30(新), 字級 14 / 18, 名字過長時自動縮字到 10。
- 主堡區的空白鍵鍵帽在主堡區圈的左上外側(中心相對主堡 (−92, −66)), 屬介面允許的「圈旁小圖示」。
