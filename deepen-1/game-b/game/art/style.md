# 魂匠惑亂 美術規格(deepen-1 / game-b)

> index.html 必須宣告 `<meta charset="utf-8">`, 否則 art.js 裡的中文在 file:// 下會變亂碼。
> 全部函式照 interface.json, 另加說明頁用的 `drawGuidePage`。RD 只需讀本檔。

## 1. 邏輯畫布尺寸

1280 × 720(`Art.canvas = { width: 1280, height: 720 }`)。HUD 佔 y 0~50, 遊戲區 y 50~720。

## 3. 形狀語言

扁平幾何 + 深色描邊; 能操作的角色與單位圓潤, 魂件一律「圓角方塊(擴槽石是六角)+ 白色圖示」, 組合魂件 = 雙色斜切 + 粗白邊。「陣營」靠色(藍我方 / 紅敵 / 紫魂亂 / 灰白中立)+ 輪廓(角、兜帽、冰冠、引信、塔、盾), 「攻擊歸屬」靠色 + 投射物外形(我方菱形箭、敵方圓彈)。

## 4. 理念落實

- **P0 辨識度先於好看**: 每種敵人一個縮圖就分得出的剪影(小鬼雙角圓身、弓鬼兜帽 + 弓、冰鬼冰冠、爆鬼圓桶 + 引信、巨鬼方身大角), 魂亂只換色與加記號、不換剪影, 玩家認得「這是哪種鬼」也認得「牠倒戈了」。
- **P1 視覺權重跟著決策迫切度走**: 黃色只給「現在按 Z 會作用在誰 / 哪一格」(互動目標框、游標), 全畫面沒有其他黃色; 草地、格線、主堡區(未進入時)壓到最低。
- **P2 規則上存在的東西, 畫面上就必須存在**: 敵人身上的空槽畫成亮虛線框 + 淡「+」(那就是可以塞魂件的地方); 失去進攻主堡的一般敵人頭上畫問號、魂亂守點畫腳下底座; 主堡區圈常駐(淡虛線), 進入時變實線並出現空白鍵鍵帽。
- **P3 一個意義一種長相**: 同一套魂件圖示用在槽列、地上、手上、魂件彈窗、商店; 紫色系只代表「魂亂 / 魂亂這一邊」(魂亂本體、魂亂提示、我方攻擊特效、HUD 魂亂數); 青綠只代表玩家與玩家的動作(搶奪環、連線、手上格)。
- **P4 關鍵區分至少兩條通道**: 一般 vs 魂亂 = 紅 / 紫 + 頭上漩渦與發光眼; 我方攻擊 vs 敵方攻擊 = 紫 / 橘紅 + 菱形箭 / 圓彈; 「拿著」vs「裝在身上」= 身體右側一大格被雙手捧著 + 青光 / 頭上一排小格; 中立 vs 我方遊魂 = 灰白半透明 + 虛線框 / 實心藍 + 實線框。
- **P7 每個元素都要掙得它的版面**: 敵人沒受傷不畫血條; 說明頁不重畫遊戲內彈窗已寫的「Z 確定 X 關閉」, 只補方向鍵帽。
- **P9 以最混亂的那一刻驗收**: 魂亂敵人和一般敵人貼身混戰時, 魂亂外框多一圈淡紫亮線, 在紅色堆裡也撿得到; 冰霜圈只鋪 11% 淡色, 多個疊在一起仍看得到單位。
- **P13 事件要排隊**: 名稱提示(合成 / 新組合 / 魂亂 / 掉落)畫在槽列之上、彈出後往上飄並淡出, 不壓槽列; 同一單位同時多個提示的排隊由 RD 依呼叫決定(本檔建議同一單位一次只播一個)。
- **P15 回饋強度和事件份量成正比**: 「合成!」暗底白字小牌 < 「新組合!」白底粗紫框大牌(字 18px); 命中火花 24px < 範圍斬擊 / 爆炸 120~140px。
- **P17 圖形與數字分工**: 出怪預警的中央數字給剩幾秒, 外圈白環只畫「這一秒還剩多少」; 搶奪環沒有數字, 照總進度畫。
- **P18 重要資訊不能只存在一瞬間**: 魂亂數常駐 HUD; 合成結果常駐在槽列(組合魂件圖示), 「新組合」數字留在結算。
- **P19 資訊貼著物件**: 槽列、血條、名稱提示都貼在單位頭上; 主堡區的空白鍵提示畫在主堡區圈內。
- **P21 示意圖選對錯理解會分岔的例子**: 說明第 7 頁同時畫合法(路旁, 綠框)與不合法(站在路上, 紅叉)兩格; 第 3 頁把「屍體直接拿」和「活鬼要撐一下(進度環)」並排。

## 5. 判讀約定(RD 請照這幾條傳值)

- **targeted 外框**: 黃色 3px, 內緣貼齊 size 外邊(畫在框外)。
- **一般敵人 `moving`**: 本檔把 `moving: false` 畫成「呆站(頭上問號)」, 這個記號的意思是「失去進攻主堡」。**建議傳「身上還有沒有進攻主堡」**, 而不是本幀有沒有位移 — 否則一般敵人停下來打魂亂敵人時也會冒問號(規則 17 攻擊時原地停)。魂亂敵人 `moving: false` 畫腳下淡紫底座(守點)。
- **Age / Duration**: 依 conventions, `0 ≤ Age < Duration` 才播, 閒置 Age = Duration 不畫效果; `drawComboName`、`drawPierceBeam`、`drawAreaHit`、`drawHitSpark` 在不播時自己不畫。
- **drawAreaHit / drawFrostAura 的 radius = 外緣**, 畫面不超出 radius(爆炸前緣環的外緣貼 radius)。
- **drawPierceBeam**: 外暈寬 26 ≤ 判定寬 28, 白芯 3px 在中線上。
- **drawEnemy 的 hp 血條**: 只在 `hp < maxHp` 時畫, 中心 (x, y − 高/2 − 6), 寬 = 種類寬, 高 4; 魂亂血條淡紫、一般紅。
- **drawCorpse**: `life < 3` 每 1/6 秒在 0.3 / 0.95 不透明度間閃; `maxLife` 只用來夾住 life。
- **表外值**: 未知敵人種類 → 畫成小鬼; 未知魂件字串 → 不畫(空); 未知 owner → 我方; 未知 kind(投射物)→ normal; 未知 kind(範圍)→ 旋風斬; 未知 kind(提示)→ 合成; 未知 team(遊魂)→ 中立。看到不該出現的預設外觀時請查傳入值。
- **動畫時鐘**: 遊魂飄動、步兵踏步、玩家走路晃動、搶奪連線流動、出怪預警閃爍用 `performance.now()`(只影響畫面, 慢動作時這幾個小動態不變慢)。

## 6. 畫面文字歸屬

遊戲內所有文字由美術畫(依 interface.textOwnership): 名稱提示、彈窗標題 /「手上」/「丟下」/ 動作提示 /「Z 確定 X 關閉」、商店標題 / 品名 / 價格 / 訊息 /「← → 選 Z 購買 X 關閉」、HUD 數值與標籤與右側「Z 互動 X 自己 空白鍵 商店」、「慢動作」字牌、結算全部文字、主堡區內的「空白鍵」鍵帽。**RD 不要再畫這些字。**
說明頁例外: 頁標題、說明文字、頁碼、翻頁提示歸 RD; `drawGuidePage` 只畫示意圖(含物件旁 2~4 字的短標籤與鍵帽)。
