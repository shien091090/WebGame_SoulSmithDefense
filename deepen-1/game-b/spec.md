# 魂匠惑亂(把魂件裝進活敵人, 讓它倒戈打自己人)

## 概述
每隻敵人身上都留著一個空的魂件槽。玩家拿著魂件走到敵人旁邊, 把魂件**塞進那個空格**, 敵人立刻「魂亂」——變成紫色、血量加倍, 身上所有魂件改打其他敵人, 還保留著「進攻主堡」的話就掉頭沿路殺回出怪點。把它的進攻主堡拿掉, 它就停在路上變成一座用敵人做的據點。敵人在路上排成一列, 魂亂敵人一出現就自然陷入混戰。魂亂敵人倒下時, 玩家裝進去的魂件全掉在地上、不會消失。被組合技打死的敵人, 屍體會多帶一件那種組合魂件。
驗證假設: H03、H32、H33、H40、H52、H53、H54、H60、H61、H62、H63、H64、H69。

## 核心循環
敵人沿路走來 → 從屍體、塔、自己身上或商店拿到一件魂件 → 走到敵人旁, 把魂件塞進它的空格 → 敵人魂亂, 掉頭殺進敵群(湊成組合時當場合成、跳出名稱)→ 混戰中敵人倒下、噴金幣, 被組合技打死的屍體多帶一件組合魂件 → 魂亂敵人倒下, 魂件掉在地上 → 撿起來塞進下一隻。
想再做一次的理由: 每一隻敵人都是潛在的兵; 塞進不同魂件, 牠們打起來的樣子完全不同。

## 規則
### 地圖
1. 畫面 1280×720, 上方 0~50 為 HUD, 遊戲區 y 50~720。
2. 敵人路線寬 56, 中線依序連接: (0,626) → (528,626) → (528,146) → (1008,146) → (1008,386) → 主堡 (1180,386)。
3. 主堡中心 (1180,386), 半徑 56。主堡中心 110 內是「主堡區」(購買用)。
4. 出怪點 (10,626)。
5. 蓋塔格: 48×48, 第 i 欄第 j 列(都從 0 起算)的格子中心 = (24+48i, 74+48j), i = 0~26, j = 0~13。

### 開局
6. 金幣 40, 主堡生命 20。
7. 箭塔兩座: (456,410)、(600,218), 魂件 [遠攻], 槽位上限 2。
8. 主堡魂件 [遠攻, 近戰], 槽位上限 3。
9. 中立遊魂兩隻, 家在 (264,386)、(792,290), 無魂件, 槽位上限 3。
10. 玩家在 (1060,520), 身上 [近戰, 空, 空], 手上空。

### 魂件
11. 基本魂件五種: 遠攻、近戰、冰霜、爆裂、進攻主堡。另有組合魂件五種(規則 13)與擴槽石。
12. 單件效果(n = 這個單位身上同種基本魂件的件數):
    - 遠攻: 每 1.0 秒對射程 200 內最近的敵對單位射投射物(速度 420), 傷害 10×n
    - 近戰: 每 0.8 秒對碰觸距離(兩者半邊長和 +12)內最近的敵對單位造成 14×n 傷害
    - 冰霜: 自身中心 70 內的敵對單位移動速度 −30%
    - 爆裂: 每 2.0 秒對自身中心 70 內每個敵對單位造成 10×n 傷害
    - 進攻主堡: 依單位而定(敵人規則 22、魂亂規則 26、中立規則 32、我方單位: 直線走到主堡邊緣停下, 據點改成停下的位置)
13. 合成: 我方單位、主堡、玩家身上、**魂亂敵人**身上, 只要有兩件基本魂件符合下表, 就立即合成為一件組合魂件: 放進兩件中較前面的那一格, 另一格變空; 依表的順序由上往下檢查, 合到沒有可合的為止。組合魂件不能拆回兩件, 可以像一般魂件一樣拆下、搬運、裝到別處。一般敵人、中立單位、屍體、地上的魂件不會合成。
    | 順序 | 組合魂件 | 由哪兩件合成 | 效果 |
    |---|---|---|---|
    | 0 | 穿透箭 | 遠攻 + 遠攻 | 每 1.0 秒朝射程 260 內最近的敵對單位射出一道直線, 線上(距線 14 內)每個敵對單位受 14 傷害 |
    | 1 | 冰箭 | 遠攻 + 冰霜 | 每 1.0 秒對射程 200 內最近的敵對單位射投射物, 10 傷害並減速 50% 持續 2 秒 |
    | 2 | 爆裂彈 | 遠攻 + 爆裂 | 每 1.2 秒對射程 200 內最近的敵對單位射投射物, 命中處 70 內每個敵對單位受 12 傷害 |
    | 3 | 旋風斬 | 近戰 + 近戰 | 每 0.8 秒對自身中心 60 內所有敵對單位造成 16 傷害 |
    | 4 | 冰霜重擊 | 近戰 + 冰霜 | 每 0.8 秒對碰觸距離內最近的敵對單位造成 16 傷害, 並使它與它身邊 60 內的敵對單位減速 50% 持續 2 秒 |
14. 合成發生時, 該單位頭上跳出「合成! <名稱>」1.5 秒; 這種組合是本局第一次合成時改跳「新組合! <名稱>」。
15. 一個單位身上有多件同種組合魂件時, 各自獨立發動。減速不疊加, 取最大的一個。每個攻擊效果各自計冷卻、各自找目標。
16. 敵對關係: 我方(玩家、我方單位、主堡)與魂亂敵人是同一邊, 敵對單位 = 一般敵人; 一般敵人的敵對單位 = **只有魂亂敵人**。中立單位不受攻擊、也不攻擊。
17. 行為優先序: 任一攻擊效果範圍內有敵對單位 → 原地攻擊; 否則照該單位的移動規則。

### 我方單位
18. 我方單位沒有生命、不會被攻擊。
    | 單位 | 槽位上限 | 半邊長 | 購買時的魂件 | 可擴槽 | 放置方式 |
    |---|---|---|---|---|---|
    | 箭塔(靜態) | 2 | 24 | [] | 是, 最多 4 | 蓋在玩家所站的蓋塔格 |
    | 步兵(移動) | 2 | 16 | [近戰] | 否 | 放在玩家腳下 |
    | 遊魂(移動) | 3 | 16 | [] | 否 | 放在玩家腳下 |
    | 主堡 | 3 | 56 | | 是, 最多 4 | |
19. 靜態單位的合法位置: 玩家所站的蓋塔格(欄 = ⌊x/48⌋, 列 = ⌊(y−50)/48⌋)在範圍內、格子中心離任何路線中線 ≥ 52、離主堡中心 ≥ 90、格子上沒有其他箭塔。移動單位的合法位置: 玩家中心離主堡中心 ≥ 90。單位放下的位置是它的「據點」。
20. 移動單位的預設移動「巡邏」: 放下時取路線中線上離據點最近的點當巡邏中心, 先直線走到巡邏中心, 之後沿路線在巡邏中心前後各 120(沿路線量)之間來回走; 步兵速度 50、遊魂速度 70。

### 敵人
21. 敵人數值(槽位上限 = 預設魂件數 +1, 多出來的那一格開局是空的):
    | 敵人 | 生命 | 速度 | 半邊長 | 魂件 | 掉金幣枚數 | 抵達主堡扣血 |
    |---|---|---|---|---|---|---|
    | 小鬼 | 40 | 45 | 16 | [近戰, 進攻主堡, 空] | 1 | 2 |
    | 弓鬼 | 30 | 50 | 16 | [遠攻, 進攻主堡, 空] | 2 | 2 |
    | 冰鬼 | 50 | 42 | 16 | [冰霜, 進攻主堡, 空] | 2 | 2 |
    | 爆鬼 | 45 | 45 | 18 | [爆裂, 進攻主堡, 空] | 2 | 2 |
    | 巨鬼 | 180 | 30 | 26 | [旋風斬, 進攻主堡, 空] | 5 | 4 |
22. 一般敵人: 有進攻主堡就沿路線走向主堡, 失去它就停在原地。身上的攻擊類魂件照規則 12、13 發動, 但只打魂亂敵人(範圍內沒有魂亂敵人時不發動、不停下)。
23. 敵人中心進入主堡半徑 +10 內: 主堡扣血, 敵人消失, 不留屍體、不掉金幣。
24. 一般敵人生命歸 0: 變成屍體, 保留全部魂件(含空格), 15 秒後連同魂件消失(最後 3 秒閃爍); 在 40 半徑內噴出金幣, 每枚 2 金。
25. 掉落組合魂件: 一般敵人被**組合魂件的攻擊**(穿透箭、冰箭、爆裂彈、旋風斬、冰霜重擊; 不論是誰身上的)打死時, 屍體多出一格, 裡面是一件同種組合魂件, 屍體頭上跳出「掉落! <名稱>」1.0 秒。每具屍體最多多一件。

### 魂亂
26. 玩家把魂件(基本或組合, 不含擴槽石)裝進一般敵人的空格 → 這隻敵人立即變成「魂亂」:
    - 生命上限與目前生命都變成原本生命上限的 2 倍
    - 改站到我方這一邊(規則 16): 身上所有魂件(原本的 + 裝進去的)照規則 12、13 發動, 改打一般敵人; 會立即合成
    - 我方單位、主堡、玩家不會打它; 一般敵人會打它
    - 移動: 身上有進攻主堡 → 沿路線**逆向**走向出怪點(用自己的速度), 走到出怪點就停在那裡; 沒有進攻主堡 → 停在原地
    - 之後再對它開彈窗, 拆、裝、互換都立即完成, 和我方單位一樣(不讀條); 拆光了仍是魂亂
    - 不會抵達主堡、不會扣主堡血
27. 魂亂敵人生命歸 0: 不留屍體; 身上**所有**魂件變成地上的魂件, 散在它中心 30 內(第 k 件放在角度 k×90° 的位置, k 從 0 起算, 0° = 正右方), 不會消失; 並照常噴金幣。
28. 每次有敵人變成魂亂, 頭上跳出「魂亂!」1.0 秒。

### 中立單位與招募
29. 中立遊魂在家附近飄: 每 2 秒在家中心 120 內隨機挑一點, 以速度 40 飄過去(會飄上路線, 不受攻擊、不擋路)。
30. 中立單位身上的魂件除了進攻主堡都沒有效果, 也不會合成。
31. 遊魂是飄浮的: 敵人與魂亂敵人都不會撞到它。
32. 中立單位裝上進攻主堡: 停止飄動, 直線走向主堡(速度 60)。中心進入主堡半徑 +10 內: 它消失, 身上的魂件依序掉在 (1100+32×k, 480)(k 從 0 起算)成為地上的魂件, 主堡商店解鎖遊魂。

### 玩家
33. 玩家移動速度 260, 不會被攻擊、不擋路。
    - 身上 3 格魂件槽(不可擴充): 身上的魂件照規則 12、13 生效(會射擊、會斬、會合成), 進攻主堡沒有效果
    - 手上最多「拿著」1 樣東西: 一件魂件、擴槽石、或一份單位材料。拿著的魂件不生效, 不會自動進到身上
    - 互動目標 = 中心距 ≤ 目標半邊長 +48 的可互動物中最近的一個: 我方單位、中立單位、主堡、屍體、地上的魂件、活著的敵人(一般或魂亂)
34. 商店: 在主堡區內、沒開任何彈窗時按空白鍵, 打開「商店彈窗」(慢動作同規則 38)。一排 8 項(從 0 起算): 箭塔 15、步兵 12、遠攻 8、近戰 8、冰霜 12、爆裂 12、擴槽石 20、遊魂 16(招募過遊魂才解鎖)。
    - 開啟時游標在第 0 項; ← → 移動(頭尾循環)
    - 按 Z 購買: 金幣足夠、已解鎖、手上是空的 → 扣錢, 東西進到手上, 彈窗關閉; 否則無效(彈窗抖一下, 底部提示「金幣不足」「尚未解鎖」或「手上要空著」)
    - 按 X 關閉
35. 沒開彈窗時按 Z, 依序判斷第一個成立的:
    1. 手上是單位材料 → 在合法位置放置(規則 19), 不合法則無效。拿著材料時畫面顯示放置預覽(合法 / 不合法); 箭塔的預覽畫在格子中心
    2. 互動目標是地上的魂件 → 手空: 撿起; 手上有魂件或擴槽石: 互換。不開彈窗
    3. 有其他互動目標 → 打開「魂件彈窗」(規則 36)
    4. 都沒有 → 無效
36. 魂件彈窗: 顯示目標的魂件槽(長度 = 槽位上限)和玩家手上的東西。
    - 開啟時游標: 手空 → 第一個有魂件的格子; 手上有魂件 → 第一個空格; 沒有這種格子 → 第 0 格
    - ← → 移動游標(頭尾循環)
    - 按 Z 依游標格執行, 成功後彈窗關閉:
      | 手上 | 游標格 | 目標 | 結果 |
      |---|---|---|---|
      | 空 | 有魂件 | 我方 / 中立 / 主堡 / 屍體 / 魂亂敵人 | 立即拿到手上 |
      | 空 | 有魂件 | 一般敵人 | 開始搶奪(規則 39), 彈窗關閉 |
      | 魂件 | 空格 | 我方 / 中立 / 主堡 / 魂亂敵人 | 立即裝上(可能立即合成) |
      | 魂件 | 空格 | 一般敵人 | 立即裝上, 敵人變成魂亂(規則 26) |
      | 魂件 | 有魂件 | 我方 / 中立 / 主堡 / 魂亂敵人 | 立即互換(可能立即合成) |
      | 擴槽石 | 任一格 | 可擴槽且上限 < 4 的目標 | 槽位上限 +1, 擴槽石用掉 |
      | 其他情況(含: 對一般敵人的有魂件格互換、把擴槽石給敵人) | | | 無效, 彈窗抖一下、不關 |
    - 按 X 關閉
    - 目標消失或目標中心離玩家超過「目標半邊長 +68」時彈窗自動關閉
37. 沒開彈窗時按 X: 打開「自身彈窗」, 顯示玩家身上 3 格 + 第 3 格之後的「丟下」格, 以及手上的東西:
    - 開啟時游標: 手空 → 第一個有魂件的身上格; 手上有魂件 → 第一個空的身上格; 沒有這種格子 → 第 0 格
    - ← → 在 4 格間移動(頭尾循環)
    - 按 Z: 身上格照規則 36 我方單位那幾列(拿下 / 裝上 / 互換, 擴槽石無效); 「丟下」格: 手上是魂件或擴槽石 → 丟在腳下成為地上的魂件(不會消失), 手空或手上是單位材料 → 無效。成功後彈窗關閉
    - 按 X 關閉
38. 任何彈窗開著時, 遊戲時間變成 0.2 倍(慢動作), 玩家不能移動。
39. 搶奪: 遊戲恢復正常速度, 1.5 秒後那一格的魂件從敵人身上移到玩家手上, 敵人立即失去它(失去進攻主堡就停下)。搶奪中玩家可以移動; 敵人中心離玩家超過「敵人半邊長 +68」、敵人死亡、敵人變成魂亂或再按 Z 時取消, 沒有任何損失。搶奪中按 Z 只做取消。

### 波次
40. 說明頁關閉後開始計時。第 k 波在 12 + (k−1)×26 秒開始; 開始前 6 秒出怪點出現預警。
41. 每 1.2 秒出一隻, 依下表順序:
    - 第 1 波: 小鬼×6
    - 第 2 波: 小鬼×3、弓鬼×4
    - 第 3 波: 冰鬼×4、小鬼×4
    - 第 4 波: 爆鬼×4、巨鬼×1、弓鬼×3
    - 第 5 波: 巨鬼×2、冰鬼×3、小鬼×5
    - 第 6 波: 巨鬼×3、爆鬼×3、弓鬼×3、小鬼×4

## 操作
只用鍵盤: 方向鍵 + Z、X、空白鍵。
| 按鍵 | 動作 |
|---|---|
| ← → ↑ ↓ | 移動(彈窗開著時 ← → 移動游標) |
| Z | 對互動目標打開魂件彈窗 / 撿起或互換地上的魂件 / 拿著單位材料時放置 |
| Z(彈窗中) | 對游標格執行: 拿、裝(含塞進敵人)、互換、擴槽、搶奪、丟下、購買 |
| Z(搶奪中) | 取消搶奪 |
| X | 打開自身彈窗(把身上的魂件拿下來、或把手上的裝到身上、或丟下) |
| X(彈窗中) | 關閉彈窗 |
| 空白鍵 | 在主堡區打開商店 |
| Z | 說明頁翻頁, 最後一頁再按開始遊戲 |
| Z | 結算畫面重新開始 |
說明頁關閉後要等 Z 放開才接受遊戲內的 Z。

## 勝負與結束
- 勝利: 第 6 波全部出完且場上沒有活著的一般敵人(魂亂敵人不算, 勝利時一併消失)。
- 失敗: 主堡生命 ≤ 0。
- 結算畫面顯示勝利或失敗、到達的波次、發現的組合數(n / 5)、本局魂亂過的敵人數, 按 Z 從開局重新開始(不再顯示說明頁)。結算出現後 0.5 秒內的 Z 不算。
