# 魂匠共鳴(魂柱共鳴: 一根柱子讓整片單位一起變招)

## 概述
Y 型雙入口的路線上, 玩家除了蓋弩塔, 還能蓋「魂柱」: 魂柱本身不攻擊, 但它身上的魂件會「共鳴」給周圍 150 內的每一個我方單位——塔、兵、主堡、連玩家自己——當作他們多帶了一件魂件, 拿來湊組合。魂柱裝冰霜, 周圍帶遠攻的塔全變冰箭; 換成遠攻, 全變穿透箭。玩家自己走進魂柱範圍, 攻擊模式也跟著變。第一次湊出的組合會被主堡的魂爐記住, 之後每一波開始, 主堡都送一件那種組合魂件。敵人只會打我方的兵, 兵被打倒 5 秒後帶著魂件站起來。
驗證假設: H03、H32、H33、H38、H39、H52、H53、H54、H65、H66、H67、H68、H69。

## 核心循環
看到預警是哪條支線 → 想好要讓哪一片單位變成什麼招 → 從塔、屍體、活敵人身上拿魂件, 裝進那一片的魂柱(或多蓋一根魂柱)→ 範圍內的單位一起跳出組合名稱 → 敵人被打倒、噴金幣 → 撿錢買塔、魂柱、兵 → 下一波換支線, 跑過去換魂柱的魂件或把魂柱旁的兵帶上去。
想再做一次的理由: 換一件魂件就讓一整片防線一起變招, 很有指揮全場的感覺; 自己在魂柱之間跑, 攻擊方式一路跟著變。

## 規則
### 地圖
1. 畫面 1280×720, 上方 0~50 為 HUD, 遊戲區 y 50~720。
2. 敵人路線寬 56, 中線由三段折線組成(Y 型):
   - 北支線: (0,194) → (720,194) → (720,434)
   - 南支線: (0,626) → (720,626) → (720,434)
   - 匯流段: (720,434) → 主堡 (1180,434)
3. 主堡中心 (1180,434), 半徑 56。主堡中心 110 內是「主堡區」(購買用)。
4. 出怪點: 北 (10,194)、南 (10,626)。北支線 + 匯流段是「北路」, 南支線 + 匯流段是「南路」。
5. 蓋塔格: 48×48, 第 i 欄第 j 列(都從 0 起算)的格子中心 = (24+48i, 74+48j), i = 0~26, j = 0~13。

### 開局
6. 金幣 40, 主堡生命 20。
7. 弩塔兩座: (456,266)、(456,554), 魂件 [遠攻], 槽位上限 2。
8. 魂柱一根: (456,410), 魂件 [冰霜], 槽位上限 1。兩座弩塔都在它的範圍內, 開局就是冰箭。
9. 主堡魂件 [遠攻, 近戰], 槽位上限 3。
10. 中立石魔像兩隻, 家在 (264,410)、(960,290), 無魂件, 槽位上限 3。
11. 玩家在 (1060,560), 身上 [近戰, 空, 空], 手上空。

### 魂件
12. 基本魂件六種: 遠攻、近戰、冰霜、索敵、進攻主堡、行軍。另有組合魂件五種(規則 14, 只能從魂爐取得)與擴槽石。
13. 單件效果(n = 這個單位身上沒配成組的同種實體魂件數):
    - 遠攻: 每 1.0 秒對射程 200 內最近的敵對單位射投射物(速度 420), 傷害 10×n
    - 近戰: 每 0.8 秒對碰觸距離(兩者半邊長和 +12)內最近的敵對單位造成 14×n 傷害
    - 冰霜: 自身中心 70 內的敵對單位移動速度 −30%
    - 索敵: 離據點 200 內有敵對單位時朝它移動, 速度 min(70×n, 140), 直到進入攻擊距離(有遠攻、穿透箭或冰箭: 180; 否則碰觸); 範圍內沒有就以速度 80 走回據點
    - 進攻主堡: 直線走到主堡邊緣停下, 據點改成停下的位置
    - 行軍: **只對移動單位有效**: 離開據點, 沿路線逆向走向出怪點(速度 50), 到了就停在出怪點; 走到 Y 型匯流點 (720,434) 時, 走向路上活著的一般敵人比較多的那條支線(一樣多走北)
14. 組合(配組, 不會合成成一件): 每個單位的「配組池」= 自己身上的實體魂件 + 共鳴來的虛魂件(規則 18)。依下表順序由上往下, 池裡兩種都有就配成一組, 能配幾組配幾組, 每件只用一次; 配組時先用虛魂件、再用實體魂件。配成組的魂件只發揮組合效果; 沒配到的實體魂件發揮單件效果, 沒配到的虛魂件沒有效果。
    | 順序 | 名稱 | 魂件 | 效果 |
    |---|---|---|---|
    | 0 | 穿透箭 | 遠攻 + 遠攻 | 每 1.0 秒朝射程 260 內最近的敵對單位射出一道直線, 線上(距線 14 內)每個敵對單位受 14 傷害 |
    | 1 | 冰箭 | 遠攻 + 冰霜 | 每 1.0 秒對射程 200 內最近的敵對單位射投射物, 10 傷害並減速 50% 持續 2 秒 |
    | 2 | 旋風斬 | 近戰 + 近戰 | 每 0.8 秒對自身中心 60 內所有敵對單位造成 16 傷害 |
    | 3 | 冰霜重擊 | 近戰 + 冰霜 | 每 0.8 秒對碰觸距離內最近的敵對單位造成 16 傷害, 並使它與它身邊 60 內的敵對單位減速 50% 持續 2 秒 |
    | 4 | 衝鋒 | 行軍 + 近戰 | **只有移動單位會配這一組**(弩塔、主堡、玩家跳過這一列): 沿路線逆向走向出怪點(速度 90, 匯流點的選法同行軍), 每 1.0 秒對碰觸距離內最近的敵人造成 30 傷害並把它往出怪點方向擊退 30; 碰觸到敵人時不停下 |
15. 組合魂件: 一件就等於一組組合, 直接發揮表中效果, 不進配組池。不能裝進魂柱。
16. 單位每多出一個組合(含共鳴造成的), 頭上跳出組合名稱 1.5 秒; 同一個單位的同一種組合 4 秒內不重複跳(避免走進走出時一直跳)。這種組合是本局第一次出現時改跳「新組合! <名稱>」, 並由魂爐記住(規則 31)。
17. 減速不疊加, 取最大的一個。每個攻擊效果各自計冷卻、各自找目標。行為優先序: 任一攻擊效果範圍內有目標 → 原地攻擊(衝鋒例外, 見表); 否則依序: 衝鋒 > 行軍 > 索敵 > 進攻主堡 > 該單位的預設移動(規則 25)> 不動。

### 魂柱與共鳴
18. 魂柱: 靜態單位, 本身不攻擊、不移動、不會被攻擊。身上的每一件基本魂件, 會「共鳴」給中心距 ≤ 150 的每一個接收者, 成為接收者配組池裡的一件虛魂件。接收者: 弩塔、我方步兵、我方石魔像、主堡、玩家(不含魂柱自己、其他魂柱、中立單位、敵人)。
19. 一個接收者同時在多根魂柱範圍內時, 每根魂柱的魂件都各算一件。
20. 魂柱只能裝基本魂件(組合魂件、擴槽石以外的東西裝不進去; 擴槽石可擴到 2 格)。
21. 魂柱的範圍(半徑 150 的圓)一直畫在地上; 範圍內的接收者和魂柱之間畫一條細細的共鳴線, 那件虛魂件有被配進組合時共鳴線變亮。

    | 石魔像(移動) | 220 | 3 | 28 | [] | 是, 最多 4 | 放在玩家腳下 |
    | 主堡 | 不受攻擊 | 3 | 56 | | 是, 最多 4 | |
23. 靜態單位的合法位置: 玩家所站的蓋塔格(欄 = ⌊x/48⌋, 列 = ⌊(y−50)/48⌋)在範圍內、格子中心離任何路線中線 ≥ 52、離主堡中心 ≥ 90、格子上沒有其他靜態單位。移動單位的合法位置: 玩家中心離主堡中心 ≥ 90。單位放下的位置是它的「據點」。
24. 我方移動單位生命歸 0 → 「倒下」5 秒: 不行動、不被攻擊、身上魂件保留, 仍可被拆裝、仍是共鳴接收者; 5 秒後滿血站起。
25. 移動單位的預設移動「巡邏」: 放下時取北路或南路中線上離據點最近的點當巡邏中心, 先直線走到巡邏中心, 之後沿那條路在巡邏中心前後各 120(沿路線量)之間來回走; 步兵速度 50、石魔像速度 40。

### 敵人
26. 敵人數值(槽位上限 = 魂件數):
    | 敵人 | 生命 | 速度 | 半邊長 | 魂件 | 掉金幣枚數 | 抵達主堡扣血 |
    |---|---|---|---|---|---|---|
    | 小鬼 | 40 | 45 | 16 | [近戰, 進攻主堡] | 1 | 2 |
    | 弓鬼 | 30 | 50 | 16 | [遠攻, 進攻主堡] | 2 | 2 |
    | 冰鬼 | 50 | 42 | 16 | [冰霜, 進攻主堡] | 2 | 2 |
    | 鼓鬼 | 45 | 48 | 18 | [行軍, 進攻主堡] | 2 | 2 |
    | 狂鬼 | 80 | 40 | 22 | [近戰, 索敵, 進攻主堡] | 3 | 3 |
27. 敵人的敵對單位 = **只有我方移動單位**(步兵、石魔像, 不含倒下中的); 不打弩塔、魂柱、主堡、玩家、中立單位。敵人身上的魂件只發揮單件效果(不配組), 行軍對敵人沒有效果。敵人用索敵(範圍 160)離開路線追兵, 目標消失後走回最近的路線點繼續前進; 失去進攻主堡就停在原地。
28. 敵人中心進入主堡半徑 +10 內: 主堡扣血, 敵人消失, 不留屍體、不掉金幣。
29. 敵人生命歸 0: 變成屍體, 保留全部魂件, 15 秒後連同魂件消失(最後 3 秒閃爍); 在 40 半徑內噴出金幣, 每枚 2 金。
30. 金幣不會消失。玩家中心距金幣 90 內時, 金幣以每秒 420 飛向玩家, 碰到玩家(距 20 內)就撿起。

### 魂爐(組合魂件的來源)
31. 某種組合本局第一次出現時(規則 16), 主堡的魂爐記住它。之後每一波開始的當下, 魂爐為每一種記住的組合各送出一件組合魂件, 放在第 c 個位置 (1052+32×c, 530)(c = 該組合在規則 14 表中的順序 0~4)成為地上的魂件; 那個位置上已經有地上的魂件時, 這一種這次不送。
32. 組合魂件裝在任何單位或玩家身上都直接發動(衝鋒裝在弩塔、主堡、玩家身上沒有效果)。

### 中立單位與招募
33. 中立石魔像在家附近閒逛: 每 2 秒在家中心 100 內隨機挑一點, 以速度 40 走過去(會走上路線, 不受攻擊、不擋路、不是共鳴接收者)。身上的魂件除了進攻主堡都沒有效果。
34. 中立單位裝上進攻主堡: 停止閒逛, 直線走向主堡(速度 60)。中心進入主堡半徑 +10 內: 它消失, 身上的魂件依序掉在 (1052+32×k, 580)(k 從 0 起算)成為地上的魂件, 主堡商店解鎖石魔像。

### 玩家
35. 玩家移動速度 260, 不會被攻擊、不擋路。
    - 身上 3 格魂件槽(不可擴充): 照規則 13、14 生效, 也是共鳴接收者; 索敵、進攻主堡、行軍、衝鋒沒有效果
    - 手上最多「拿著」1 樣東西: 一件魂件、擴槽石、或一份單位材料。拿著的魂件不生效, 不會自動進到身上
    - 互動目標 = 中心距 ≤ 目標半邊長 +48 的可互動物中最近的一個: 我方單位(含倒下中)、中立單位、主堡、屍體、地上的魂件、活著的敵人
36. 商店: 在主堡區內、沒開任何彈窗時按空白鍵, 打開「商店彈窗」(慢動作同規則 40)。一排 8 項(從 0 起算): 弩塔 15、魂柱 12、步兵 12、遠攻 8、近戰 8、冰霜 12、擴槽石 20、石魔像 18(招募過石魔像才解鎖)。索敵、進攻主堡、行軍只能從敵人與單位身上取得。
    - 開啟時游標在第 0 項; ← → 移動(頭尾循環)
    - 按 Z 購買: 金幣足夠、已解鎖、手上是空的 → 扣錢, 東西進到手上, 彈窗關閉; 否則無效(彈窗抖一下, 底部提示「金幣不足」「尚未解鎖」或「手上要空著」)
    - 按 X 關閉
37. 沒開彈窗時按 Z, 依序判斷第一個成立的:
    1. 手上是單位材料 → 在合法位置放置(規則 23), 不合法則無效。拿著材料時畫面顯示放置預覽(合法 / 不合法); 靜態單位的預覽畫在格子中心; 拿著魂柱材料時預覽一併畫出它的範圍圈
    2. 互動目標是地上的魂件 → 手空: 撿起; 手上有魂件或擴槽石: 互換。不開彈窗
    3. 有其他互動目標 → 打開「魂件彈窗」(規則 38)
    4. 都沒有 → 無效
38. 魂件彈窗: 顯示目標的魂件槽(長度 = 槽位上限)和玩家手上的東西(虛魂件不顯示在彈窗裡, 不能拆)。
    - 開啟時游標: 手空 → 第一個有魂件的格子; 手上有魂件 → 第一個空格; 沒有這種格子 → 第 0 格
    - ← → 移動游標(頭尾循環)
    - 按 Z 依游標格執行, 成功後彈窗關閉:
      | 手上 | 游標格 | 目標 | 結果 |
      |---|---|---|---|
      | 空 | 有魂件 | 我方 / 中立 / 主堡 / 屍體 | 立即拿到手上 |
      | 空 | 有魂件 | 活敵人 | 開始搶奪(規則 41), 彈窗關閉 |
      | 魂件 | 空格 | 我方 / 中立 / 主堡 | 立即裝上(組合魂件不能裝進魂柱) |
      | 魂件 | 有魂件 | 我方 / 中立 / 主堡 | 立即互換(組合魂件不能換進魂柱) |
      | 擴槽石 | 任一格 | 可擴槽且未達上限的目標 | 槽位上限 +1, 擴槽石用掉 |
      | 其他情況 | | | 無效, 彈窗抖一下、不關 |
    - 按 X 關閉
    - 目標消失或目標中心離玩家超過「目標半邊長 +68」時彈窗自動關閉
39. 沒開彈窗時按 X: 打開「自身彈窗」, 顯示玩家身上 3 格 + 第 3 格之後的「丟下」格, 以及手上的東西:
    - 開啟時游標: 手空 → 第一個有魂件的身上格; 手上有魂件 → 第一個空的身上格; 沒有這種格子 → 第 0 格
    - ← → 在 4 格間移動(頭尾循環)
    - 按 Z: 身上格照規則 38 我方單位那幾列(拿下 / 裝上 / 互換, 擴槽石無效); 「丟下」格: 手上是魂件或擴槽石 → 丟在腳下成為地上的魂件(不會消失), 手空或手上是單位材料 → 無效。成功後彈窗關閉
    - 按 X 關閉
40. 任何彈窗開著時, 遊戲時間變成 0.2 倍(慢動作), 玩家不能移動。
41. 搶奪: 遊戲恢復正常速度, 1.5 秒後那一格的魂件從敵人身上移到玩家手上, 敵人立即失去它。搶奪中玩家可以移動; 敵人中心離玩家超過「敵人半邊長 +68」、敵人死亡或再按 Z 時取消, 沒有任何損失。搶奪中按 Z 只做取消。

### 波次
42. 說明頁關閉後開始計時。第 k 波在 12 + (k−1)×26 秒開始; 開始前 6 秒, 該波用到的每個出怪點出現預警。
43. 每個出怪點每 1.2 秒出一隻, 依下表順序:
    - 第 1 波: 北 小鬼×5
    - 第 2 波: 南 小鬼×3、弓鬼×3
    - 第 3 波: 北 鼓鬼×3、小鬼×3; 南 小鬼×3
    - 第 4 波: 南 冰鬼×3、狂鬼×2; 北 弓鬼×3
    - 第 5 波: 北 狂鬼×3、鼓鬼×2; 南 冰鬼×3、小鬼×3
    - 第 6 波: 北、南 各 小鬼×3、狂鬼×2、冰鬼×1、鼓鬼×1

## 操作
只用鍵盤: 方向鍵 + Z、X、空白鍵。
| 按鍵 | 動作 |
|---|---|
| ← → ↑ ↓ | 移動(彈窗開著時 ← → 移動游標) |
| Z | 對互動目標打開魂件彈窗 / 撿起或互換地上的魂件 / 拿著單位材料時放置 |
| Z(彈窗中) | 對游標格執行: 拿、裝、互換、擴槽、搶奪、丟下、購買 |
| Z(搶奪中) | 取消搶奪 |
| X | 打開自身彈窗(把身上的魂件拿下來、或把手上的裝到身上、或丟下) |
| X(彈窗中) | 關閉彈窗 |

## 勝負與結束
- 勝利: 第 6 波全部出完且場上沒有活著的敵人。
- 失敗: 主堡生命 ≤ 0。
- 結算畫面顯示勝利或失敗、到達的波次、發現的組合數(n / 5), 按 Z 從開局重新開始(不再顯示說明頁; 魂爐清空)。結算出現後 0.5 秒內的 Z 不算。
