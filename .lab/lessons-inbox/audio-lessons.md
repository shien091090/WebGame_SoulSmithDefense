# 音效經驗提案(SoulSmithDefense 打磨第 14 輪 音效 build)

## 提案 1 → 放進「授權與下載」分類(新條目)

- `辨識` **Kenney 與 BigSoundBank 用 curl 下載回 403, 檔案存下來其實是 1~2 KB 的 HTML 錯誤頁** → 兩站都擋預設 curl 的 User-Agent; Kenney 頁面也沒有直接的 zip 連結(按鈕是用腳本去要一個有時效的簽名網址) → 一律帶瀏覽器 User-Agent 與 Referer(該素材頁網址)。Kenney: 對 `https://kenney.nl/download-link/<"assets/<slug>" 的 16 進位字串>` 發 GET, 回 JSON 的 `url` 就是 zip 的簽名下載網址(slug 是素材頁網址最後一段, 例 `impact-sounds`), 用同一組標頭下載; 用 Node 內建 fetch 寫成一支小腳本即可。下載後一律檢查檔頭(zip 是 `PK`、wav 是 `RIFF`), 不看檔頭的話要到解碼時才會報錯。(SoulSmithDefense 打磨第 14 輪 build)

## 提案 2 → 放進「素材來源」分類(新條目)

- `辨識` **要「金屬徽章 / 錢幣高速旋轉、越轉越近」約 1 秒的上揚音, 搜 medal / spin 只有合成掃頻** → 合成掃頻聽起來是介面音, 不像實體金屬 → BigSoundBank 的「Coin spinning on a table #2」(編號 2698, CC0, Joseph Sardin)最後約 1.3 秒是錢幣倒下前的高速顫轉, 天生越轉越快、越來越響(每 50 毫秒包絡 −33 → −22 dB), 停住的時間點用包絡驟降找(本例 16.45 秒)。取「停住前」一段, 用變速曲線再從 1.0 加速到 1.4 讓音高也往上爬, 尾端對齊規格的落定時間; 下面墊反轉的金屬盤 / 鐘當蓄力。同站的「Chimes "Dream"」「Chimes "butterfly"」系列(CC0)可當金粉灑落與單擊「叮~」(butterfly #1 開頭 0.07 秒是單獨一擊、0.4 秒衰減)。(SoulSmithDefense 打磨第 14 輪 build, 聽感待試玩)

## 提案 3 → 合併到「素材來源」的「成對事件(目標出現 / 目標達成)…」那一條, 接在最後當(續)

- (續)同一段勝利旋律可以做出三個尺寸, 讓玩家一聽就知道是「同一首凱旋的小 / 中 / 大」: 小 = 只用輕樂器分軌、升四度加速(新手畢業); 中 = 主要分軌原速(一般過關); 大 = 六種以上分軌、放慢約 0.84 倍(降約 3 個半音, 更莊重、自然變長), 起頭加戰鼓, 最後主和弦再加戰鼓 + 鐘 + 風鈴(全破)。主和弦時間先從原速分軌量起音(本例撥弦 / 鋼鼓在 1.605 秒), 除以速度就是放慢後的重擊點。(SoulSmithDefense 打磨第 14 輪 build, 聽感待試玩)
