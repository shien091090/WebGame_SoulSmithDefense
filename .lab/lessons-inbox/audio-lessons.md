# 音效經驗提案(SoulSmithDefense 打磨第 4 輪 音效 build)

## 提案 1 — 合併到「技術」分類「規格要『慢動作時背景音樂降一半並壓低音色』」那條, 以(續)接在後面

- `辨識` (續)壓低音樂的原因變多(彈窗、暫停、圖鑑、引導卡、演出), 而且全掛在「開 / 關」音效事件上時, 狀態會漏記 → 兩個原因: (1) 掛勾寫在「未 init / 靜音 / 同名限頻」的提早 return 之後, 靜音中開彈窗、或同一幀連呼開 + 關, 就只記到一半, 取消靜音後音樂卡在一半音量; (2) 用單一布林, 暫停中開圖鑑再關暫停, 會把圖鑑那份壓低一起解掉 → 掛勾放在 play 的最前面(只排除未知事件名), 不受靜音與限頻影響; 壓低改成「原因 → 設定時間」的表, 任何原因在就降一半, 只有彈窗原因才改播放速率; 換曲 / 停止音樂時清掉舊原因(防「從暫停直接離開關卡、沒播解除音」殘留), 但保留 150 毫秒內剛設的(防 RD 同一幀先播引導暫停再換曲)。結束點沒有專屬事件的(引導卡、演出都是按 Z 關), 掛在規格指定的關閉音(`ui_confirm`)上, sound.md 用一張「開始事件 / 結束事件 / 效果」表寫給 RD。冒煙測試用假 Audio 逐一驗: 交錯開關、靜音中開關、同一幀開關、換曲後殘留與保留。(SoulSmithDefense 打磨第 4 輪 build, 瀏覽器實測待試玩)

## 提案 2 — 新增到「事件設計」分類(目前尚無條目)

- `辨識` **規格指定演出音的撞擊點時間(例: 約 1.5 秒、撞擊在 0.9 秒), 現成素材沒有剛好的「蓄力 → 撞擊」** → 自己疊時, 蓄力層如果用正向素材, 起音在前、撞擊點對不準; 而且建置流程「整體裁掉開頭靜音」會把很輕的蓄力前段當靜音裁掉, 撞擊點整個往前移 → 把同一批素材包裡的鐘、金屬盤、法術聲**反轉**當蓄力(反轉後是從無到有的漸強, 尾端剛好是原音的起音), 每層用「結束在第 N 秒」對齊而不是「從第幾秒開始」; 這類音關掉整體開頭裁切。蓄力太輕會等於前段無聲: 第一版三層各 −4~−8 dB 時前 0.2 秒是 −120 dB、0.5 秒處才 −45 dB, 改用較長的鐘聲取前 0.9 秒反轉、各層提到 −4~+2 dB 後, 從 −56 dB 一路爬到 0.9 秒的 −10 dB。撞擊後接既有「新組合」同一段鋼鼓樂句, 聽起來是同一家族的大一號版本。驗收用 mp3 解碼器扣掉執行時的起播位置, 量最響點在播放時間 0.95 秒、全長 1.6 秒。(SoulSmithDefense 打磨第 4 輪 build, 聽感待試玩)
