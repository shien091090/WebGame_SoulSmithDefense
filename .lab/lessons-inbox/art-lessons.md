# 美術經驗提案(魂匠守衛者 polish-2 建置)

## 提案 1 → 「狀態可辨識」分類, 新增一條(掛 P4、P3)

- 介面要求組合物用「兩件材料的融合色」表現(魂柱範圍、晶石、共鳴線), 但有的組合是同一種材料兩件(遠攻 + 遠攻 = 穿透箭、近戰 + 近戰 = 旋風斬), 融合色退化成單色, 範圍和基本魂件的範圍長得一模一樣(魂匠守衛者 polish-2 建置設計判斷, 非老闆回饋, 不算升格證據) → 介面作者寫「融合色」時想的是異材料的典型例子, 沒逐一列出每種組合的兩色; 美術照字面套「材料 A 色 + 材料 B 色」, 同材料那幾種就只剩顏色一條通道、而且和基本件同色 → 用「材料色」編碼組合時, 先把每種組合的兩色列出來, 有同色對就不能只靠顏色: 組合一律多一個和基本件不同的形狀詞(該作: 範圍改雙實線外框、晶石加金框、虛魂件改金色虛線框, 對應圖示「比基本魂件多一圈外框」), 同材料的第二色取淡色只當輔助; 在 style.md 判讀約定寫明同材料組合的畫法(待老闆試玩確認)〔P4〕〔P3〕

## 提案 2 → 合併到「狀態可辨識」既有經驗「規格建議預告用半透明, 但半透明在遊戲內已有別的意義」, 補一段再現

- 魂匠守衛者 polish-2 建置設計判斷再現(非老闆回饋, 不算升格證據; 介面直接指定外觀詞): 介面要選單的說明區畫成「淺色底板」, 但「全畫面唯一淺底」是教學泡泡的字典詞(教學靠它在滿場時被找到); 照字面做, 選單裡就出現第二塊淺底, 教學泡泡貼在選單旁時兩塊淺底並排 → 介面作者寫的是相對意思(比面板亮、讀起來是一塊說明區), 沒查淺底在本作已被教學佔用 → 介面對外觀用的形容詞(淺色、半透明、發光、紅色)也要先查字典; 被佔用時保留介面的相對意思(比面板亮一階的深色底), 不用絕對的淺底, 在 style.md 判讀約定寫明偏離(待製作人驗收)
