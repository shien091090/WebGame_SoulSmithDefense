# 美術經驗提案(魂匠守衛者 polish-4)

## 提案 1 — 併入「交付自查」的經驗「多條路線(路、軌道、河道)有重疊段落…」, 作為一條「同類」

- 同類: 暫停式引導的壓暗層要在 1~2 個聚光燈圓內挖空, 兩個圓可能重疊(該作: 弩塔與步兵兩圈、半徑 52 / 44, 位置由玩家擺放決定), 順手寫成「全畫面矩形 + 每個圓」一條路徑 `fill('evenodd')`, 重疊那一塊被奇偶規則算成「在裡面兩次 = 在外面」, 壓暗被補回來, 正好蓋在兩個目標之間; 改用 nonzero + 反向圓, 重疊處的 winding 也會變回非零(魂匠守衛者 polish-4 建置設計判斷, 非老闆回饋, 不算升格證據) → 挖空寫成一次填色時只想了單一圓的情況, 沒算多圓重疊的填色規則 → 「多個區域都不畫」改成逐區剪裁: 每個圓各做一次「大矩形 + 該圓」的 evenodd `clip`, 連續剪裁取交集 = 所有圓之外, 再填壓暗; 柔邊環各自畫, 畫的時候也剪掉其他圓的範圍。自測至少餵一組兩圓重疊的資料(不掛理念: 屬畫法; 玩家看到的後果是 P19, 被指的東西一半被壓暗)

## 提案 2 — 併入「交付自查」的經驗「物件的狀態外觀(倒下、選中、受驚、失敗)超出介面給的判定框 `size`…」, 作為一條「同類」

- 同類: 全畫面暫停類元件(引導卡、合成演出、圖鑑、暫停)都是「全畫面壓暗 + 中央面板」, 介面給的 `size` 是 `{dim: 1280×720, panel: …}`; 假 ctx 的外接框把整張壓暗層算進去, 外接框永遠等於整張畫布, 面板放大彈入超框也報不出來(魂匠守衛者 polish-4 建置自查, 非老闆回饋: 引導卡紙底下多畫一層位移 4~6px 的陰影, 彈入到 1.05 倍時右下超出允許的 462×147 約 4px, 第一次跑超框檢查時被壓暗層蓋過, 沒報) → 外接框只累計一個總框, `size` 裡有多個子部件時沒有分開比 → 假 ctx 把「覆蓋整張畫布的填色」從外接框排除(全畫面層本來就不會超框), 再拿面板的允許框比; 或照經驗「子部件錨點」的做法把面板與壓暗分開量。自測同時餵面板彈入最大的那一幀(不掛理念: 屬交付流程)
