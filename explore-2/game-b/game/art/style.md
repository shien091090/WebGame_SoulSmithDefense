# 魂匠佈陣 美術規格(explore-2 / game-b)

RD 只讀這份。函式簽章與 state 欄位照 interface.json; 這裡寫畫法、判讀約定與尺寸。
`index.html` 必須宣告 `<meta charset="utf-8">`(art.js 內有中文字串)。`art.js` 是一般 script(非 module), 載入後提供 `window.Art`。

## 邏輯畫布尺寸
1280 × 720(`Art.canvas`)。HUD y 0~50, 遊戲區 y 50~650, 圖鑑列 y 650~720。

色相張力: 魂件六色裡「爆裂橘 28°」與「進攻主堡洋紅 340°」只差 48°。魂件靠**圖形**分(爆星 vs 旗子), 顏色只是第二條通道, 灰階差 54。最容易搞混的情況: 這兩件在 18px 槽位裡並排。

## 形狀語言
扁平填色 + 深色描邊。我方是**方正、有城垛的藍色建物/石塊**; 敵人是**圓頂、底部波浪的暖色幽靈**; 玩家是**奶白色兜帽小人拿鎚**; 魂件是**圓角方塊 + 白色圖形**(擴槽石是菱形、單位材料是木箱, 類別不同所以外形也不同)。

## 理念落實
- P0: 敵我的分法是「藍色方正建物 vs 暖色圓頂幽靈」, 顏色和輪廓兩條都分得開; 玩家是唯一的奶白色; 屍體去色、壓扁、眼睛畫成 X。
- P1: 最醒目的是 HUD 右半的下一波預告(金邊紫底, 字比左半大), 其次是互動目標的黃框與彈窗游標。背景、格線、路面的方向 V 字都壓到很淡。
- P2: 規則上存在的狀態都畫得出來: 屍體剩幾秒(頂端細條, 最後 3 秒閃)、敵人被拆掉進攻主堡後停住(頭上「?」)、減速(冰藍色調)、單件冰霜的範圍(地面虛線圈)、主堡區(地面圈, 玩家在區內時變亮)、互動目標(黃框)、中立和我方的歸屬(灰色閉眼 vs 藍色亮眼加胸前符文)。
- P3: 同一種魂件在槽位列、地上、手上、彈窗、圖鑑、商店都用同一個圖示; 同一種敵人在場上、屍體、HUD 預告、說明頁也用同一個造型; 黃色只代表「選中」, 粉紅只代表「搶奪」。
- P4: 魂件 = 顏色 + 圖形; 敵種 = 剪影(角 / 盔甲 / 翅膀加影子 / 小隻 / 速度線)+ 顏色; 放置預覽 = 綠 / 紅 + 不合法時加叉; 中立 / 我方 = 灰 / 藍 + 眼睛與符文; 圖鑑已發現 / 未發現 = 實框亮底 / 虛線暗底 + ???。
- P7: HUD 不畫主堡血條(數字已經夠用); 地上魂件只畫圖示和影子; 我方單位身上不加名字。
- P9: 敵人用深色粗描邊, 互動框用全場唯一的亮黃粗框, 滿場時也找得到。槽位列有深色底板, 疊在草地或路上都讀得到。
- P13: 組合名稱一次只出現在一個單位頭上; 「新組合!」比一般組合名大一級, 也是不同的長相(金底深字 vs 深底白字)。
- P15: 回饋分三級, 每升一級都換長相, 不只放大: 單體命中 = 小火花; 範圍招 = 地面上一大圈; 新組合 = 金色彈跳牌。
- P17: 數字給精確讀數(金幣、主堡生命、倒數秒數); 圖形只畫數字沒給的那一段(屍體剩餘時間細條、搶奪進度環)。預警圈裡只有秒數和朝右箭頭, 不另畫一圈倒數環。
- P18: 組合名稱只閃 1.5 秒, 但底部圖鑑會常駐留下來(名稱 + 兩件魂件)。
- P19: 魂件槽列貼在每個單位頭上; 停住的「?」、減速色調、受擊閃白都長在敵人身上; 手上物品畫在玩家頭頂。
- P21: 說明頁第 2 頁另外加了一隻小鬼, 讓它吃同一支普通箭來對照: 小鬼少了 1/4, 鐵甲鬼只少 1/36。只畫鐵甲鬼的話, 玩家不知道「一小截」到底算小。

### 文字歸屬
- 美術畫(RD 不要再畫): 組合名稱、彈窗裡的全部字(標題、「手上」、動作提示、「J 確定  K 關閉」)、商店的按鍵 / 品名 / 價格、HUD 全部字、圖鑑全部字、「慢動作」、結算面板全部字(含「按 J 重新開始」)。
- 說明頁例外: 頁標題、說明文字、頁碼、翻頁提示**由 RD 畫**。`drawGuidePage` 只畫示意圖和物件旁的短標籤(例:「你」「主堡」「屍體」)與鍵帽。示意圖的框請留在頁面文字之外, 兩邊才不會疊在一起。
- `drawGuidePage` 不在 interface.json 的繪製清單裡(interface 只寫了 `guidePages: 7`)。RD 畫說明頁時要另外呼叫它。

## 判讀約定
- 半徑都指**外緣**: 主堡區 110、冰霜範圍 radius、範圍斬擊 radius、搶奪環外緣 24。畫面上的邊界就是判定邊界。
- 互動目標黃框: 3px 寬, 內緣貼齊 size 外邊, 畫在框外。
- 屍體閃爍節奏由 `life` 自己算(`floor(life×5)` 是奇數時變淡), RD 不用另外傳。
- 步兵與石魔像的走路動作、玩家的晃動、預警的閃爍、搶奪光點的流動, 都用 `performance.now()` 自己跑, 只影響畫面。
- 組合名稱的底板寬度有上限, 加上彈跳與上飄後仍在 size 內; 名稱太長時文字會被壓窄, 不會超出框。
- 慢動作的去色用 canvas 的 `globalCompositeOperation = 'saturation'`。不支援的舊瀏覽器只會少了去色, 冷色、暗角、邊框和字都照畫。

## 繪製層級
照 interface 的 drawOrder 畫。允許畫到框外的只有: 主堡區地面圈、搶奪進度環、HUD 與圖鑑的整條區域、慢動作與結算的全畫面。
