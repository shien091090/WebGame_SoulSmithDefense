# 試玩回饋 explore-2

## 共通
- 「我希望改成方向鍵為移動, 其他按鈕操作盡可能限縮在z、x、空白鍵, 以只使用最多3個按鍵為限制去設計」 → 對應機制: 鍵盤按鍵配置(本輪用了 J / K 等鍵)。使用者補充: 「以後每款遊戲仍可以探索用滑鼠玩的可能性, 只是如果要用鍵盤操作的話, 要以我給的限制來做設計」(已寫進流水線共同守則)

## game-a(魂匠親征)
- 「我不喜歡守衛跟著角色移動, 我想要的是一種佈陣的感覺」 → 對應機制: 買來的移動單位成為跟班跟著玩家走(H37)
- 「我不喜歡魂件先放在角色身上, 再拿出放在其他單位上的感覺, 多一層手續會讓整個玩家體驗很卡」 → 對應機制: 玩家身上的魂件槽兼作搬運(H34 的搬運面)
- 「但我有覺得角色本身因為安裝魂件有不同攻擊模式的遊玩方式很有趣」 → 對應機制: 玩家角色裝魂件就有對應攻擊方式(H14、H34 的出手面)
- 使用者提出的兩全做法(原話): 「當玩家獲得魂件之後, 應該是處於"拿著"的狀態, 接著玩家可以選擇把魂件拿去裝到別人身上, 或是裝在自己身上, 裝在自己身上魂件就不是拿著的狀態了, 而之後要有一個按鍵可以再從身上把魂件取出, 變成拿著的狀態」
  - 經使用者確認的理解: 拿著時不生效、不自動進角色槽; 裝到自己身上才生效; 另有一鍵把自己身上的魂件取下變回拿著

## game-b(魂匠佈陣)
- 「圖鑑的設計我覺得改個方向會更有趣, 例如遠攻+遠攻解鎖了穿透箭之後, 他們會合成變成"穿透箭"魂件, 之後就可以透過某種方式直接獲得穿透箭魂件」 → 對應機制: 組合圖鑑(H13); 使用者想要的方向是「發現組合 → 合成為新魂件 → 之後可直接取得」
- 「我喜歡角色不會被攻擊的設定, 因為角色如果會被攻擊, 死掉必定會有某種懲罰例如暫停活動一段時間或是回主堡重生, 無論是哪種, 對於這種需要謹慎分配時間到某個地方的遊戲方式來說, 會有一種難以控制局面的無力感」 → 對應機制: 玩家角色不會被攻擊(本款敵人不攻擊任何單位, H40; 使用者講的是「角色」); 反面對應 A 款的玩家會被打、倒下掉魂件(H35、H36)與 H22

## game-c(魂匠收編)
- 「我不喜歡箭塔只能蓋在指定地點的設計, 這讓布局彈性變的很差, 可玩性被限縮, 沒辦法給人有很大的發揮空間」 → 對應機制: 靜態單位只能蓋在固定塔位(對照 B 款可蓋在路旁任意空格, H42)
- 「步兵放在道路上會一直往前衝的設計, 我覺得這應該要是某個組件, 或是某個組件搭配才會出現的移動模式, 會比較有趣」 → 對應機制: 移動單位放上路線就逆著路線推進(H46); 使用者想要的是由魂件(或魂件組合)賦予這種移動模式

## 跨款比較
- 使用者想要佈陣感(A 的跟班、C 的固定塔位都被否定, 理由都是佈局 / 佈陣的發揮空間)
- 使用者選擇進入深掘

## 不好的體驗
- 「多一層手續會讓整個玩家體驗很卡」 → 可能來源: 魂件先進玩家身上再拿出(A)
- 「難以控制局面的無力感」 → 可能來源: 玩家會被攻擊、死亡有懲罰(A 的倒下掉魂件; 推論)
- 「布局彈性變的很差, 可玩性被限縮」 → 可能來源: 固定塔位(C)

## 與已成立假設的衝突
- H26(滑鼠點擊操作 → 玩起來不喜歡): 「以後每款遊戲仍可以探索用滑鼠玩的可能性」 → 情境不同(條件: 本作)。使用者確認原話: 「這個遊戲機制我覺得比較適合鍵盤玩」——「仍可探索滑鼠」是對整條流水線其他遊戲的通則, 本作維持只用鍵盤, H26 保留在避開清單, 補上成立條件「本作的角色走動調度機制較適合鍵盤」
