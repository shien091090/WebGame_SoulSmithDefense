# 魂匠收編(把敵人收編成自己的軍隊)

## 概述
三條平行路線上, 敵人一路推向主堡。玩家可以貼身把活敵人身上的魂件一件件搶下來——拆掉「進攻主堡」它就停下、拆掉攻擊它就無害、**拆光它就變成中立的迷魂**, 再替它裝上「進攻主堡」, 它會自己走進主堡, 從此主堡就能買這種鬼當自己的兵; 買來的兵放到路上會逆著路線往敵營推進。同種魂件疊越多, 技能升級成有名字的大招(近戰×2 旋風斬、×3 裂地斬); 我方陣亡的單位會帶著原本的魂件重生。
驗證假設: H02、H03、H05、H10、H19、H20、H32、H33、H44、H45、H46、H47。

## 核心循環
敵人沿路推進 → 衝上去搶它身上的魂件(搶到的魂件拿去強化塔或兵)→ 拆光的敵人變中立, 替它裝上進攻主堡送進主堡 → 商店多一種兵 → 買兵放到路上反推敵營, 把同種魂件疊在王牌身上升級大招 → 陣亡的兵帶著魂件重生, 再上 → 下一波出現更強的敵人(魂王鬼), 想把它也收編。
想再做一次的理由: 敵人的種類就是你未來的兵種清單; 收編魂王鬼、讓它替你打仗的成就感。

## 規則
### 地圖
1. 畫面 1280×720, 上方 0~50 為 HUD。
2. 三條路線, 寬 56, 中線:
   - 上路: (0,170) → (1040,170) → 主堡 (1180,385)
   - 中路: (0,385) → 主堡 (1180,385)
   - 下路: (0,600) → (1040,600) → 主堡 (1180,385)
3. 主堡中心 (1180,385), 半徑 56。主堡中心 120 內是「主堡區」(購買用)。
4. 出怪點: 上 (10,170)、中 (10,385)、下 (10,600)。
5. 建造地基六塊(64×64), 編號從 0 起算: 0 (300,100)、1 (760,100)、2 (520,278)、3 (520,492)、4 (300,670)、5 (760,670)。

### 開局
6. 金幣 40, 主堡生命 20。
7. 地基 1、3 上各有一座箭塔, 魂件 [遠攻], 槽位上限 2。
8. 主堡魂件 [遠攻, 遠攻](= 連射), 槽位上限 3。
9. 中立野狼兩隻: (200,278)、(200,492), 無魂件, 槽位上限 2。
10. 玩家在 (1060,480), 手上空。

### 魂件與技能等級
11. 魂件五種: 遠攻、近戰、鐵壁、索敵、進攻主堡。另有擴槽石(不是魂件)。
12. 同一單位身上同種魂件的件數 n 決定技能(n ≥ 2 的等級有名字):
    | 魂件 | n = 1 | n = 2 | n ≥ 3 |
    |---|---|---|---|
    | 遠攻 | 每 1.0 秒對射程 200 內最近的敵對單位射投射物(速度 400), 8 傷害 | 「連射」: 同上但每 0.4 秒一發 | 「箭雨」: 每 1.0 秒對射程 220 內最近的敵對單位所在處降下箭雨, 該點 60 內每個敵對單位受 16+8×(n−3) 傷害 |
    | 近戰 | 每 0.8 秒對碰觸距離(兩者半徑和 +12)內最近的敵對單位造成 12 傷害 | 「旋風斬」: 每 0.8 秒對自身中心 60 內所有敵對單位造成 16 傷害 | 「裂地斬」: 每 0.8 秒對自身中心 90 內所有敵對單位造成 26+8×(n−3) 傷害 |
    | 鐵壁 | 受到的傷害 ×0.5 | 「堅守」: 受到的傷害 ×0.25, 且 100 內的敵對單位優先攻擊它 | 「不動城」: 受到的傷害 ×0.1, 且 140 內的敵對單位優先攻擊它 |
    - 索敵: 240 內有敵對單位時朝它移動, 速度 min(70×n, 140), 進入攻擊距離(有遠攻: 180; 否則碰觸)就停; 目標消失後回到自己路線上最近的點
    - 進攻主堡: 見規則 18、22、27
13. 每次有單位因為裝上魂件而升到有名字的等級(連射、箭雨、旋風斬、裂地斬、堅守、不動城), 頭上跳出名稱 1.5 秒; 本局第一次出現的名稱改跳「新技能! <名稱>」。
14. 每個攻擊技能各自計冷卻。行為優先序: 攻擊範圍內有目標就原地攻擊 > 索敵 > 其他移動(依單位種類)> 不動。

### 敵人
15. 敵人數值(槽位上限 = 魂件數):
    | 敵人 | 生命 | 速度 | 半邊長 | 魂件 | 掉金幣枚數 | 抵達主堡扣血 |
    |---|---|---|---|---|---|---|
    | 小鬼 | 30 | 45 | 16 | [近戰, 進攻主堡] | 1 | 2 |
    | 弓鬼 | 24 | 45 | 16 | [遠攻, 進攻主堡] | 2 | 2 |
    | 盾鬼 | 60 | 36 | 20 | [鐵壁, 近戰, 進攻主堡] | 3 | 3 |
    | 魂王鬼(菁英) | 160 | 35 | 30 | [近戰, 近戰, 鐵壁, 進攻主堡](= 旋風斬 + 鐵壁) | 8 | 6 |
16. 敵人的敵對單位 = 箭塔與我方移動單位; 不攻擊玩家、主堡、中立單位。我方(含主堡)的敵對單位 = 敵人。
17. 敵人有進攻主堡時沿自己的路線走向主堡; 沒有就停在原地(範圍內有我方單位仍會攻擊)。
18. 敵人身上沒有任何攻擊魂件(遠攻、近戰)就不會攻擊, 畫成無害的樣子。
19. 敵人身上魂件被拆到一件不剩 → 立即變成「迷魂」(該種類的中立單位): 停在原地、不攻擊、不被攻擊、不再算敵人。
20. 敵人中心進入主堡半徑 +10 內: 主堡扣血, 敵人消失, 不留屍體、不掉金幣。
21. 敵人生命歸 0: 變成屍體, 保留全部魂件, 15 秒後連同魂件消失(最後 3 秒閃爍); 在 40 半徑內噴出金幣, 每枚 2 金。金幣不會消失, 玩家中心距金幣 34 內自動撿起。

### 中立單位與收編
22. 中立單位(野狼、迷魂)只對進攻主堡有反應: 裝上後直線走向主堡(速度 45); 其他魂件裝上沒有效果。
23. 中立單位中心進入主堡半徑 +10 內: 它消失, 身上的魂件依序掉在 (1100+32×k, 480)(k 從 0 起算)成為地上的魂件; 主堡商店解鎖對應的兵種(野狼 → 野狼; 小鬼迷魂 → 小鬼兵; 弓鬼迷魂 → 弓鬼兵; 盾鬼迷魂 → 盾鬼兵; 魂王鬼迷魂 → 魂王兵)。

### 玩家與魂件彈窗
29. 玩家移動速度 260, 不會受傷、不擋路。手上最多拿 1 樣東西: 一件魂件、擴槽石、或一份單位材料。
30. 互動目標 = 中心距 ≤ 目標半邊長 +48 的可互動物中最近的一個: 我方單位、中立單位(野狼、迷魂)、主堡、屍體、地上的魂件、活著的敵人、空地基(只有手上拿著箭塔材料時才算)。
31. 手上拿著單位材料時按 J:
    - 箭塔材料: 互動目標是空地基 → 在上面蓋箭塔
    - 移動單位材料: 玩家中心離任一路線的水平段(x 0~1040)中線 ≤ 40 → 單位放在該中線上最近的點, 屬於那條路線
    - 其他情況無效。拿著移動單位材料時畫面顯示放置預覽(合法 / 不合法); 拿著箭塔材料時空地基會亮起
32. 互動目標是地上的魂件時按 J: 手空 → 撿起; 手上有魂件或擴槽石 → 互換; 不開彈窗。
33. 其他互動目標按 J: 打開「魂件彈窗」, 遊戲時間變成 0.2 倍(慢動作, 玩家不能移動):
    - 顯示目標的魂件槽(長度 = 槽位上限)和玩家手上的東西
    - 開啟時游標: 手空 → 第一個有魂件的格子; 手上有魂件 → 第一個空格; 沒有這種格子 → 第 0 格
    - ← → 移動游標(頭尾循環)
    - 按 J 依游標格執行, 成功後彈窗關閉:
      | 手上 | 游標格 | 目標 | 結果 |
      |---|---|---|---|
      | 空 | 有魂件 | 我方 / 中立 / 主堡 / 屍體 | 立即拿到手上 |
      | 空 | 有魂件 | 活敵人 | 開始搶奪(規則 34), 彈窗關閉 |
      | 魂件 | 空格 | 我方 / 中立 / 主堡 | 立即裝上 |
      | 魂件 | 有魂件 | 我方 / 中立 / 主堡 | 立即互換 |
      | 擴槽石 | 任一格 | 可擴槽且上限 < 4 的目標 | 槽位上限 +1, 擴槽石用掉 |
      | 其他情況 | | | 無效, 彈窗抖一下、不關 |
    - 按 K 關閉彈窗
    - 目標消失、死亡或目標中心離玩家超過「目標半邊長 +68」時彈窗自動關閉
34. 搶奪: 遊戲恢復正常速度, 1.5 秒後那一格的魂件從敵人身上移到玩家手上, 敵人立即失去它(並依規則 17~19 改變行為)。搶奪中玩家可以移動; 敵人中心離玩家超過「敵人半邊長 +68」、敵人死亡或再按 J 時取消。
35. 沒開彈窗時按 K: 把手上的魂件或擴槽石丟在腳下成為地上的魂件(不會消失); 手上是單位材料或空手時無效。
36. 在主堡區內、彈窗沒開、手上空時, 按數字鍵購買, 東西進到手上; 金幣不足或未解鎖則無效:
    | 按鍵 | 品項 | 價格 |
    |---|---|---|
    | 1 | 箭塔材料 | 15 |
    | 2 | 步兵 | 12 |
    | 3 | 遠攻魂件 | 10 |
    | 4 | 近戰魂件 | 10 |
    | 5 | 擴槽石 | 20 |
    | 6 | 野狼 | 12 |
    | 7 | 小鬼兵 | 8 |
    | 8 | 弓鬼兵 | 10 |
    | 9 | 盾鬼兵 | 16 |
    | 0 | 魂王兵 | 30 |
    6~0 未收編前鎖住。鐵壁、索敵、進攻主堡只能從敵人與單位身上取得。

### 波次
37. 說明頁關閉後開始計時。第 k 波在 12 + (k−1)×24 秒開始; 開始前 6 秒, 該波用到的每個出怪點出現預警。
38. 每個出怪點每 1.3 秒出一隻, 依下表順序:
    - 第 1 波: 中 小鬼×5
    - 第 2 波: 上 小鬼×4、弓鬼×2
    - 第 3 波: 下 盾鬼×3; 中 魂王鬼×1、小鬼×3
    - 第 4 波: 上 弓鬼×4、盾鬼×2; 下 小鬼×5
    - 第 5 波: 上、中、下 各 小鬼×3; 中 再加 魂王鬼×1(排在小鬼之後)
    - 第 6 波: 上、中、下 各 小鬼×3、弓鬼×2、盾鬼×1; 下 再加 魂王鬼×1(排在最後)

## 操作
只用鍵盤。
| 按鍵 | 動作 |
|---|---|
| W A S D | 移動(彈窗開著時不能移動) |
| J | 對互動目標打開魂件彈窗 / 撿起或互換地上的魂件 |
| J(彈窗中) | 對游標格執行: 拿、裝、互換、擴槽、搶奪 |
| ← →(彈窗中) | 移動游標 |
| K(彈窗中) | 關閉彈窗 |
| K | 丟下手上的魂件或擴槽石 |
| J(搶奪中) | 取消搶奪 |
| J(拿著單位材料) | 在空地基蓋箭塔 / 把移動單位放到路線上 |
| 1~9、0 | 在主堡區購買 |
| J | 說明頁翻頁, 最後一頁再按開始遊戲 |
| J | 結算畫面重新開始 |
說明頁關閉後要等 J 放開才接受遊戲內的 J。

## 勝負與結束
- 勝利: 第 6 波全部出完且場上沒有活著的敵人(迷魂不算敵人)。
- 失敗: 主堡生命 ≤ 0。
- 結算畫面顯示勝利或失敗、到達的波次、收編了幾種兵(0~5), 按 J 從開局重新開始(不再顯示說明頁; 收編清空)。結算出現後 0.5 秒內的 J 不算。
